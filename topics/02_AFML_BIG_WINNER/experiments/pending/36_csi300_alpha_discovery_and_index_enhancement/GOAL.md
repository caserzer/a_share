## 1. 核心目标与已确认决策

复用既有 A-share 数据与研究工具，检验日频量价信息能否在历史沪深300成分股中提供可重复的未来收益排序，并转化为成本后的指数增强。

1. **A、B 两条路径都做，分别裁决。** A 检验排序及高分组长仓；B 检验基准权重上的受约束增强。A 不显著不能自动取消 B，B 的结果不能反向修改 A。
2. **优先简单基线、Ridge、LightGBM。** 不要求完整复刻 CMM、先证明经济机制或升级神经网络。
3. **共享预测层。** 同一模型的同一冻结预测供 A/B 使用，不分别选模型、种子或训练。
4. **研究对象为沪深300。** 不继承 Big Winner 的赢家分类、右尾召回、入场事件或风险概率验收目标。
5. **完成实验不等于获得正结果。** 无效、成本后消失和明确的数据阻断均为有效交付。

Alpha 在这里指历史模拟样本外的可重复排序信息及其成本后相对收益潜力，不是经济机制、因果关系或风险调整截距的证明。

训练和评分总体均为各历史信号日当时有效的沪深300成分。**首版不采用全市场训练、沪深300预测。** 不能因后来退市、跌幅大或未来标签缺失删除历史总体。资格规则只依赖当时可见历史长度及字段覆盖。

每期报告原始成分数、可评分数、成熟标签数、未知标签数、可交易数、缺失证券基准/组合权重。未知标签不填零；持仓缺价必须另外披露估值规则及敏感性，禁止将无依据旧价静默视为真实净值。无法可靠估值的区间不得认证收益结论。

股票与基准须统一分红、公司行动、时间和计价语义。正式 B 优先采用一致的全收益比较；使用前复权价格代理时，建立同口径历史基准篮子，并与官方基准核对差异。官方只有收盘值时不伪造开盘全收益。EP30 的价格/total/executable 别名不得解释为三个独立或已认证收益。

## 4. 特征与模型

### 4.1 核心及扩展特征

E2 核心特征控制在约100项以内，以运行前冻结的 `feature_dictionary.csv` 为准：

- 最近20日原始逐日收益，以及逐日截面标准化收益；后者以每个历史日当时有效的沪深300成分为参照，记录有效样本及零方差处理。
- 1/3/5/10/20/60日累计收益及最近1日、此前2—5日、6—20日固定分段。
- 5/20/60日波动、振幅、回撤、区间位置。
- 相对成交量、成交额、可用换手率及其变化。
- 沪深300同期趋势、波动、回撤等市场状态。

相对市场收益与截面标准化收益含义不同；是否保留前者及去重清单在 P0 冻结。E3 增加不超过约40项事前列明的既有量价特征，不自动导入历史 EP 模型预测。E2/E3 必须报告相同日期和证券上的配对比较及覆盖变化。

历史填补、尺度和筛选参数仅在相应训练窗口拟合；当日截面变换使用当时已知总体。复权特征采用重锚不敏感的比例表达，检查原始量额、VWAP、复权价格的单位和尺度一致性。

## 5. 标签、时间推进及预测封存

主信号 t 为每周最后一个市场交易日，收盘信息完整可用后生成。按市场日历定义：入场 t+1 开盘，H10 出场 t+11 开盘，价格代理收益为 `adj_open[t+11]/adj_open[t+1]-1`。截面标准化后的 H10 收益作为训练目标，零方差或样本不足日期不可训练。样本最低数量、标准差约定和异常处理在 P0 冻结。

标签按共同计划时点定义；缺端点保持未知，不能事后选择有利成交日。交易账户独立处理成交、现金与持仓，不能用重叠 H10 标签直接拼接净值。

默认准备2017年起数据，2017—2020年初始训练/验证，外层从2021Q1逐季度推进；实际范围取决于覆盖、warmup 和标签成熟，不预称数据已覆盖最新日期。

- 主窗口 expanding，季度重训；rolling36 为固定稳健性分支。
- 每折仅使用拟合截止前已成熟标签；最近约6个月作为内层验证，按实际 `[entry, exit]` 标签区间 purge 重叠样本。
- 内层早停选定轮数后，按预先固定规则使用拟合截止前全部合格成熟历史重训，不读取外层标签。
- 以信号生成时点分配季度模型；不能用执行日才拟合的模型倒填此前信号。冻结模型可用时点与数据可用时点。
- 预测与未来标签分表；预测阶段不读取测试标签。保存每折模型、配置、数据快照、特征版本、拟合截止、成熟记录与哈希。
- 预测至少包含 signal_date、instrument、universe_id、fold_id、model_id、seed_or_ensemble、feature_cutoff、model_fit_cutoff、score、score_eligible、missing_reason、feature_version、data_snapshot_id。文件哈希存独立 manifest，避免文件自哈希循环。
- A/B 读取同一封存预测文件，在各自消费 manifest 记录一致 SHA256；不能为不同成本情景重新训练。

已有历史被反复研究，本轮只能称历史模拟样本外，不宣称未见盲测。仅可交付前瞻接口；未真实生成并成熟的预测保持 `FORWARD_PENDING`，不因本文自动启动前瞻任务。

## 6. A：排序与高分组组合

每周在完整列明的合格评分总体内分五组，Q1最低、Q5最高。冻结同分排序、组大小和缺分处理，不按结果修改。

报告 H10 RankIC、原始非年化 ICIR、RankIC 正值比例、五组收益和 Q5−Q1 诊断；分组差不表示已执行融券收益。

另外运行 Q5 等权长仓，每周下一市场开盘再平衡，按每日账户记账。报告毛/净收益、换手、回撤及相对官方或匹配基准、当期成分等权的收益。成分等权交易对照使用一致时钟和成本，并区分指数收益与带摩擦账户收益。

区分整体排序、排除差股票、高分组盈利和跑赢基准，不用其中一项代替其他项，也不据此取消 B。

## 7. B：基准权重上的约束增强

使用同一预测，围绕当时可用基准权重 b 形成目标倾斜，不把回归分数解释为百分比预期收益。

可评分股票转成居中的截面排名倾斜 z；不可评分成分在排名变换后赋 z=0，保留基准权重。所有分数相同或无有效倾斜时 q=b；否则 `kappa=2*A0/sum(abs(z))`，`q=b+kappa*z`。以最小化 `sum((w-q)^2)` 的统一投影生成目标，A0=10%。报告实际主动份额及投影对未评分股票产生的偏离。

| 约束 | 默认值 |
| --- | --- |
| 目标 | sum(w)=1，w>=0，不融资、不做空 |
| 股票范围 | 当期沪深300；不可卖出调出股作为被动遗留持仓披露 |
| 个股主动偏离 | ±0.5个百分点 |
| 行业主动偏离 | ±2个百分点；历史代理身份另列 |
| 后续单次单边换手 | 20%，相对交易前漂移持仓 |
| 初始主动份额预算 | 10%，投影后可能降低 |
| 跟踪误差 | 实际测量；2%—4%仅观察参考，不作为已控制的硬约束 |

P0 冻结包含现金维度的换手定义、初始建仓例外及目标与实际成交换手的区别；同时输出买入/NAV、卖出/NAV，以便复核费用。首次建仓所有组合均计实际成本，免后续20%换手上限。

信号日冻结分数、可用基准信息和组合规则；执行日按预定规则，用实际持仓及当时报价计算漂移权重、约束与订单数量。该做法属于日频开盘成交近似，不宣称开盘前已知道精确开盘价。

不可行时优先保留真实不可交易持仓、保证账本及不融资不做空，再在可交易部分尽量满足其余限制；记录所有约束偏离、求解状态和未成交，不静默放宽或虚构清仓。具体可行性规则在 P0 固定。

三层对照全部保留：官方可比基准；同执行引擎基准跟踪 B0；E0/E1/E2/E3 同组合器增强。只战胜有摩擦 B0 不等于战胜官方指数。

报告成本后超额、逐年超额、IR、TE、相对净值最大回撤、换手、现金、持仓数、行业和个股偏离。`relative_NAV=portfolio_NAV/benchmark_NAV` 的年化增长与两者 CAGR 之差分列；IR 基于日主动收益并注明年化交易日约定。

## 8. 统一账户与成本

信号收盘后生成，下一市场交易日开盘执行，随后每日估值记账。禁止同收盘信息同收盘成交。买入未成交留现金，卖出未成交继续持仓；不追单、不事后挑选有利补成交日，至下次计划调仓按新目标处理。

| 情景 | 买入 | 卖出 |
| --- | ---: | ---: |
| 零成本 | 0 bps | 0 bps |
| 主成本 | 10 bps | 20 bps |
| 压力成本 | 30 bps | 80 bps |

费用按实际成交金额扣除，保留费用产生的现金差异，不强制重标满仓。明确成本是否已含滑点/冲击代理，避免重复收费。这些是研究假设，不声称等于当前实际账户费率。原始报价用于可交易检查，复权价格用于收益代理时须有一致账户转换口径，禁止混算股数与资金。

## 9. 固定稳健性与证据裁决

主结果为 expanding + H10 + 周频，全部登记模型运行 A/B 和三种成本。稳健性分别改变一个条件，不做所有设置的笛卡尔积：rolling36、固定日历锚的双周调仓、额外一个市场交易日执行延迟。H5/H20 用同一 H10 预测评价期限敏感性，首版不另训练两套期限模型。

逐年、逐季度完整报告。时间块不确定性保留同日横截面关联及 H10 重叠；块长度、抽样次数、区间方法、随机种子在读取外层结果前冻结。披露实际尝试数量，事后优胜者仍需后续冻结验证。必要异常检查包括行业/个股集中、源差异、缺失覆盖及单一时期贡献，不扩成经济机制归因主线。

分别回答：有没有排序信息；Q5 是否成本后有价值；B 是否有净增强；LightGBM 是否比简单基线有增量。

- 正点估计但区间、成本或覆盖不足：历史正向线索，不升级为强证据。
- 主成本下净增强为正、时间块区间支持且非少数异常驱动，基线及稳健性完整：较强历史支持，仍不是实盘认证。
- 毛收益被成本吃掉：当前实现未证明可交易价值。
- 数据或口径足以翻转方向：证据不足或分支受阻，不强行成功/失败。
- A弱B强、A强B弱均如实保留；简单基线获胜也为有效结果。
