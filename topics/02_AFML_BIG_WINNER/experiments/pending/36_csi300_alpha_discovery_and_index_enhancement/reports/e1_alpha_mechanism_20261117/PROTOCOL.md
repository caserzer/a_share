# EP36 行业内回撤修复与 E1 信息增量实验方案

本轮要回答：E1 是否识别了一种可以事前定义的股票状态，这种状态能否在控制已知风格后预测收益，并在实际交易约束下兑现？首个候选机制是“行业内中期相对强势股票的短期相对回撤修复”。共同反弹、风险补偿和执行路径是竞争解释，不预设候选机制成立。

## 2 假说与可推翻条件

**M1 回撤修复：** 同行业中，较早一段时间相对强势、最近五日相对回撤的股票，未来 H10 收益具有超出趋势、反转各自主效应的增量。可能的经济解释是暂时性价格压力，但价格数据只能验证状态和收益关系，不能证明谁在卖、为何卖。

**M2 共同反弹与风险补偿：** 所谓修复只是普通反转、市场反弹、高波动或流动性风险暴露的兑现。同日行业和风险对照若获得相近收益，模型特有解释应被削弱。风险补偿也可能可交易，但不应命名为未知信息。

**M3 日期与路径：** 月初优势主要由入场日期、继续持有或换仓造成。固定名单事件与连续账户分开后，若优势只存在于某种账户路径，应归入实施机制，不能反推 H10 预测能力更强。

| 问题 | 支持该方向的证据 | 反向或不足证据 |
| --- | --- | --- |
| M1 是否存在 | 条件收益及简单规则成本后差额均为正，并通过预设主检验 | 控制主效应后消失、成本吞噬、或区间过宽 |
| M1 是否解释 E1 | E1 选股富集该状态，状态收益贡献可追溯，剩余条件增量减弱 | E1 并不富集、收益来自其他事件，或剩余增量仍大 |
| E1 是否仍有新信息 | 控制候选状态后仍有条件预测增量，辅助经济对照也支持 | 只有原始收益好，条件增量不足 |
| M2 或 M3 是否更合理 | 匹配对照同步获利，或改变日期和路径足以改变结果 | 同日期固定期限下仍有稳定选股差异 |

不显著只记为证据不足。要宣布经济上足够小，必须另有事前等价界限和相应检验，本轮不作等价结论。

## 5 候选状态与独立简单规则

为避免近五日收益同时进入两个方向，使用不重叠窗口：

- 中期趋势 T：log(C[t−5]/C[t−60])，即排除最近五日的前 55 个交易日收益。
- 短期回撤 P：−log(C[t]/C[t−5])。
- 分别减去当日同行业其他有效股票的等权均值，再做行业内平均秩百分位 u、v，定义为 (平均秩−0.5)/n。数值越高，分别表示相对中期更强、相对短期回撤更大。
- 简单加法分数 B=(u+v)/2；共同状态分数 J=min(u,v)。二者不使用 E1 系数、不使用未来标签、不估计收益权重。

J 要求两个条件同时较高；B 允许一项很高补偿另一项较低。它们的差异是本轮固定检验对象，不测试其他乘积、窗口或阈值来替换主规则。

为解释结果，另作 2×2 状态表：按 u、v 是否大于 0.5 分为强势回撤、强势非回撤、弱势回撤、弱势非回撤。该表是描述，不凭四格均值选择新策略。T、P 是相对状态；并不保证绝对价格上涨或下跌，绝对收益符号另列。

只保留五个简单分数作诊断：u、v、B、J、原 E1。其中 u、v 不设额外主检验。B 是独立简单基线，不代表已经穷尽所有已知风格。

## 7 实验 E1 条件收益与剩余信息

本节 E1 为实验编号，其模型对象仍为原 E1 Ridge。使用所有有效原周信号，不仅使用月初 Q5。

每个信号日进行等权截面回归，因变量是 H10 开盘到开盘毛收益；不将逐只股票当作独立时间样本。控制项 Z 包含截距、行业哑变量、13 项标准化风格，以及 u、v 各自的线性项和固定折线项 max(u−0.25,0)、max(u−0.5,0)、max(u−0.75,0)，v 同理。折线控制各自主效应的非线性，避免把它误认为共同状态效果。

P1：y=Zγ+δJ+ε，检验日期平均 δ 是否正向。J 在当日标准化；δ 是收益关联，仍非因果机制证明。

P3：y=Zγ+δJ+θS+ε，其中 S 是当日 E1 分数的标准化截面秩。检验日期平均 θ 是否正向，以回答候选机制及既有风格之外 E1 是否仍有信息。

回归使用 SVD、rcond=1e−12；记录矩阵秩、有效自由度。标准差为零的列删除并记录；目标变量被控制项完全解释或目标残差方差小于 1e−12 时记不可识别，不能把系数零作为无效证据。对因变量不事后截尾；异常收益核查原始数据，修正必须有来源凭据和版本。

辅助报告：原分数、J、B 的 H10 RankIC；双方秩残差相关的条件 RankIC；H5/H20 条件系数；逐年结果、逐年留一、去掉最大三个贡献月的敏感性。后两者明确为已知贡献集上的影响诊断，不重新生成主结论。

## 8 实验 E2 独立规则的经济增量

主比较 P2 为月初第一个原周信号的 H10 净事件 J−B，同日配对、等事件权重。它回答共同状态规则是否优于简单加法风格规则，不直接回答原账户能否完全复制。

每个日期使用 C 样本，k=ceil(n/5)，每股目标权重 1/k。按各行业在 C 中的数量比例分配 k 个名额：先向下取整，剩余按小数余数从大到小分配，同余按行业代码排序。B 在各行业内选分数最高股票，分数同值按股票代码排序。这样行业预算只依赖股票池，不读取 E1。

J 和辅助 E1 对照在相同行业名额、相同 k 下最大化各自分数秩，并要求 13 项风格的目标均值与 B 相差不超过当日截面 0.25 标准差。B 自身是可行解；用固定 MILP，time_limit=2秒、mip_rel_gap=0.01。不验证通过的解不得成交；无合格解记 NO_TARGET，不放宽容差。记录最优界、解差、重复名单比例及因约束导致的 J−B 分数差缩小。

买入/卖出费用主设 10/20bps，辅助零成本和 30/80bps。独立事件按上述开盘定义记费；连续账户保留持仓，按真实换手计费。组合约束只保证目标暴露，成交后和持有中漂移逐日检查，不能叫全程风险中性。

连续账户仅运行月初原日历的 B、J、受约束 E1，以及只读原 E1 和原同行业等权基线；不扩展周度、双周参数网格。主历史终点固定，对不支持估值的账户报告停账和共同终点，不截短后冒充完整主区间。NO_TARGET 日期账户保留旧仓；固定事件不产生新可比较目标，失败月份仍留在分母和日志。

账户指标：净 CAGR、相对净值、日均主动收益、最大相对回撤、跟踪误差、年化单边换手、成本金额、现金及实际风险偏离。连续账户为经济验证辅助，不用 CAGR 的点估计替代 P2 主检验。

覆盖不足、配对退出未知或成交后风险差较大时，只能报告相应可观察部分。另列未知预算与其已知特征，不用任意收益填充构造“全样本结果”。本轮没有资金规模和盘口冲击数据，固定费率结果不能认证大资金容量。

## 9 实验 E3 共同反弹与交易路径

M2 的状态分组只读信号前信息：沪深300过去20交易日总收益正/非正，以及过去20日波动高/低于此前252日滚动波动值的中位数；历史不足者 UNKNOWN。分组结果仅作辅助，市场未来是否反弹可用于事后描述，不能成为当时交易条件。

同日股票匹配作为解释性核验：每个原 Q5 股票从未入选的同日 C 池寻找同 L1 行业的最近邻；13 项标准化风格每项距离不超过0.5，最小平方距离优先、同值按代码。允许有放回匹配并披露对照重复度，控制股不按未来可交易性筛选。报告覆盖预算、匹配差异和未匹配事件。J 状态差异若也被匹配消除，只能解释为本匹配合同下可识别空间很小，不能据此证明无 Alpha。

日历安慰剂使用100个固定种子序列，在同日行业内无放回随机选股，保持上述行业名额和 k；每次最多100次尝试满足相对 B 的相同13项容差。失败保留，不挑最好种子，不扩大容差。报告随机分布与覆盖，不把受约束抽样当成有严格交换性保证的因果随机试验。

M3 只复用原第一、第二周相位，按以下三项比较固定 H10 事件：月初旧名单立即入场、同名单在第二相位入场、第二相位新名单入场。B、J 与受约束 E1 各自保存旧新名单。立即与延迟差异混合信号老化和日期；延迟旧名单与同日新名单差异定位刷新效应，两者都不是纯因果分解。

H20 路径按同一初始资本与固定单位拆为1—5、6—10、11—20交易日，建仓费只计一次，H20最终退出费只计一次。单独 H5/H10 清算另表，不能把三次独立持有净收益直接相加。事件路径不外推连续账户收益。

## 10 统计分析与多重检验

主检验族固定三项：P1 条件 J 系数、P2 月初 H10 净收益 J−B、P3 条件 E1 系数。全部为主区间、E1 相关样本、H10；P2 使用主成本。双侧检验、正向点估计、Holm 三项校正后 p<0.05 才记该项获得历史统计支持。不得用辅助项替换失败主项。

时间块 Bootstrap 5000 次，种子20261117。周信号均值以13周连续日历块重采样；月度配对差用3个月块；辅助账户日收益用65交易日块。整块保留所有股票与模型的配对关系，不按股票独立抽样。缺失日期占位保留，统计量使用有效观测；没有有效观测的重采样记失败并披露。

报告95%百分位区间、以零假设中心化的双侧 p 值并作 +1 修正、Holm p、有效日期、覆盖、块数与效应量。95%普通区间不是家族同时置信区间；主裁决依据 Holm p。辅助相关图和逐期表不给“确认性显著”标签。

统计与经济分开裁决：正向 δ 不能代替可交易净收益，P2 通过不能代替 E1 独立信息；零成本胜出但主成本失败记成本不足。风险、数据代理和历史选择边界不会因 p 值较小而消失。

执行级冻结时登记首个未来信号、确切截止日期、代码与参数哈希及预定审阅日。观察期固定为连续36个完整自然月，结束后待最后 H20 标签成熟再作正式统计裁决；月报只检查数据、覆盖与风险，不因累计盈利提前宣布成功。24个月仅作中期描述；36个月也不保证有足够功效。若36个月中有效配对不足36个，P2 仍只能给出部分样本估计，不自动延长观察以补足门槛。

正式前瞻三项主检验统一在36个月末作一次；24个月报告只估计效应、覆盖和区间，不作显著性通关。冻结时用历史时间块方差估计24/36个月的最小可检出效应，报告功效限制，不能据此挑选更赚钱的规则。若需更长观察，须在到期前另记延长期限，不能为跨过显著性门槛无限续看。

E1 前瞻需要可按原流程产生的新分数；当前只冻结历史预测并不自动具备这项能力。若原有生产流程不可用，先运行独立 B/J 前瞻，E1 相关比较记 FORWARD_BLOCKED_MODEL；不得偷偷新增训练替代。后续如启动例行训练，另冻结原算法、成熟标签隔离和季度更新流程，不改变本轮历史模型。

历史和前瞻不合并计算“更显著”的主 p 值。输入不可得、延迟出分或临时无法成交均实时记录；已发生事件不能事后补记成当时有效信号。

## 12 执行顺序和验收条件

| 阶段 | 工作和产物 | 进入下一阶段的条件 |
| --- | --- | --- |
| G0 数据与范围审计 | 输入清单、哈希、样本覆盖、标签时点说明 | 原账户与模型对象无混淆，缺口已列明 |
| G1 实现与冻结 | 代码、配置、特征组映射、三个主检验、版本凭据 | 数据时间与计算单元检查通过，未计算本轮新收益统计 |
| G2 无标签构造 | 全量状态、分数贡献、名单、约束和失败记录 | 分数复放通过；名单和哈希封存后才连接标签 |
| G3 历史验证 | P1/P2/P3、原账本桥接、路径与覆盖 | 全部成功和失败结果保留；主辅助分开 |
| G4 独立裁决 | 每个假说报告、简单中文解释、停止或继续理由 | 不以换阈值补救失败，历史结果保持探索标签 |
| G5 前瞻登记 | 时间戳信号、月度审计、固定终点报告 | 未来数据未被提前观察，模型可用状态真实 |

实现检查至少包括：未来价格被扰动不能改变当期名单；不重叠窗口索引正确；行业内排名与同值顺序确定；原分数复放；固定 k 和行业名额；风险约束验证；缺价不变零；建仓和退出费用不重复；账本贡献加总；Bootstrap 保留日期配对；不可行与退出失败不丢行。只做与这些风险相关的测试。

任何数据时序泄漏、原模型无法复放、标签边界错误或账本不平先暂停对应分支，保留错误凭据，修复后提升版本。匹配覆盖不足记 PARTIAL_IDENTIFICATION；数据缺口记 BLOCKED_DATA；区间宽或主检验未通过记 INCONCLUSIVE；主指标反向且区间排除零记 EVIDENCE_AGAINST。停止不等于未来永远无效。

## 13 结果交付和决策

每个实验报告均包含“想验证什么—怎么比较—发现什么—为什么不能下结论—下一步”，并给出原始明细入口。计划产物：

- 总报告和机制裁决表；模型分数解释报告；独立规则报告；共同反弹及时间路径报告；前瞻登记说明。
- 股票—信号日全量表、季度特征贡献、状态分组账本、匹配对照与失败表、固定事件路径、逐年逐月账户及成交成本。
- 三项主检验原始与校正统计、完整辅助结果、覆盖与缺失表、源数据和输出哈希、环境与运行凭据。

| 最终组合证据 | 研究决定 |
| --- | --- |
| M1 条件关系和净收益均获支持，E1 无额外支持 | 候选机制进入前瞻，优先保留简单规则；不能用“不显著”声称 E1 等价 |
| M1 获支持且 E1 仍有剩余信息 | 候选机制和 E1 各自前瞻；后续特征研究另立版本 |
| 有条件排序，但主成本后不足 | 报告预测信息与经济空间，先看成本和容量，不调相位救回测 |
| 主要由共同反弹或日期路径解释 | 转为风险和实施研究，停止宣传模型独立 Alpha |
| 覆盖不足或统计功效不足 | 保留线索与缺口，不强行二元结论 |
| 条件关系与经济增量均无支持 | 本轮机制分支结束；不在相同历史反复改阈值 |

“真正可用”的最低含义是：事前可生成、相对合理基线有增量、成本可兑现、风险和数据限制明确，并在新数据中复现。本轮首先负责把可检验的机制建立起来，不承诺完整因果解释，也不承诺最终一定存在 Alpha。
