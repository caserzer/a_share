# E1 超额的逐年逐月分布

本轮固定原始E1 expanding Ridge、每月第一个周信号Q5等权账户，未换成上一轮受约束S1。区间为2021-01-08信号收盘至2025-03-03收盘，首次交易2021-01-11，1001个净值交易日。买入10bps、卖出20bps，建仓费用计入；全天停牌旧价估值最多20日等原代理规则不变。未重训、未调参、未改原始持仓。

所有股票收益仍是前复权合成单位口径，行业使用历史L1区间代理；基准使用真实沪深300全收益收盘，不虚构指数开盘或历史指数成分权重。原E1和原成分等权账户均完成逐日精确复放。历史已被查看，本轮是描述性归因与反事实比较，不是独立盲测或因果证明。

初始各投入100元，原E1期末为120.674元，指数为78.043元，财富差为**42.631元**。其中E1自身净盈利20.674元，指数损失21.957元，两者共同形成这笔相对财富差。本文“贡献元”指对全期差额的归因，并非该行业或股票独立账户的收益率。

先逐日核对股票损益减费用与NAV变化，再按上一日资本权重扣除指数机会收益，用对数连接系数将日贡献连接到全期相对财富；最后对所有贡献使用同一个换算系数。这样月份、年份、股票、行业、费用和现金各自加总都能回到同一笔财富差。月份自身收益率差不能直接相加。
