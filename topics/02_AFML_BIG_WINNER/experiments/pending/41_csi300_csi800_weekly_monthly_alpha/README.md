## 执行记录应留下什么

1. **先报基线和支持范围。** 登记运行号、输入快照、历史可用日期、季度成熟标签截止、代码/模型版本、完整期数、可配对资金和缺口。有数据缺口可以先完成不依赖该源的实验。
2. **每轮只解释有单项对照的改动。** 锁定本轮参数、主比较、对照和完成条件后再看账户；探索性子项按家族列出所有尝试。更改阈值、行业分类或信号方向另记版本。
3. **交付三张结果表。** 每期与逐月的配对净差；实际订单、费用和可成交资金；收益来源与失败区段。分列历史发现、反例、区间不确定和真实新期。来源锚定到[登记前仓库版本](https://github.com/caserzer/a_share/tree/7514ecdcf825f8c4e60d074d2ad1f8ce9e8c2edc)。
