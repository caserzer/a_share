# N5｜披露过的客户与供应商能否改善换入选择

对光伏和动力电池的四份具名公告做了历史样本回放。两家公司须有可核对的证券代码，关系须已公告且在合同期内。单列这四条供应关系时，1,389 个信号日中只有 **7 日** 能在相同买入预算内部改选股票。5 日关联收益相对同覆盖 Ridge 顺位的净差为前段 **−0.06**、后段 **+0.24 bp/月**。行业动量对照为 −0.06、+0.23 bp/月。可改变的预算太少，无法据此评价全市场产业链效应。

**选股与可用时点。** 固定 P2 的原 Ridge 核心、树卖单、候补范围和 Ridge 顺位买入预算。原顺位买单中有几席获得关系覆盖，就只在有覆盖的候补中重排这几席。保留其余买单，逐日按十袖净订单收费。40,103 个候补席位观测只有 173 个具备可比信号，原顺位计划买单只有 26 个在覆盖范围。供应方和买方均可读取另一端已知收益，排除自身和伪组中的真实对手方。使用五或十个交易日的复权收盘变化；行业均值使用信号日历史池。公告日收盘后再启用，另设合同起止日。对后来复述的合作使用所核对公告的日期。原文只证明披露的合同或框架，实际发货数量和后续履约变更缺少完整版本链。[逐日覆盖](coverage.csv) · [全部可评分候补及关联方](signals.csv) · [净订单](net_orders.parquet) · [逐月结果](months.csv)
