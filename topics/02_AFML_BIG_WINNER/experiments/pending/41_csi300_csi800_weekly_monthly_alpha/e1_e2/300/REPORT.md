# 沪深300｜边际费用门槛 E1 与自然换仓 E2

两段独立账户的 49 和 18 个共同完整月中，成本门槛显著减少实付费用。后段放弃交易的毛收益超过节费，Ridge 和树两臂都落后原路径。只用原 Ridge 自然买入预算的 E2 在两段相对原仓月差为正，区间均跨零。

| 同月配对净差，bp/月 | 前段 | 后段 |
|---|---:|---:|
| E1 Ridge 零缓冲减原 Ridge | +0.81 | −39.97 |
| 其中毛差 / 实付费差 | −13.51 / −14.32 | −75.73 / −35.76 |
| E1 树零缓冲减原树换股 | −1.27 | −29.30 |
| 其中毛差 / 实付费差 | −21.53 / −20.26 | −64.30 / −35.01 |
| E1 Ridge 加 10 bp 缓冲减原 Ridge | +2.53 | −39.99 |
| E1 树加 10 bp 缓冲减原树换股 | −8.84 | −31.47 |
| E2 自然换仓减原 Ridge | +2.59 | +7.47 |

| E2 减原强制五席 | +0.20 | −3.63 |

E2 相对原 Ridge 的 95% 三月时间块区间为 [−7.22, +10.79] 和 [−28.57, +41.76] bp/月。两段各删最佳三月后相对原 Ridge 转负。历史支持继续观察自然买入预算，尚不足以升级模型。[所有主对照、机械对照、区间与删月](results/comparisons.csv)

E1 近 252 个已到期的历史信号日内，以合格截面内去均值的 H10 毛收益对去均值分数计算滚动最小二乘斜率。历史标签仅在其 H10 出场开盘已经发生时纳入。以候补和拟卖原仓的分差乘斜率及目标票面，比较该替换与保留原股票两种净额计划的费用；另九袖逾期卖单只用信号日已知的持仓、收盘价和交易状态估算。Ridge 使用 R 分，69 项换股使用树分。先配目标中新股分最高与旧股分最低的可比对，门槛未通过则保留旧股；不合格原股照常卖，尚无历史斜率时执行原无门槛计划。0 与额外票面 10 bp 两个规格全部保留。时间窗口和校准函数为本轮实现选择。机械臂按代码和日期哈希选择相同接受对数，独立历史仓会引起实际订单金额差异，按月披露实际换手差。[逐对预测和门槛](results/pairs.parquet) · [校准历史](results/calibration.csv)

E2 先读取同日原 Ridge 实际袖持仓，锁住原 Ridge 保留仓，并保护替换臂已持的原目标。只从原计划自然新买的股票移走树分最低者，将同笔权重分配给下一档中两本账均未持有、树分最高的股票；最多 floor(K/5) 席。每臂实际出售数量和资金随历史持仓变化。机械臂使用相同日期和席位预算并按可用对数封顶。原强制五席账户见 P2，逐笔保存预定金额与真实净单。[预算与席位](results/decision_counts.csv) · [实际订单](results/orders.parquet) · [净值与费用](results/daily.parquet)

在 EP41 目录，先生成 P2 的冻结评分，再用项目 Python 依次运行 `e1_e2/300/run.py` 和 `e1_e2/300/summarize.py`。两条无门槛基准与 P2 同名账户逐日一致；逐股实付费用合计核平每日总费用。此次历史回放结束于 2026-10-12。

E2 中原强制名单拟删、因自然买入约束而实际续持的原仓，按原 H10 端点核算，前段已知净毛损益 −0.00134，后段 +0.00676，单位为初始本金 1；其中上涨仓分别贡献 +0.10130、+0.03517，另有下跌抵消。候补实际换入金额分别 17.44 和 7.43，毛损益 +0.05993、+0.03918；被挤出的计划新买按票面估计的机会收益 +0.04832、+0.01730。不同路径资金规模与费用另见逐月表，这些部分项不可直接相加。运行 `attribution.py` 可由冻结目标独立重放并核对 E2 净值。[机会成本与实持损益明细](results/opportunity.parquet)

另在每个原始相位从同一实际期初账本复制，以相同计划单席金额和相同换股对数给真实门槛与机械顺位置单，两臂独立受实际成交约束。连续路径先复核原结果，再固定另外九袖的计划。E1 零缓冲真实筛选减机械筛选的本袖单期净差，Ridge 为 +4.10 / −1.90 bp/H10，树为 +2.62 / +5.30。E2 同金额净差 +3.71 / +19.25 bp/H10。该单期对照集中检查买入决策，连续十袖效应仍以完整月表为准。运行 `same_budget.py` 可核对每个起点、票面与资金是否严格配对。[共同账本结果](results/same_budget_summary.csv)
