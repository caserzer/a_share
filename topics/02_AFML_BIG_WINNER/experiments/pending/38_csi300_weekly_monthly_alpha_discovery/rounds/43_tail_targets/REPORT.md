# 训练模型避开十日左尾，真的能改善净收益吗

用原78项特征拟合两个季度滚动线性模型，分别预测同日股票随后十日落入末十分之一、进入前十分之一的指示量。对23个季度核对了训练行数与标签成熟日。用相同训练数据重做原收益秩模型，在已选股上的最大评分复现误差为6.53×10⁻¹⁶。两个新分数只用于改变原持仓的同行业内权重。真实尾部标签按有到期报价的当日全池定义，未用于下单。

| 避左尾相对收益秩等权，十起点平均 | 前段 | 后段 |
|---|---:|---:|
| 后来落入末十分之一的目标资金变化 | −0.63个百分点 | −0.65个百分点 |
| 后来进入前十分之一的目标资金变化 | −0.48个百分点 | −0.40个百分点 |
| 零费，每十日整组合差 | +1.93 bp | +0.57 bp |
| 标准费，每十日整组合差 | +1.03 bp | −0.46 bp |
| 双费，每十日整组合差 | +0.14 bp | −1.48 bp |
| 标准费超过等权的起点数 | 7/10 | 5/10 |
| 标准费相对只追右尾，每十日 | +4.15 bp | +2.98 bp |

避左尾确实小幅减少了随后跌入末十分之一的实际目标权重；同期也放弃了部分大涨股。标准费下，十起点平均最大回撤的改善只有约0.05／0.02个百分点。去掉各段三个最佳共同月，相对等权的剩余月均净差为 −0.95／−17.33 bp。这条规则有可复核的尾部暴露变化，缺少足够稳定的整组合净收益，不升级为前瞻候选。
