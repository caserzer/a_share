# 把训练收益期限延长一倍，能降低换手，但未改善同样本的选股

保持原78特征、季度扩展Ridge及沪深300最高十分组，比较原十日收益秩与二十日收益秩。组合均持有十个交易日。额外训练一条十日模型，在二十日模型所用的相同股票、信号日和成熟日期上拟合，区分训练目标与训练样本的作用。23个季度均复现原模型，评分误差小于10⁻¹⁰。

| 十起点等权平均 | 前段 | 后段 |
|---|---:|---:|
| 二十日模型双边换手／期初资本，每十日 | 124.8% | 130.6% |
| 原十日模型同口径换手 | 130.7% | 137.4% |
| 二十日减原十日，每十日标准费净差 | +1.03 bp | +0.69 bp |
| 同一比较，零费／双费 | +0.13／+1.92 bp | −0.33／+1.71 bp |
| 二十日减同训练样本十日模型，标准费 | −1.28 bp | −4.62 bp |
| 二十日减原十日，去最佳三个月后的月均净差 | −6.37 bp | −23.98 bp |

前段预测二十日收益的平均RankIC，二十日模型为0.0863，同样本十日模型为0.0817；后段则为0.0525与0.0556。二十日训练在前段改善过全池排序，持仓上的净差没有胜过控制模型。相对原E1的每十日净差前／后为 +8.08／+2.41 bp，相对同期收盘全收益指数为 +52.77／−7.33 bp。停止仅通过延长训练标签来改善十日账户。
