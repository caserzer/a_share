# 十批资金错峰执行的费用与回报

各起点用十分之一本金独立投资，仅在同一开盘、同一股票出现反方向净单时内部抵消，节省的费用留在现金。已逐日核对相同经济标的的开盘价格及合并费用，逐批用月度收益复利复现原终值。以下使用十批都完整覆盖的月份，区间开始时保留各批建仓后的资金差异。

| 整笔资金累计净收益 | 2021年2月至2025年1月，48个月 | 2025年4月至2026年8月，17个月 |
|---|---:|---:|
| 冻结行业候选 | +30.38% | +15.98% |
| 收益秩基线 | +29.87% | +15.69% |
| 原E1 | +18.79% | +17.10% |
| 动量行业池 | +29.54% | +16.84% |
| 沪深300全收益指数 | −21.34% | +24.13% |

行业候选对收益秩的月均差前／后为 +0.87／+1.45 bp。第38轮是各起点十日差等权，本轮是各批资产独立增长后按市值加总，再取共同日历月；两者分母和区间不同。后段行业候选累计跑输指数约8.16个百分点。

行业候选与收益秩前48个月各自抵消的单边金额都是原总本金的0.775%，相对各自区间初始资金，共少付约0.23 bp；后17个月均无可抵消成交。实际上不同起点的常规调仓分散在不同交易日，只有少数延迟卖单能遇上另一个起点的买单。停止以跨批净额执行解释行业候选的收益优势。
