# 连续指数权重快照中的非价格变化能否预示后续超额

使用信号日之前最近两个完整相邻自然月的沪深300权重快照，仅限此前已连续存在、两端有收盘价的成分。对每股计算新权重／旧权重／两端复权价格倍数；比较两家公司时指数总量因子消去。保留月度权重归档的公布时间未知、分红与股本变化可能影响解释的历史代理边界。按归档精度为每个权重赋予±0.0005个百分点误差，只有两家比率即使考虑两端误差仍分离才做调整。在每个指数权重五分组及当期一级行业内，从低比率向高比率移动两者较小漂移目标权重的一半。每个单元只选上界最低和下界最高的一对。对照在同一单元内选择两端复权涨幅最高与最低者，二者与信号使用相同资金（取两对四股最小权重的一半）。反向规则镜像同一笔调整。报告所有计划日、日期资金覆盖、三档成本、净差与去最佳月份检验。主要预测是正向比率账户同时优于漂移与同资金价格动量；不能将有效日期视作已核验的首次公开时间。
