# 左尾模型排除20日波动率后还剩什么

保持原选股名单和行业预算，在每个信号日先扣除已选股票中行业与20日低波动排名对避左尾评分排名的线性解释，再按剩余分数调整同行持股。20日低波动解释了行业内评分变动平方和的日均37.4%／41.8%。残差本身与去行业均值的低波动排名正交，再排序后的持仓仍可能暴露于波动风险。

| 十个调仓起点平均 | 前段 | 后段 |
|---|---:|---:|
| 实际未来左尾目标权重变化 | −0.387个百分点 | −0.390个百分点 |
| 实际未来右尾目标权重变化 | −0.326个百分点 | −0.342个百分点 |
| 对等权，每十日零费 | −0.07 bp | −3.08 bp |
| 对等权，每十日标准费 | −1.31 bp | −4.38 bp |
| 对原避左尾模型，每十日标准费 | −2.34 bp | −3.93 bp |
| 对单用低波动，每十日标准费 | −3.06 bp | −5.26 bp |

残差仍能减少后来大跌股票的目标资金，但也少持有后来大涨的股票。两个历史段扣费均落后；后段十个起点仅一个超过等权。停止把这部分残差作为独立选股信号。
