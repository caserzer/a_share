# 现有EP30原件抽取未能覆盖这项历史选股检验

从EP30第3、4版字段抽取结果中，按证券身份、公告编号、报告期和原件哈希配对收入与归母净利润。共找到1,738份没有冲突数值的字段对，全部属于年报。仅5份涉及本实验历史股票池中的4家公司。已有3份同时具备两个字段的页面复核记录，均不在本实验股票池。

即使将尚标为UNKNOWN/BLOCKED的候选也计作覆盖上限，并且只要求年报距决策在一年内、有可用日期，单日可覆盖资金也至多为0.126%。2021和2023的全年日均覆盖资金约0.03%和0.06%，其他年份为零。页级复核记录本身不等于独立人工认证。没有把原件候选加入模型；本地这两批抽取没有补足季度桥接和较早可知版本。下一步若继续验证利润率，需要面向当期沪深300成分与报告期获取首发财报，并先核验能形成同行对照的覆盖。
