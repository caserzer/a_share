# 同时要求少跌和多涨，能否保留左尾信息

保持第43轮的模型与持股，仅比较两套预测提供的信息。先在同行持股内分别排序，再把避左尾和追右尾的秩相加，希望挑出左尾少、右尾多的公司。相减作为偏向两端波动都低的对照。相加规则的实际作用资金前／后只有6.6%／6.4%，单用避左尾约13.8%／13.9%；两个评分在不少行业内抵消。

| 相加规则，十起点平均 | 前段 | 后段 |
|---|---:|---:|
| 真实左尾权重变化 | −0.037个百分点 | +0.002个百分点 |
| 真实右尾权重变化 | +0.092个百分点 | −0.032个百分点 |
| 相对等权，每十日零费 | −0.15 bp | −1.39 bp |
| 相对等权，每十日标准费 | −0.90 bp | −2.13 bp |
| 相对单用避左尾，标准费 | −1.93 bp | −1.67 bp |
| 相对两端波动偏低对照，标准费 | −1.87 bp | −2.62 bp |

前段微弱的方向区分在后段反转。后段10个起点仅1个超过原等权，剔除最佳三个月后，前／后剩余月均净差分别为 −3.77／−8.17 bp。若单独看两个尾部模型，历史上更容易识别高低波动倾向。将两侧分数合成后，未得到有经济价值的方向信号。停止用这对评分调配仓位。
