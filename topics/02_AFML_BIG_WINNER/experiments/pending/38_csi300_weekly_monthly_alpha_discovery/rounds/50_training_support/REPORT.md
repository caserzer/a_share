# 推迟季度训练截止日与剔除缺报价样本分别贡献了多少

第49轮的同样本十日控制表现较好。本轮把改动拆成两步。先仅用计划二十日也已到期的周样本拟合十日收益秩，保留所有十日收益已知的公司；再去掉这些周里第二十日没有可评价收益的公司。交易时各模型均对同一股票池评分。23个季度中，第一步每次少用最近2–3个周截面，第二步每季度从剩余训练档案去掉186–256条公司记录。

| 改动及标准费用结果 | 前段 | 后段 |
|---|---:|---:|
| 只推迟截止日，每十日配对净差 | +2.42 bp | +5.88 bp |
| 只推迟截止日，零费／双费 | +2.44／+2.40 bp | +5.79／+5.96 bp |
| 推迟后实际更改的目标资金 | 3.88% | 3.28% |
| 只推迟截止日，胜过原模型的起点数 | 8/10 | 8/10 |
| 再剔除缺二十日报价的训练股票，每十日增量 | −0.11 bp | −0.57 bp |
| 两项合计，每十日净差 | +2.31 bp | +5.31 bp |

推迟规则前段在991个信号日中的747日改动持仓；后段381日中264日有改动。按完整自然月汇总，前／后月均增量 +6.28／+12.50 bp，去掉各自最佳三个月后仍有 +2.17／+3.27 bp。三个月分块95%区间为 [−3.72,+14.86]／[+4.05,+21.47] bp/月。这一归因在观察过第49轮后提出，区间未校正历轮选择。两步配对差逐期相加精确还原组合差。改善来自推迟拟合样本截止日，缺报价过滤没有提供增量。依此固定规则跨更早时期复核。
