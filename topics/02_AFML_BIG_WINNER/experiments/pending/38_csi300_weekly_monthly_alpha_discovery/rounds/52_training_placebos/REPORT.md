# 推迟最近两三周与删除其他季度末同量周的对照

固定第50轮延后训练截止日模型。三个安慰剂仍拟合十日收益秩、保留最近已成熟周，转而删掉早一、二、三个季度末当时最近的同样数量成熟周。各控制独立拟合和逐日交易；三者平均值是配对比较量。所有季度的删除日期、行数和评分模型可回查。

| 延后训练相对哪一组，每十日标准费用净差 | 前段 | 后段 |
|---|---:|---:|
| 保留全部成熟周的原收益秩 | +2.42 bp | +5.88 bp |
| 删除早一个季度的周 | +3.61 bp | +4.55 bp |
| 删除早两个季度的周 | +3.90 bp | +4.57 bp |
| 删除早三个季度的周 | +3.05 bp | +4.18 bp |
| 三个安慰剂平均 | +3.52 bp | +4.43 bp |

对安慰剂平均，两段均有8/10个起点取得正增量；零费下为 +3.51／+4.35 bp，双费下为 +3.53／+4.52 bp。共同月内先对十个起点等权，删去三个贡献最高月后，剩余月均差为 +4.84／+0.69 bp。三个月分块95%区间为 [+0.95,+14.81]／[−1.27,+20.50] bp/月，后段的证据对少数月份较敏感。

2021年后的改善优于这三个等量历史扰动，但都是有限、预先指定的位置，不代表对所有可选删除方式进行过随机化检验。更早2019年的收益集中，2020年的全年敏感性重放未取得正增量。保留“最近训练周对个股排序的影响”这条研究线索，尚不能认定跨时期稳定，也没有新的前瞻预测。
