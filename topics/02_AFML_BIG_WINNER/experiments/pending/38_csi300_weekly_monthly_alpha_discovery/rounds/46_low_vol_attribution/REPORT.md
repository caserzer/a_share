# 单用低波动的历史优势是否值得前瞻升级

第45轮对照按过去20个交易日的波动给同行持股分配资金，本轮逐笔复用原账本。前后两段的正常费用均值为正，但后段双倍费用下转负，删去最有利三个月后两段均转负。

| 十个起点等权 | 前段 | 后段 |
|---|---:|---:|
| 每十日相对收益秩，正常费用 | +1.75 bp | +0.88 bp |
| 正增量起点数 | 7/10 | 6/10 |
| 零费／双费，每十日 | +2.73／+0.77 bp | +1.92／−0.15 bp |
| 共同完整月，月均增量 | +4.54 bp | +0.81 bp |
| 三个月日期分块95%区间 | [−3.46,+11.77] bp | [−17.56,+19.17] bp |
| 去最佳三个月，月均增量 | −0.38 bp | −15.07 bp |
| 指数上涨月，月均增量 | +1.47 bp（21个月） | −14.22 bp（13个月） |
| 指数下跌或持平月，月均增量 | +6.93 bp（27个月） | +49.66 bp（4个月） |

后段保护集中于少数市场下跌月份，以该月指数涨跌分组属于事后归因。月主动收益对指数收益的回归斜率前／后为 −0.001／−0.059，截距分别为 +4.49／+8.96 bp/月，后段只有17个共同月份。最大回撤相对等权在前段平均加深0.04个百分点，后段平均减轻0.69个百分点。

各完整月的逐股损益差已逐一核回组合月差。前段最有利三只为SH600745、SH601633、SH600999，最不利为SZ300274、SH688012、SH601318；后段最有利为SH601127、SH603392、SZ300450，最不利为SH601669、SZ300502、SZ000657。保留低波动作防守特征参照，不另立选股候选。
