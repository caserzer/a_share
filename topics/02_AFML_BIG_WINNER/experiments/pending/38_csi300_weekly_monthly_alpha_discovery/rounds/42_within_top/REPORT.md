# 原模型的前十分之一持仓是否应继续按分数加权

保持收益秩模型选中的全部股票和一级行业预算，在每个行业内部多配模型评分较高的已选股。十个调仓起点都用独立账户，E1评分在同一份名单上的线性倾斜构成消融。各腿用相同开盘、买10／卖20基点及到期规则核算。

| 十起点平均 | 前段 | 后段 |
|---|---:|---:|
| 实际调整的目标资金 | 13.8% | 13.9% |
| 同行业加权相对等权，整组合十日事件毛差 | −0.31 bp | −2.99 bp |
| 零费连续账户净差，每十日 | −0.65 bp | −2.96 bp |
| 标准费连续账户净差，每十日 | −1.63 bp | −4.04 bp |
| 双倍费用，每十日 | −2.60 bp | −5.11 bp |
| 标准费超过等权的起点数 | 3/10 | 0/10 |
| 标准费相对同行业E1评分倾斜，每十日 | +0.16 bp | +1.07 bp |

更换为E1评分没有挽救这个分配思路。集中在十日事件换入换出均可成交的共同报价上时，毛差仍为负。十相位对收益秩共同月的月均净差前／后为 −3.30／−8.54 bp；剔除最佳三个月后分别为 −5.83／−17.81 bp。当前全池评分进入最高组后，继续对同业高分股票加码没有历史经济支持。停止组内线性加码。
