# 行业换股的相对强势主要出现在哪一段

固定八个新增调仓起点，将行业候选实际换入与换出的股票作等预算比较。前段各起点平均改动2.4%的组合资金，后段约3.4%。在信号前十个交易日，两段的换入股都已经领先；实际能下单后，整十日差接近零。

| 价格区间 | 前段，整组合预算 | 后段，整组合预算 | 前段，仅主动资金 | 后段，仅主动资金 |
|---|---:|---:|---:|---:|
| 信号前10日至信号收盘 | +3.41 bp | +1.51 bp | +141.43 bp | +49.26 bp |
| 信号收盘至下一开盘 | −0.02 bp | −0.18 bp | −0.74 bp | −5.22 bp |
| 入场开盘至第五个交易日后的开盘 | −1.15 bp | −0.53 bp | −44.87 bp | −17.51 bp |
| 随后五日开盘至开盘 | +0.92 bp | +0.56 bp | +39.39 bp | +18.34 bp |
| 买入后完整十日 | −0.19 bp | +0.02 bp | −3.98 bp | +0.84 bp |

逐相位先计算再等权平均。整组合列使用目标持股的实际资金比例，计入无换股日的零贡献。主动资金列在有完整价格与成交门控的换股日，按换入预算归一。八起点共1096个窗口，前段有2个发生换股的窗口因端点或门控不足留作未知，后段全部可评价。各区间分别归一，两个五日差不能简单相加。个股事件代理未扣费，与第38轮连续账户零费结果可有差异。

这是对选股时序的描述。信号形成前的领先可能直接来自行业目录的价格输入，不能登记为策略收益。第一段回吐、第二段回升是否值得实际延迟下单，需要计入新交易与期间持仓。
