# 第十二轮：指数底仓中可转移多少负向公告资金

第十一轮受原 D10 持股交集限制，仅得到主段25笔、后段2笔。把机制放到更广底仓，先做事件级资金可行性核算。每个交易日收盘的负向公告反应及同行匹配沿用第十轮。事件次日开盘转移最近一期历史指数权重的一半，指数权重快照严格早于事件日，不早于60个自然日；源股和替代股同时仍是成员。任何时点允许占用的入场名义权重总和不超过5%，同日超额同比例缩减。同一源股未归还前不得重复使用。十日后同一开盘卖替代并买回原股，如受阻延至首次两边均可成交开盘。入场须能卖原股且能买替代股。重放两档费用并核算完整卖／买／卖／买四笔费用，双倍费用保持相同选股和权重，源股、同行均按复权开盘计价。结果为各笔对单位底仓的边际损益，月末指数权重是历史代理，未建立逐日整指数持仓现金账本，不能把各事件贡献之和当作整账户净年化。退出未知保留标记。旧研究覆盖至2026年4月30日之后，仅等待已进入事件到期。先看早、主、后段能否都付清往返成本，再决定是否扩大到账户。
