# M05：候选与在池观察竞争优先级

2026-11-12，任何M05重放前登记。依据早期窗口审计，原日期组合有194个父过程曾在及时窗口进入可用候选前5但受当时池空位限制。该数不代表可恢复机会；绝大多数遗漏是排名限制。本轮只回答池维护是否存在局部可改进之处。

## 固定与唯一变更

固定M02日期权重BALANCED评分及ORIGINAL20动量评分、全目录、准入、E02B标签、每周新增≤5/在池≤20、8周上限、两周弱势及断链退出、4周冷却。无重新拟合或参数搜索。保留两种评分各自原池规则，并增加竞争维护版，共4臂。

当周先按原规则处理强制退出。为每个存续在池行业计算当日同一种排序分数：若当日满足对应准入，使用已冻结评分；若有完整价格支持但不符合准入，优先级低于所有准入候选，明确记为当前缺少准入证据，而不是缺失分数填零。数据不足依原规则退出。

将存续池与满足准入且不在冷却的新候选一起按当日分数降序、行业代码升序排序。新候选只有处于联合前20才具备竞争资格。每周最多从具备资格的新候选中选5个；超过普通空位时，淘汰联合排名最低的存续观察，淘汰数恰等于新增数减空位数，不能无替补清空旧池。竞争退出进入原4周冷却。新候选分数与在池比较只用当日值，不比较跨年或历史保存分数。

先决定替换再发出事件；退出的行业当周不能再UPDATE并获取首次覆盖，防止同时享受旧池更新与新池提示。保留所有退出原因及完整前后池状态供审计。父/子未来标签和事后遗漏不得进入调度。

## 比较设计

四臂：ORIGINAL20_STATIC、ORIGINAL20_COMPETE、BALANCED_STATIC、BALANCED_COMPETE。独立运行每臂5/20，无额外确认。另做共同日期1/3/5新增上限的四臂逐周等新增负担：各臂计算当周可入人数，取共同最小值，再执行各自准入与必要替换。STATIC可入人数受空位限制，COMPETE受联合前20候选数限制。不新增确认档，以保持本轮单一池机制问题；旧等待实验仍保留。

共16条重放，无任何参数扫描。主比较独立5/20与配对5/20，次档完整报告。主要对照每个评分的COMPETE减STATIC及BALANCED_COMPETE减ORIGINAL20_STATIC。13周共同块、2000次、种子34105。全4540父/458子分母，不因替换变更分母。

## 必须报告与停止

覆盖、及时、迟到、提示质量/未知、父子分别计数、首次覆盖来源、时差、全部目录状态、负担、替换次数、重复/重入及年度/状态/市场分层。列出竞争版新增覆盖与原版独有覆盖的过程名单，解释哪些旧池跟踪损失抵消收益。对独立NEW完整跟踪20/60/90/180日，但不据此选规则。

容量减少阻塞不等于预测能力增强。同负担与独立运行都要成立才可讨论实用增量，不将额外新增的覆盖全归因于排序质量。没有共同改善则停止，不搜索替换差值、最短持有、优先级混合或阈值。历史重用和行业相关性限制不变。
