# EP34：全行业价格回暖与升温观察方法研究

创建日期：2026-11-11。修订日期：2026-11-12。  
状态：目标修订与核对阶段。当前20日动量观察基线及历史结果保留；原业务目标尚未充分实现。


## 一句话目标

仅使用现有本地数据，在全部可研究申万三级行业中，通过简单规则和简单模型，**提高真实价格改善过程的整体观察覆盖，并尽早发现刚出现、尚未充分确认的回暖或新增升温迹象**；在可管理的研究负担下，为后续行业研究分配注意力。

## 一、业务目的

行业太多，用户无法逐项持续跟踪。观察方法应帮助用户发现：

- 哪些此前弱势的行业，正在出现值得核查的初步改善；
- 哪些此前已不弱的行业，正在出现相对于原趋势的新增强；
- 哪些已有观察需要继续跟踪，哪些已经中断或失效；
- 哪些变化尚不确定，需要保留观察，而不能直接下结论。

提示可以发生在持续性尚未确认时，允许其中一部分最终只是短暂反弹。但必须提供当时依据、未知事项、后续观察重点和失效条件。

价格变化是进入研究流程的线索，不直接确认订单、盈利或产业景气改善，也不等同于买入建议。

## 二、共同主目标与必要约束

### 共同主目标

1. **提高整体覆盖**：让更多真实、可评价的价格改善过程进入有效观察视野，减少遗漏。
2. **尽早发现**：尽量在变化初期提供有依据的提示，减少价格已经明显走强后才发现的情况。

两者必须同时评价：

- 总覆盖提高，但新增覆盖主要来自迟到提示，不能直接称为整体改善；
- 提示提前，但覆盖明显下降或误报大幅增加，也不能直接称为整体改善；
- 出现取舍时，完整报告收益与代价，不用单一综合分数替用户决定。

### 已确认的观察负担

- 每个自然周最多新增 **5个唯一行业**。
- 同时在池最多 **20个行业**。
- 允许少提示和空池，不强制填满。
- 更新、退出、重新入池及重复提醒的工作量另行统计，不通过改名绕过容量约束。

### 提示质量约束

用户此前提出“希望至少约一半提示有效”。本轮保留其作为质量参考，具体操作口径和是否作为硬验收线须在实验前核对。

- 不将当前约88%的历史过程匹配率作为新方法必须维持的基准。
- 不因追求早期提示而取消质量评价。
- 不通过缩小分母、将失败改为未知或放宽成功定义满足质量参考。
- 尚未确认新的最低覆盖率、提前天数或置信区间下限，不虚构用户已确认的数值。

## 三、识别对象

### 回暖

此前弱势或下行的行业，开始出现可观察的初步改善，例如下跌幅度收窄、止跌、低点逐步抬高或初步向上运行，并在后续路径中形成可评价的持续改善。

不要求提示时累计收益已经转正，也不要求行业已经进入涨幅排名前列。

上述现象是待检验的候选证据，不直接规定为最终入池条件或成功标签。

### 升温

此前已不弱的行业，出现相对于原有趋势的新增增强过程。

不能仅因行业已经强势、累计涨幅较大或持续占据排名前列，就重复认定发生了新的升温。

### 必须保留的对照类型

- 短暂反弹后重新走弱；
- 初步改善但未形成持续过程；
- 持续改善已经成立，随后发生中断；
- 已经明显上涨后才发出的迟到提示；
- 已在跟踪但没有新增变化的重复提示；
- 存在改善，但被排序、准入或容量遗漏；
- 数据不足、分类断点及观察期未成熟。

允许这些情况具有不同业务意义，不将其全部压成一个成功或失败数字。

## 四、当前方法的定位与历史结论

当前方法要求近5日、20日收益均为正，并按20日涨幅排序，本质上是**动量观察基线**。

它的历史过程匹配、容量及覆盖结果可以保留，但不足以证明已经实现“提高整体覆盖、尽早发现初期变化”的完整目标。

因此：

- 保留20日动量方法作为主要对照。
- 撤回此前原业务目标已完成的结论。
- 用户曾选择20日排序，表示对已有方案的取舍，不等于将业务目标改为追踪强势行业。
- 高过程匹配率不等于早期发现准确率，也不等于提示后上涨概率。
- 所有旧目标、协议、实验、失败结果和封存产物保留，不追认旧失败为成功。
- EP33半年上涨与超额收益目标及失败结论保持原样，不迁移为本任务验收标准。

## 五、范围与数据纪律

1. 以全部现有可研究申万三级行业为主要目录，不以事后成功行业或固定少数行业定义有效性。
2. 分类制度分别处理，保留身份变化、价格链和分类断点。其他层级可以提供背景，不混为独立机会重复计数。
3. 只使用现有本地可读取数据，允许历史代理和部分缺失，明确数据版本、截至日期及当时可得性限制。
4. 不把缺失记作零，不把未知记作无机会、无信号或失败。
5. 提示、更新、退出及模型特征只能使用当时已知信息；未来完整路径仅用于标签和评价。
6. 基本面和事件解释属于后续研究，不因相关资料缺失阻断价格观察，也不由价格上涨反推出经济原因。
7. 本目标不授权新增外部采集、交易、部署、发送报告或对外发布。

## 六、先对齐评价对象，再训练模型

必须区分以下对象：

- **当时可观察的价格迹象**：用于形成提示依据。
- **事后可评价的持续改善过程**：用于判断是否真实覆盖了值得观察的过程。
- **用于模型学习的训练目标**：必须与业务目标对应，并明确其与最终评价对象之间的关系。

不得用同一个候选信号阈值同时定义入池条件和成功标签。

### 独立过程定义

过程定义须独立于方法选中的名单，覆盖全目录所有可评价日期，明确：

- 此前状态；
- 改善幅度及持续性；
- 回撤、反复和中断容忍；
- 参考起点、首次可辨阶段及确认时点；
- 起止边界、相邻过程合并和嵌套增强；
- 分类跨界、左删失、右端未成熟及数据不足。

定义应同时容纳温和持续改善和较快改善，不能默认只有固定期限内大涨才值得观察。

### 标签与业务语义核对

在训练或比较方法前，用不依赖候选名单的分层案例检查定义，至少覆盖：

- 弱势中尚未累计转正的改善；
- 温和但持续的改善；
- 强势中的新增增强；
- 短暂反弹；
- 改善后中断；
- 迟到提示；
- 已有观察捕获新变化；
- 数据不足与边界不确定。

案例用于检查定义，不用于证明方法有效。

已有过程定义优先复核和复用。若发现语义错误，必须先说明具体问题、保留旧版、登记修订，再对全部方法统一重评；不能根据候选成绩挑选更有利的标签。

## 七、评价必须分账

主单位为**行业价格改善过程、唯一新增提示和实际观察工作量**，不得用重复行业周抬高成功样本。

| 评价账目 | 必须报告的指标 | 约束 |
|---|---|---|
| 整体过程覆盖 | 得到有效观察覆盖的过程数／全部可评价过程数；遗漏数量及比例 | 分母独立于准入、排序和提示名单 |
| 及时与迟到覆盖 | 及时覆盖、迟到覆盖及各自占完整分母的比例 | 不用迟到补及时，也不把迟到等同于从未发现 |
| 新增与持续跟踪 | 新增提示贡献、已有观察更新贡献及去重并集 | 单纯占位不算覆盖，必须有对应该变化的当时证据 |
| 提示质量 | 成熟可评价唯一提示的有效率；短暂反弹、无效、重复、未知及未成熟数量 | 有当时依据不自动等于有效；未来偶然上涨不能补造依据 |
| 识别时机 | 相对过程参考阶段的时间差、提示前已有涨幅、确认前提示比例及确认等待时间 | 报告分布与尾部；参考时点不进入信号 |
| 提示后表现 | 新增绝对与相对价格表现、延续、中断、回撤及成熟状态 | 不把提示前涨幅算作提示后成功，不替代过程覆盖评价 |
| 观察负担 | 每周新增、并发在池、更新、退出、重复与无效提示数 | 报告中位数及高负担周，同时满足5/20约束 |
| 覆盖与稳定性 | 目录与可评价数据覆盖；年度、回暖／升温、市场环境及行业相关性分层 | 保留失败时期和数据困难行业，不选择性删样本 |

“及时发现且后续持续改善”可以作为明确命名的联合指标，但必须同时展示其组成部分，不能独占“覆盖率”或替代完整评价。

市场普遍反弹中的行业改善，与行业特有改善分开报告，不能将前者直接解释为独立行业选择能力。

## 八、归属、重复与首次提示

- 每个过程在覆盖分子中最多计一次。
- 每次新增提示至多匹配一个主过程。
- 父过程与新增增强分别报告，不简单相加为独立机会。
- 首次误报继续计入提示质量和工作量，不能被后来的成功删除。
- 首次误报或未知，不永久取消过程后来被有效发现的资格；后续有新证据时可以取得一次覆盖，时机据实记录。
- 已在池行业不自动算作新过程被发现，也不因没有再次入池就自动算遗漏。
- 退出后重新入池、跨边界、左删失、重复提醒及未知归属单列。
- 原始提示、更新、退出和重入记录完整保留，不事后挑最有利的一次改写历史。

## 九、简单模型研究要求

本任务需要开展简单模型训练与比较，但**训练完成不是目标完成，最终方法也不强制使用模型**。

### 拟研究的模型

优先研究少量可解释、复杂度受控的模型，例如：

- 正则化逻辑回归；
- 浅层决策树。

具体模型、特征、参数和训练目标在实验协议中冻结，不在目标阶段无依据扩展模型清单。

### 模型要解决的问题

检验此前价格状态、近期变化及其他有依据的候选信息，能否帮助：

- 在弱势行业中区分初步回暖与短暂反弹；
- 在已不弱行业中区分新增增强与原有强势延续；
- 在固定观察负担下，提高覆盖并改善发现时间。

不能训练一个复制涨幅排名的模型，再因名称不同宣称解决了新问题。

### 必要对照

至少保留：

- 当前20日动量基线；
- 不使用模型的简单规则；
- 只使用基础价格／动量信息的模型；
- 增加候选信息后的模型。

区分信息增量、模型组合能力、准入改变和观察池规则改变。一次比较不能同时改变多项因素后，将全部改善归因于模型。

### 训练纪律

- 按时间顺序训练和评价，不随机切分制造验证。
- 每个训练时点只使用当时已成熟、可判定的标签。
- 特征处理、缺失处理、标准化及参数选择只能使用对应训练数据。
- 对重叠标签、未结束过程、分类断点及标签修订明确处理，防止未来信息泄漏。
- 行业身份、日期或事后过程编号不得成为记忆历史答案的捷径。
- 若输出未经校准，只称观察分数或证据等级；若使用概率，须明确预测对象并单独检验校准。
- 反复研究过的历史称历史模拟，不能称独立样本外验证。

## 十、比较与验收原则

比较必须同时呈现：

1. 同日期、同可用数据范围、同新增负担及相同并发上限下的覆盖、及时性和提示质量。
2. 不同质量水平下可实现的覆盖与及时性；没有实际共同点时明确无法直接比较。
3. 更早提示带来的误报、后续中断及跟踪负担。
4. 等待更多确认造成的延迟、遗漏与质量变化。
5. 准入母体改变、模型排序改变和观察池规则改变各自的影响。

不能只优化F1或单一综合分数，掩盖“几乎不提示”“大量噪声”或“主要是迟到覆盖”。

具体评价窗口、训练标签、最低样本支持、质量参考操作口径及统计方法，须在方法比较前登记。不能看到结果后放宽、更换或追加有利标准。

数值尚未确认时，可以报告研究发现，不能自行宣布业务验收通过。

## 十一、最小研究顺序

### 第一阶段：目标与协议对齐

核对本目标，复核既有过程定义及失败证据，明确共同主目标与质量、负担约束。

交付业务问题、评价对象、分子分母、匹配规则、成熟条件和正反例的对应表。区分用户确认事项与研究假设。

### 第二阶段：建立可训练的数据与简单对照

检查特征当时可得性和标签成熟性，明确训练样本覆盖。

保留当前动量基线，建立少量有明确依据的简单规则。已有失败分支只有在存在不同信息依据或必要遗漏比较时才能重启。

### 第三阶段：训练简单模型并比较

按冻结协议训练简单模型，进行时间顺序历史模拟。

首先报告整体覆盖、及时性、提示质量和负担，再解释模型特征、年度表现及失败类型，不只展示最优模型或最有利时期。

### 第四阶段：冻结观察规则与复核

只有在证据支持后，才冻结特征、模型或阈值、复核周期、入池、更新、退出、重新提示及身份规则。

完成全目录逐期清单、跨时期核查和版本化持续评价。若简单规则更好，则采用规则；模型无增量则保留失败结论。

## 十二、观察清单交付

逐期覆盖全目录，明确区分：

- 新入观察；
- 持续跟踪；
- 退出或失效；
- 暂未触发；
- 数据不足。

每行至少提供：

- 行业身份、数据截至日期、规则与模型版本、唯一观察编号；
- 当时触发理由、此前状态、绝对和相对价格变化、已有涨幅；
- 模型分数或证据等级及其含义；
- 首次提示、当前更新、新增变化与重复旧信息的区别；
- 失效条件、未知事项及需要进一步核查的问题。

事后过程编号、最终标签和后验评价另存，不伪装为提示时已经知道的信息。

逐期汇总新增工作量、在池规模、更新负担，以及标签成熟后的覆盖、及时性、提示质量和后续表现。

## 十三、每轮反思与停止条件

每轮执行：

**业务问题 → 假说 → 事前计划与可行性 → 最小实验 → 完整结果 → 反思 → 下一步。**

反思必须回答：

- 是否让更多改善过程进入观察视野？
- 是否在变化更早阶段发现，而不只是匹配到已发生的上涨？
- 覆盖提高是否只是多报，质量提高是否只是少报？
- 提前发现付出了多少误报和跟踪成本？
- 改善来自新增信息、模型组合，还是准入与容量变化？
- 回暖与升温是否都得到改善，还是只对其中一类有效？
- 是否存在年度、市场环境或行业聚集导致的表面优势？

只剩无理由更换窗口、阈值、权重、模型或成功定义时，停止该分支。不得因自动续行无限生成实验。

未找到有效方法时，如实交付适用范围和失败边界，不转成半年收益筛选，不以重新命名指标宣称完成。

## 十四、完成边界

完整目标完成需要：

- 独立、可复核且符合业务含义的过程定义；
- 明确的训练目标、成熟规则和防前视检查；
- 冻结的量化评价与比较协议；
- 简单规则和简单模型的完整比较；
- 全目录、跨时期及不同市场环境下的证据；
- 在5/20容量内，对整体覆盖与尽早发现有实际支持的观察方法；
- 对质量、遗漏、迟到和跟踪成本的完整交代；
- 逐期观察清单与持续评价机制。

**仅有目标文本、模型训练完成、代码检查通过、高过程匹配率、单项指标改善或某段历史表现突出，均不构成目标完成。**

最终应能回答：

> **在同样的注意力预算下，这套方法是否让用户看到了更多真实的行业价格改善，而且更早看到；为此付出的无效观察成本是否可以接受？**
