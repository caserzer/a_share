这是本地历史模拟交付，最新完整复核日为 **2026-10-16**，数据版本截至2026-10-21；不是2026-11-12当天信号。没有部署、交易或对外发送。

## 从哪里开始

- [早期候选最新全目录](early_model/latest_full_directory.csv) / [最新20个在池行业](early_model/latest_pool.csv)。
- [动量候选最新全目录](momentum/latest_full_directory.csv) / [最新20个在池行业](momentum/latest_pool.csv)。
- 各目录 `periods/YYYY-MM-DD.csv`：343个有支持复核期，每期全目录，分别227或347个行业。
- `all_period_catalog.parquet`：每个候选107141条完整行业日期记录。
- `event_history.parquet`：所有新增、更新、退出，含稳定观察编号、首次提示、重入关联。身份切换时退出的旧行业可能已不在新目录，但退出仍在事件账保留。
- `weekly_workload.csv`：新增、跟踪、目录状态及完整退出计数。5个分类衔接未知周工作量为未知，不填0。
- [冻结方法和字段](METHOD.md)、[持续评价规范](MONITORING.md)、[核验结果](delivery_audit.json)。

后验结果另存于 `../../outputs/v3_candidate_evaluation_20261021/`：完整父子过程、事件评价、按提示周分组的截至末日有效率和20/60/90/180日后续路径。这里的历史周质量是截至数据末日才知道的结果，不是当周已知成绩。

价格提示是后续行业研究入口。模型分数不是上涨概率，退出也可能仅是注意力优先级下降，不能直接解释为基本面失效。
