# S02 完整过程存续期重复提示核算

2026-11-11，结果计算前登记。已有主结果和 S01 已知，本项是补齐遗漏的描述性归因，不是新信号实验，也不改变任何成功、失败或一对一匹配。

对每个既有版本的全部唯一 NEW，按交易日、观察 ID 排序。关联同分类制度、同行业，满足过程起点 ≤ 提示日 ≤ 过程自然终点的所有已登记过程。保留全部重叠关联，不用收益挑选过程；同一提示在统计中只计一次。没有关联只称“无已登记存续过程参照”，不得记成不存在机会或提示失败。过程起点前提示不属于此存续期诊断，原及时评价保持不变。

若同一过程已有更早的不同 NEW 观察 ID，后续 NEW 为该过程上的重复新增。记录所有前次 ID、距离起点是否超过 60 日、首次与前次提示日。已知起点过程的重复和仅左边界未知过程的重复分开；右删失单列，既有区间可作描述，但不声称寿命完整。若提示同时关联新过程与旧过程，明确列出混合情形，不将其整体判为无价值重复。按 family 折叠另报，不能把同 family 的新增强过程直接判失败。

分母展示全部唯一 NEW、具有已登记存续过程参照的 NEW，以及逐过程关联行数。报告重复 NEW 数及占全部 NEW 比例、超过起点 60 日的重复、混合新旧过程、左边界未知、右删失、重叠关联；不把关联行数当机会数。

对有运行状态池的 R01 主档、容量和延迟档，另核查同制度同行业后续 NEW 之前是否存在上次观察的 EXIT，区分 UPDATE、未知暂停、分类边界退出。R02/R03 仅信息对照，不声称具备退出后重入状态；其运营字段标为 NOT_MODELED。

输出逐提示、逐关联和汇总及输入哈希。验证唯一观察 ID、时间顺序、区间包含、不同 ID、无跨分类关联、计数守恒；容量 5 档及延迟 0 日必须复现主档关联和汇总。主结果封存只读。该诊断不说明重复必然无用，不增加准确率或召回成功数。
