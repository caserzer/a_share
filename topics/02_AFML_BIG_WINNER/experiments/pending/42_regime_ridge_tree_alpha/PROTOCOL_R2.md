# EP42｜绝对量纲、市场状态与 Ridge／树的选股收益

2026-11-27 登记，当前为**修订2，已登记，待执行**。本轮接续 EP41，覆盖 A1–A5、D1–D6、S1–S5 和 G1–G7，共 **23 个一级编号**。D1–D4 下设 **22 个必须逐项交付的子实验**，分别为5、3、3、11项。D5 是预先指定的主要账户检验。各方向可独立推进，机器登记册保留每个子项的状态。[方向1–4逐项执行表](D1_D4.md) · [机器登记册](config.yaml)

## 要回答什么

1. 树在一天里可以用绝对波动、价格位置或相对成交额区分股票。当这些特征的全市场分布一起移动时，进入同一叶子和进入前列的股票是否也会系统变化？保持个股排序、缺失和股票构成时，这部分变化能解释多少费后收益？见[绝对量纲 S1–S5](ABSOLUTE_SCALE.md)。
2. 仅使用下单前可见的市场信息，可否判断当前哪种选股方法更合适？把同一对 Ridge 与树以随状态变化的权重混合，能否持续胜过从相同历史学出的恒定权重？见[主要实验 D5 和状态实验 G1–G7](MARKET_STATE.md)。
3. 头部排名、买卖两端、特征和交易费分别贡献多少？哪些其他候选仍值得独立检验？见[五项盈利归因](ATTRIBUTION.md)和[六个原方向的登记入口](CANDIDATES.md)。

EP41 的69项原值树胜过两种秩化输入，纯树相对 Ridge 的收益也曾在两个历史阶段变号。秩化会同时改变绝对尺度、股票间距和有效样本。历史阶段本身还混有股票构成、行情和交易机会的变化。本登记把这些解释视为待验证假设。EP41 使用2021年初至2026-10-12的历史账户，注册晚于回放终点。[EP41 模型结果](../41_csi300_csi800_weekly_monthly_alpha/models/REPORT.md) · [EP41 总报告](../41_csi300_csi800_weekly_monthly_alpha/REPORT.md)

## 共用账本与验收口径

- **样本和时钟。** 主池使用信号日历史沪深300合格股。中证800及其非300部分仅在指定实验中使用。信号取交易日收盘时已知的数据，下一交易日开盘执行，H10 标签取入场开盘到十个交易日后开盘的收益。每个季度使用扩展的历史训练窗，以周样本训练，只接收出场开盘严格早于该季度起点的标签。保留可选但后来缺标签的股票。时点无法认证的输入标记为历史代理，缺失的未来价格、公告或信息值保留未知。[继承的历史账户规格](../41_csi300_csi800_weekly_monthly_alpha/config.yaml)
- **机会与资金。** 基线为冻结的78项收益秩 Ridge 和69项原值纯树。新训练和新数据单列臂。沪深300目标席位为当日合格数除以10向下取整。除明确的事件资金账户或预算实验外，各臂维持同席位、同初始本金、十份错峰、同股净额收费，买10 bp、卖20 bp，保留实际交易限制、公司行动、现金与遗留持仓。指数用全收益收盘端点，另列同池等权、原 Ridge 和登记的直接对照。800有估值缺口时独立起账，不拼接净值。
- **账户产物。** 每臂保存逐日分数、状态及可用时间、目标、成交、现金、毛损益、费用和净值。费后策略主量为相同完整月份的平均配对净差，单位 bp/月；月初分母须为同账户段的上月末净值。另报各段及逐年净收益、相对基准差、最大回撤、剔除本段最佳三月、双费情景和实际触及资金额。状态或事件归因的每笔投入、席位数、比较日期数和整账户分母分别列示。日频、十个起点及200条随机路径有重叠，按时间而非席次估计不确定性。
- **推断。** D5 预定一次主要比较。沪深300沿 EP41 的前后两段，段内以相邻三个月移动块做10,000次成对重抽，固定种子4201，跨段按共同完整月数加权，报告双侧95%百分位区间。历史正向候选须同时满足两段费后点差同向为正、汇总区间下界大于零；删除最佳三月后反号或状态覆盖不足，报告为集中或未辨明。并列纯 Ridge、纯树的绝对收益和差值，防止虽胜静态混合却跑输单模型时误报策略改进。其余22项为归因或探索，报告所有已登记臂。确需对一组次级变体给显著性判断时，按该编号预列的全部同类比较作 Holm 校正，保留原始区间；探索结果不能递补 D5。
- **执行顺序。** 优先核对冻结分数、参考账户和状态时钟；S1、S2、G1、A1、A2可并行。D5 的模型、状态和主要比较已在本版固定，不从 S/G 结果中挑选。G2–G7用于追问机制，A3–A5与其余方向按各自输入条件推进。条件项缺数据或核账不合时留下覆盖数及原因，无须换一套规则补结果。
- **历史与前瞻。** 2018–2020年的早期折、2021–2026年的历史和已研究过的800子域均有研究使用记录。历史实验开始前留存输入、实现与配置哈希；后续变更另记版本。前瞻从对应版本首次在入场前实际封存分数、状态、权重和目标起算，结果在标签成熟后追加。12、24个不重叠成熟H10是前瞻复核点。本次交付为登记文本，没有新增回测或前瞻样本。[前序时间边界](../41_csi300_csi800_weekly_monthly_alpha/GOAL.md)
