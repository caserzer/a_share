# EP42 修订2｜方向1至4的逐项执行表

登记日为2026-11-27。下列22项全部进入执行范围，每项各留一行状态、证据路径和结论。共享模型、交易时钟和资金口径见[原方向协议](CANDIDATES.md)与[总登记](README.md)。D1–D4可与市场状态研究并行。D5 的收益、A2 的方向以及同组其他子项的阳性结果，均不构成启动前提。

执行时逐项核对列出的比较。账户项给出各历史段共同完整月费后差、区间、实际换入资金和费用；概率审计给出逐季度验证结果。多种窗口、席数、来源或持有期在同一子项内分行，保留零触发、负值及缺失。若所需时点、模型或数据不齐，记录具体缺口、覆盖和仍可完成的比较；“仅覆盖审计”“未触发”“账户已完成”分别记账。目录层级为23个一级编号，以下是其中 D1–D4 的子项。

## 方向1　只调整原计划自然新买的股票

在同日原 Ridge 的自然新买名单上实施。锁住原续仓，按同一目标资金、成交约束和后续持有期比较树低分、Ridge 边界及等数随机剔除。逐席区分取消一笔拟买与实际卖出。买不到合格替代时保留原买单。

| 编号 | 实验 | 直接对照与核查 |
|---|---|---|
| <a id="d1-1"></a>D1.1 | 冻结69项树剔除低分新买股，分别跑1、2、3席，以2席为主。 | 固定同一批顺位补入股，比较树剔除与 Ridge 边界剔除。另报同日随机剔除和原 Ridge。补入池为 K+1 至 2K。 |
| <a id="d1-2"></a>D1.2 | 单独检验候补池宽度和树分保护线。 | 在固定2席剔除下做四格：补入范围为 K+1 至 K+3 或 K+1 至 2K，各自开关树分大于当日池内第30百分位的条件。报告筛完后可补席数、同额资金与未能替换比例。 |
| <a id="d1-3"></a>D1.3 | 检验浅层早停树能否更好地剔除新买股。 | 只换剔除分数，固定顺位买单。深度3、按历史内折早停的做法与原69项树比较，按 G2 的成熟时间重建；比较实际换股名单和扣费后差额。 |
| <a id="d1-4"></a>D1.4 | 检验180日市值、成交额安全垫及已公告的调出。 | 以同日历史300成分为参照，将过去180个交易日平均自由流通市值和成交额均在末10%的候补标为边缘股，比较跳过与原样补入。另列仅跳过信号收盘前已公开调出公告的一臂。代理、已公告与事后出池各自统计；缺字段保留原顺位并计数。 |
| <a id="d1-5"></a>D1.5 | 重放原提案的联合规则。 | 用原树剔除2席，限定 K+1 至 K+3、树分超过30%分位，再用 D1.4 的180日代理检查候补。对比原 Ridge、仅剔除和去掉每项条件的账户；另列最大1席、3席。各账本保留续仓、未获替换资金和实际净费。 |

## 方向3　左尾风险与右尾保护

| 编号 | 实验 | 直接对照与核查 |
|---|---|---|
| <a id="d3-1"></a>D3.1 | 分开训练和核验左、右两个 H10 尾部概率。 | 事件沿用相对当期截面中位收益和事前波动的 ±2 倍定义。用此前成熟的折外预测分别对比同尾日频基线及历史发生率，报告 AUC、Brier、校准误差和事件数，标明各季度两个模型能否共同启用。 |
| <a id="d3-2"></a>D3.2 | 按左右尾概率差识别应取消的新买单。 | 全部自然新买按左尾概率减右尾概率排序，固定右尾权重为1，在差值为正者中最多剔除2席。与同机会、同席数的单左尾及随机规则比较。另跑修订1的先筛左尾前15%再按差值排序，两种选法分别给账。 |
| <a id="d3-3"></a>D3.3 | 同时要求左尾概率居前15%、右尾概率居后50%。 | 双门槛与同日同席单左尾、随机否决及原 Ridge 比较。两个概率的百分位均取当日合格池，命中多于2席时按左尾概率降序。和 D3.2 使用相同模型及自然买入资金，逐组核算剔除与补入的实际左右尾损益、误删赢家和交易费。 |

两种账户规则均继承 D3 原有的模型启用门槛。未通过的季度按原仓回放，同时保留 D3.1 诊断及两种规则的回退记录。

## 方向4　全池基本面、独立事件账户与 ETF 资金流

全池融合使用历史中证800。只在有覆盖的股票内估计输入与78项量价特征的关系，保留残差，混合系数仅由此前已成熟折外样本校准。未知股沿原 Ridge 排序，记录覆盖指示。事件账户按首次公开时点和可交易开盘形成，资金独立于 P2 五席候补。给定披露日但无时刻时，执行原方向协议的日期回退规则。H10、H20使用与持有期相应的等本金错峰预算，均不透支，逐笔给出配对资金和费用。

| 编号 | 实验 | 直接对照与核查 |
|---|---|---|
| <a id="d4-1"></a>D4.1 | 全池同机构、同财年 EPS 预测修正。 | 比较20日等权及60日半衰期规格相对同覆盖 Ridge 的费后增量，同时列覆盖标志与未经正交处理的信号。 |
| <a id="d4-2"></a>D4.2 | 全池券商目标价调整。 | 同机构、币种、复权口径可比的两次已公开目标价计算相对变化；每家机构取近20日最新修正，再取机构中位数。比较同覆盖、同日期 Ridge，另列当期价格动量，报告拆并及口径不明的排除数。 |
| <a id="d4-3"></a>D4.3 | 全池机构覆盖变化。 | 比较相邻两个不重叠60交易日窗口内、出具有效同财年预测的独立机构数变化。比较同覆盖 Ridge 和仅用当前机构数的基线；区分新增研究覆盖与数据归档中断。 |
| <a id="d4-4"></a>D4.4 | 季度盈利意外单独进入全800截面排名。 | 按 D4B 财期和首次披露规则得到标准化盈利意外（SUE）。每股从可知日起保留最多20个交易日，新披露替换旧值。按同覆盖、同生效窗口比较正交融合与原 Ridge；覆盖与触及资金另列。 |
| <a id="d4-5"></a>D4.5 | EPS 修正与季度 SUE 共同进入全池排名。 | 在各自有值处求居中秩残差，对可用信号等权平均，再按同一内折协议估计一个混合系数。比较双源、单 EPS、单 SUE、仅覆盖指标及原 Ridge；两源均有值的同股同日再做成对核对。 |
| <a id="d4-6"></a>D4.6 | 按财报盈利意外开独立事件账户。 | 对 Q1、半年报、Q3、年报区分单季与累计，分列可量化业绩预告、快报和正式披露。缺可比事前预期时只计覆盖。同公司同财期首次意外与后续新信息分别核算，避免重复入账。H10/H20 各比同日同行业同市值的 Ridge 机会。 |
| <a id="d4-7"></a>D4.7 | 检验季度营收、扣非净利同比加速度。 | 两个指标分别以当季同比增速减前一季同比增速计算，基期非正和会计口径变化记缺失；使用当时可得单季数。分别对比简单同比增速和同事件日匹配账户。具备同指标事前共识时再单列预期差，保留未达覆盖的财季。 |
| <a id="d4-8"></a>D4.8 | 单独检验券商大幅上修后的事件收益。 | 同机构、同财年、同币种，先前 EPS 为正且本次上修至少20%定义为事件；由亏转盈等其他情况单列。相同股票同一日多家上修合并一次，每袖不重复买同一事件。H10/H20 分别对比同日同行业同市值的 Ridge，另与一般正向上修比较。 |
| <a id="d4-9"></a>D4.9 | 原两只沪深300 ETF 的申赎冲击检验。 | 在相同历史篮子、份额、换入资金和 H10 上同时比较顺流买入、逆流买入、同覆盖 Ridge；披露一日滞后代理、首次可认证来源及受现金替代影响的金额。 |
| <a id="d4-10"></a>D4.10 | 把双向检验扩展到宽基与行业 ETF。 | 按当时存在的300、500、1000、科创50和行业 ETF 分组建历史矩阵。先在相同股票和资金上比新增基金覆盖与沪深300双基金，再扩到各自可比成分池；分别跑延续与反转。按日去重股票、累加有向净需求，保留退出基金与缺篮子区间。 |
| <a id="d4-11"></a>D4.11 | 披露的供需关系事件。 | 用当时已披露且生效的具名关系，比关联方过去5日收益、同行动量及等数伪关系。保留 EP41 四条已知关系，另核对新增关系的可用日期与资金；覆盖不足时仍交付来源核查。 |

本次具体化了180日代理的末10%门槛、季度 SUE 的20日有效期及大幅上修的20%定义。这些数值用于固定待检验规则。正式成分调整公告仍以首次公开记录为准，两个方向的 ETF 结果按同一口径并列呈现。
