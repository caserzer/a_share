# A4｜个股特征、日内隔夜和风险暴露

两池五个独立账户段里，Ridge 的日内毛贡献全部高于原值树。沪深300两段树的隔夜损失较轻，但这项优势不足以抵消日内差距。中证800中段两者隔夜均获利，树仍有隔夜优势。全体历史账户可以逐日加回。这给出了利润发生的时段，选股前可预测性仍须后续实盘前封存检验。

## 账户和基准

## 哪些输入影响给分和盈利

## 利润在什么时候发生

隔夜以上收盘持股数量乘以到本日开盘的价格变化，日内以开盘成交后的数量乘以开盘到收盘的变化。策略到期的末日使用开盘结算；800第一段市场缺估终点为独立中止日。停牌、现金、转换关系和对应成交限制继承EP41正式账，价格使用其已有的复权与已确认停牌估值，现金不计息；实际手续费独立列出。表为各段单位初始本金的贡献百分比，可横向加回。各日成本和净值加回最大误差为2.6e-15。

## 已观测风格能解释多少

按当日之前的历史申万一级行业、自由流通股市值代理、与沪深300市场同期有效窗口120日（至少60对）的Beta及残差波动率、当时历史记录的盈利收益率分解。盈利收益率从本地EP32审计过哈希的个股PE面板取倒数，行情聚合、行业及估值来源均保留历史代理边界，无法认证首次发布时间。每个交易日和时段在当时合格股票上使用四项截面标准化风格与全套行业哑变量回归，检查满秩；没有足够截面、缺风格或行业不支持的持仓单列损益。5,542/5,566个截面可估。可支持持仓市值比例分别为300 R 98.15%、T 98.46%，800 R 97.81%、T 98.33%。
