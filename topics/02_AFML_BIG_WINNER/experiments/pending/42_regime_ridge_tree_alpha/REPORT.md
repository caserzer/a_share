# EP42｜全部登记实验的执行结果

2026-11-27 完成修订2的历史回放。**按市场状态调整 Ridge 与树的权重，未通过唯一预先指定的主检验 D5。** 沪深300前49个完整月比同季静态组合少1.77 bp/月，后18个月两者完全相同。合计67个月 **−1.29 bp/月，95%区间 [−3.79，+0.85]**。史料支持树确实会随绝对量纲改变选股，其中一部分变化发生在波动水平共同移动时；把这个观察用于决定该给树多少资金，尚未获得可重复的费后收益。

23个一级编号、方向1–4下的22个子项均有执行记录。每行关联冻结问题、具体对照、产物与实际状态，表内保留没有触发的买单和无法取得合格输入的条件规格。[23项结果](run_register.csv) · [22个必做子项](subtrials.csv) · [原始协议](PROTOCOL_R2.md) · [核验收据](verification.json)

## 唯一主检验 D5

每季只使用该季之前已经成熟的训练数据。在同一套真实账户上先选基准树权重，再检验用市场离散度提高、降低或维持该权重。静态臂与动态臂共享基准树权重，逐日比较相同可选股票、相同席数和本金。下表中每个收益差均为同月费后收益相减后取均值。1 bp 等于0.01个百分点。

| D5比较，bp/月 | 前段49月 | 后段18月 | 67月 |
|---|---:|---:|---:|
| 动态减同季静态 | −1.77 | 0.00 | **−1.29** |
| 动态减纯 Ridge78 | +2.59 | +14.81 | +5.88 |
| 动态减纯树69 | +29.35 | +25.91 | +28.43 |
| 动态减永久17.5%树权重 | −4.63 | −4.10 | −4.49 |
| 浅层早停树，动态减其同季静态 | +1.82 | −7.36 | −0.65 |

23个季度中只有5个选择改变树权重。303个评分日权重发生变化，累计改选438席。具有实际调权下单日的18个完整月平均落后4.94 bp/月。后段所有季度都选择零斜率，因而后段的零差没有提供识别切换方向的交易。全样本双倍收费后主差为 −1.28 bp/月，分别删各段最强三个月后为 −2.40。相同持仓的静态混合在后段也获得17.11%的净收益。[完整年度收益、回撤与基准](state/results/benchmark_years.csv) · [权重、资金、全部替代对照与图](state/REPORT.md)

**模型版本复核纠正了一条研究前提。** EP41 后段“纯树领先 Ridge 58.13 bp/月”来自78项树。逐日对齐冻结分数、目标、实付费及净值后，D5指定的69项原值树相对 Ridge 在两段分别落后26.76和11.09 bp/月。两臂均仍按登记版本执行。[EP41模型原表](../41_csi300_csi800_weekly_monthly_alpha/models/results/model_accounts.csv) · [本次逐日核对](state/results/main/baseline_parity.csv)
