# 绝对量纲与树的状态依赖｜S1–S5

EP41 中，69 项原值树按有限换股方式运行，在两个历史段均优于每日秩化树。原值变为当日排名时，输入同时丢失跨日水平、离散度、分布形状，部分列的有效股票集合也会改变。纯树相对 Ridge 的分段收益方向反转，尚不能判断上述哪一项解释了换股收益。本组以沪深300独立纯树前 K 组合为主，以同日原78项 Ridge 为共同基准；EP41 的五席账户只用于核对历史口径。[EP41 输入变换](../41_csi300_csi800_weekly_monthly_alpha/models/REPORT.md#m1) · [既有特征消融和状态分组](../40_csi300_d10_reward_penalty/EP40_FULL_REPORT.md)

**共同条件。** 季度扩展折仅使用在截止前已成熟的周训练标签。每个测试日 t 的股票资格、特征和状态取 t 收盘可知值，下一交易日开盘执行，持有 H10。各比较沿用相同 K、十份错峰资金、净额收费、分段起账、缺价及受限单规则。树结构、列序、训练折中位数及全部终端叶值需要可复现。先核对逐股分数、前 K、成交和账户。原档若只存分割值，按冻结配方重建完整树；核对失败的折保留失败记录。S2 明列同配方重训，其余原树干预均固定当季已核对的参数。测量与决策各自留时间戳。

状态 Z1 沿用[市场状态登记](MARKET_STATE.md)。t 收盘计算最近20日合格股日收益截面四分位距的均值，用止于 t−1 的252日历史参照转换为百分位。涉及状态的检验以预先定义的 Z1 和其连续值为共同口径，状态缺失单列。描述性高低状态按总登记分档。模型持续持股，本文所称「择时」指截面选股对当时市场状态的响应；股票总预算固定。

每项保留原始观测掩码、折内填补值和股票日分母。训练日计算分布时先对同日每只合格股等权，再令各训练日等权。训练折拟合的常数或分布在测试季度冻结，内层验证重新按内层训练集计算。每种干预分别报告分数、前 K 席位、可改变的买入金额、合并净单、毛收益、实付费和净收益。两段及共同完整月分别列示，区间按总登记的成对时间块计算。按信号日关联状态时，使用属于该信号的 H10 持仓损益，报告重叠窗口和费用分摊，并与连续账户核账。

<a id="s1"></a>
## S1　原树的哪些分裂会随状态改变

**问题。** 同一棵已冻结树、同一批股票，在 Z1 不同的日期是否走向不同分支？分裂点在全池横截面的百分位，会把实际没有到达该节点的股票也算进去。

**执行。** 对每折每棵树按真实父节点路径逐股遍历。训练折记录节点到达率及到达父节点后走左支的比例。外层逐日保留实际到达数、左右支数、填补后走支数和最终叶值。主结构量为各节点当日左支比例偏离其训练左支比例的绝对值的加权均值，权重取训练到达率乘当日可观测指示，折内固定节点编号。零到达节点记缺测，另报其训练权重。按折内去均值的 Z1 估计结构量的斜率，两个阶段分报，同时列达到相同父节点的相邻两日同股票实际转支数。季度交界只比较各自折内变化。

**成分对照。** 每季在开始前最后一个信号日锁定当时的合格名单，逐日对这份固定名单重新走树。后续退出成分的股票只用于结构审计，上市状态和行情按当天记录。失去报价、特征缺测、入出成分带来的分母变化分别留表。逐日再比较相邻两天都可观察的同股票，在原树中的转支与换叶。报告整个冻结名单的可观察下界及未知数，不用季度末名单倒选。

**判断。** 若原池呈现状态关系，固定名单、非填补路径及共同股票均不重复该关系，证据指向成分或缺失构成。即使三者方向一致，也只支持树路径随市场条件变化。节点数、股票数不能作为独立的市场日期数；收益判断需另由 S2–S5 的对照给出。

<a id="s2"></a>
## S2　保持观测掩码后，当日排名损失了什么

**问题。** 用当日排名替代数值造成的历史差距，能否由「消除当日整条边际分布」重现？

**执行。** 每折在完全相同的69项列、周训练行、标签、树容量、种子和合格股票日上，分别训练四棵纯树。A 用原值。B 用当日合格池逐列中秩百分位，平局同分。C 将 B 的百分位放回外层训练折固定的该列原值分位函数，保留股票当天的位置和原计量单位，所有日期共用一条参考分布。D 用训练折固定的经验分布函数转换原值，目标是保留跨日高低关系，并与当日秩 B 比较。D 单列参考范围外饱和与并列带来的次序损失。B、C、D 的分位定义和插值在折内固定。各列先在完全相同的原始有效股票上求值，再按各臂自己的训练中位数填补相同的空格。所有臂共用同一原始资格；另将同义滞后列限制到共同有效股票的对照单列，并在相同掩码下重跑 A。

**主比较。** A 减 C 的整账户月均净差衡量去掉每日边际分布对整套模型的影响。B 对 C 核查只改参考计量单位、D 对 A 核查固定单调编码能否复现原账户，逐折解释训练分箱、并列、越界和前 K 差异。若这些控制的差额已与 A 减 C 相当，或补齐掩码后主差消失，保留输入编码或缺失结构解释。即使 A 优于 C，尚需 S3、S4 区分分布形状和绝对尺度的时间作用。

<a id="s3"></a>
## S3　固定树，拆开波动特征的当日水平与离散度

**问题。** 在同日排名与其他输入不变时，个股波动特征的截面中位数、四分位距，哪一项能实际改变树的选择？本实验预先只检验 `vol5/20/60` 三列。结论限于该特征族。

**执行。** 对每一列当日严格为正的有效值取对数，记中位数为 m、四分位距为 s，保留每只股票的残差 u＝(log vol−m)/s。每折参考 m₀、s₀ 取此前训练日期 m、s 各自的中位数。对同一棵原树保留四种输入，分别为 exp(m₀+s₀u)、exp(m+s₀u)、exp(m₀+su)、exp(m+su)。其余66列和原缺失格不动，原来等于零的观测始终保持零。当天该列 s 为零或无法计算时，四臂均保留原列并记录未干预。最后一臂须能复原每个原值、分数和名单。对每臂列出训练实值范围外的输入、变化的路径与席位，以及少数极端日的贡献。

**主比较。** 原值减同时冻结水平与离散度，按相同本金衡量净差。两个单项贡献取四格两个相应边际差的等权平均；另报四格交互，不将交互重复计入两项之和。取原值输入臂的逐股实际持仓核账。若只改变树分数而未改变交易，结论止于结构敏感性。若收益仅出现在超出历史支持的状态或集中在少数月份，不能据此认定有可重复净增量。保留各日 u 的偏度和尾部，和 S2 消除整条分布的检验有不同含义。

<a id="s4"></a>
## S4　让同一组股票承接较早的市场尺度

**问题。** S3 的六个共同量（三列的 m 和 s）即使改变选股，使用恰好属于 t 的那一组数值是否更有利？本项在同一棵树内替换共同量，保留当日每只股票的 u、原掩码和其余66列。三列整体搬移，保持其共同量之间的同时关系。

**执行。** 同一天对比当日真实共同量、固定折内参考共同量、同市场 t−20 个交易日的六维共同量。登记的时间错位主对照为 t−20。另建20条事前可构造的安慰剂路径，每个外层20交易日块按固定种子1–20，从折开始前已完整观察的连续20日块中抽取共同量，保留块内顺序。种子共享同一行情，只用作参考分布。缺少起始历史时各臂沿原计划，单列未触达资金。主比较为当日减滞后20日的净差，分别报告当日减固定值及当日减各历史块。另报两臂共同量的边际分布和自相关，单个滞后不保证打破持续状态。

**训练支持。** 以每只股票三列共同变换后的实际输入核查训练覆盖。逐列记录超出该折训练实值范围的股票日；再将非缺失波动三维对数按训练中位数和四分位距标准化，用到训练集中另一交易日最近点的距离审计联合支持。训练期留日距离的第99百分位固定为支持边界。在各臂均有支持的可比股票上重复比较，资格收缩后按原席位预算填充，可选不足的资金持现，另报与全池不同的席位和资金。三列含零或缺失的股票在联合距离中计为支持未知。

**判断。** 真实共同量相对固定值和错位值均有同方向的历史费后增量、在共同支持上保留，才提供「尺度的日期配准有经济作用」的线索。若仅优于固定值，可能只说明树受益于某些输入范围。若只有不可比的人工向量产生差距，只保留模型敏感性。按 Z1 给出的信号日分组用于解释该差距，因果外推仍需新增时间样本。

<a id="s5"></a>
## S5　同一行业与风格机会内，尺度效应是否保留

**问题。** 市场状态与行业占比、自由流通市值、流动性构成一同变化，所观察的尺度效应有多少能在可比的选股机会中复现？

**执行。** 独立重建 S3 的原值树与固定共同量树，保留全池自由选股作为基线。每个 t 收盘用历史有效申万一级行业、信号日前最近已知的自由流通股快照乘当日未复权收盘、截至 t 的 ADV20，分别计算全池的市值和成交额百分位。两树的行业席位均锁定为当日冻结 Ridge 前 K 的行业席数，组内按各自分数补足。再取两树在相同行业预算下的分歧席位，在同一行业内要求两项百分位各差不超过0.10，最大化无放回配对数、再最小化两项距离，按代码破平局。共同股同额续持，匹配双方给相同目标资金，未配对的分歧预算两边均持现。各自实际成交、遗留仓及其造成的实际风格差继续按日记录。分别报告全本金、仅配对资金两个分母。

**固定构成的状态复核。** 按申万一级行业及全池自由流通市值三分位分格，以折前最后一个完整季度的平均合格股格权重作为参考。在同一 t 对固定权重内的各股等权重算收益截面四分位距，再沿 Z1 的相同20/252日时钟另算固定构成的离散度；原 Z1 保留。对每个 t 只处理有资格、有行情的格，记录有支持的历史参考权重。缺格时单列缺失并报告原 Z1 在相同日期的对照。参考构成版本从该折开始前按同一份折前权重回建所需窗口，供该测试季度使用；训练折、前瞻预测均独立冻结各自权重。

**主比较。** 记录行业和风格双重约束后的原值减固定共同量月均净差，并和自由预算、只锁行业预算的账户并列。在共同日期上比较收益差随原 Z1 与固定构成离散度变化的方向，列示相应资金和日期覆盖。匹配前后资金规模、独立复投和交易路径均可能改变，不能直接相减求得「未匹配资金的利润」。若放宽预算才出现收益，或高低状态缺乏重叠的行业与风格支持，只能识别该组合中的配置或覆盖差异。若在可比资金、固定构成状态及两个阶段均保留，支持可比机会内的历史选股增量；实际市场定时能力仍以登记后逐期封存结果检验。
