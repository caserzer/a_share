# A3　把共同起点与连续持仓的差异拆到账

EP41 的第0相位在相同原 Ridge 旧仓上，用同一笔H10资金比较树挑候补与顺位候补，前、后两段费后分别为 +3.31、+2.62 bp。扩展到全部十相位的991、381次决策后，等权平均为 −0.37、+0.29 bp。按各袖真实起始本金加权后为 −0.11、−0.03 bp。原相位与全相位产生不同结论。[每相位毛利、收费、净差与本金加权](phase_comparison.csv)

每个调仓日复制三种真实旧仓，包括现金、尚未卖出的遗留和其他九袖。对树历史路径和顺位历史路径各执行一次树买单、一次顺位买单，构成四角；原 Ridge 共同旧仓再做两角，共8,232次反事实。其余九袖沿各自冻结计划，交叉抵消及同日实付费用随反事实重算。实际路径的开头与结束逐日对齐原账，最大误差约 1.1×10⁻¹⁵。用两种起点的对称平均分配路径交互后，在整本H10窗口内，“本次决策”前后段为 −0.04/+0.04 bp，“旧仓及其他袖路径”约 −0.41/+0.23 bp。两项逐窗口之和等于整本差。[四角明细](corners.parquet) · [逐起点分解](corner_attribution.parquet) · [原账核对](parity.csv)
