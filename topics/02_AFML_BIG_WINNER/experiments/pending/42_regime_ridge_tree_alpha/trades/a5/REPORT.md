# A5　门槛节省了什么费用，又放弃了什么机会

## 拒绝配对的预测误差

中证800后段 Ridge 被拒7,906对，覆盖371个决策日，共29.435单位冻结票面；逐日从同一期初账在无门槛下试单，买卖两侧能同时成交的资金为28.746单位。两端可估且预测可得的票面为29.405。每单位票面预测换仓毛差 **−22.36 bp**，后验实际新股减旧股为 **+74.16 bp**。获准的551对，预测/实现为 +50.75/+288.40 bp。实际被拒配对没有转为真实的新股仓位。冻结机会损益与连续账户现金及净值分账。[逐段接受与拒绝](opportunity_summary.csv)

把原旧仓此前 H10 相对指数的涨跌分开，中证800后段 Ridge 在旧仓已涨的3,169个拒绝配对上把 −27.83 bp 预测成实际 +106.80 bp，可同时执行资金11.63单位；旧仓此前已跌的4,737对同样低估，预测 −18.71 bp、实际 +52.41 bp，可执行17.12。缺价前的已涨组实际 −3.87 bp，缺价后重启的已跌组实际 −32.18 bp。后段存在低估，但买方机会、旧仓路径和市场阶段均参与，无法把后段账户损失稳定归给“留住已上涨的旧仓”。[按既有涨跌分组](opportunity_old_path.csv)

逐股新、旧百分位来自信号日各自全部拟买组和待卖组。当日收盘收益离散度取有分股票的截面样本标准差，分界仅用过去252个有效信号日，历史不足独列。每格提供实际对数、交易日期、该批日期全部机会数、票面、双边可执行额、实际换入、预测和实现共同覆盖、实际支付于该对股票的费用。空格保留缺测值。各格“该批日期全部机会数”在格间可能重叠。[排名×离散度全格](opportunity_grid.csv) · [再分旧仓此前走势](opportunity_old_path_grid.csv) · [300日期切点](dispersion_300.csv) · [800日期切点](dispersion_800.csv)

## 实际手续费的去向

两池共核对27,830个账户交易日，原 E1 每日净值、现金、买入、卖出、抵消与实际费用的最大差为零。按每袖真实净买单位建立 FIFO 批次，减仓时按最早买入批次分摊买费和卖费；段末仍持有的批次保留买费及成本。历史换股合并事件使用账本的转换价格移交份额。两池共791,342条已缓释或结存的份额记录，分摊费与券商费最差绝对差约1.4×10⁻¹⁷。

以中证800后段 Ridge 为例，原账户成交费为0.09174单位本金，其中正好1个H10的买费/卖费为0.0222/0.0447。E1成交费降至0.01396，正好1个H10的买费/卖费降至0.0006/0.0013；超过3个H10批次的费用为0.0023/0.0048。若同袖旧仓滚动也按虚拟全卖全买记，E1理论费用为0.12214，扣同袖净额抵消费0.10818，再扣袖间抵消才到实付费用。抵消费是旁账；收益只扣实际成交费。[按持有期、退出原因分摊](fifo_summary.csv) · [理论与实付核对](fee_reconciliation.csv)
