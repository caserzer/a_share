# D6｜分域预留预算和分域重训各自带来了什么

**可评分股票的变化。** 重算域内尺度后有121个评分日的合格集合发生变化，共少2,737个股票日，其中300域4个、非300域2,733个。为检查这部分影响，另在两套分数都有值的逐日交集上重放乙、丙，席位和资金规则相同，三段净差为 −5.16、−18.23、−8.73 bp/月，合计 −10.09 [−25.63，+4.79]。限制为同一批股票后，主要结论保留。[逐日剔除数](results/d6_common/coverage.csv) · [同股票对照](results/d6_common/comparisons.csv)

**资金效果。** 乙减甲同时包含席位和两域本金分配变化。三段合计+3.59 bp/月，区间 [−3.70，+12.05]，删强月后 −6.04。自由流通市值条件臂只在两个域的合格股都有可核自由流通市值时使用；1,381个评分日中1,372天满足，平均约74.56%分给300域，其他9日新启用的袖持现。逐日覆盖以域内所有合格股为分母。[每日分域与市值支持](results/d6/coverage.csv) · [已成交的两域资金与损益](results/domain_actual_exposures.parquet)

**模型效果。** K沿用原300池当日合格数除以10的整数席位。乙与丙均将前域席位取K的一半向下取整，另一域用剩余席位。丙在各域各自重算横截面收益的滞后特征，使用域内H10目标收益秩，以本域已成熟的周样本估计缺失填补、缩放和固定正则Ridge。原混池甲对封存P1的三段589、411、391个估值日逐日核对，任一账户字段最大误差1.12×10⁻¹⁵。前5%、前10%另立两臂，保留改变总席数的比较。[23季、两域训练截止](results/domain_folds.csv) · [原账核对](results/d6/baseline_parity.csv) · [逐日目标](results/d6/targets.parquet) · [行业预算](results/d6/industry_weights.parquet)
