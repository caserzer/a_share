## 2. 一页结论

1. **D8 的样本期收益最高，但优势主要来自五个事件月。**在固定 `S0 + lambda=0 + no-stop + SLIP005` 下，D8/D9/D10 的21月复合收益分别为 `52.47% / 45.56% / 21.99%`。D8 在五个事件月全部为正，事件月复合收益 `+15.01%`；D10 的事件月复合收益为 `-6.32%`。在16个非事件月，三桶月均收益只相差约 `0.16` 个百分点。
2. **桶收益不支持简单的“越靠近 D10 越好”。**D10 相对 D8 的月均差为 `-1.103` 个百分点，但21个月 block-bootstrap 95% 区间为 `[-2.298%, +0.035%]`，仍跨越0。当前结果更像事件状态下的桶暴露差异，不是稳定的单调排序证据。
3. **lambda=0.5/1 的板块倾斜非常弱。**D10 的复合收益仅从 `21.99%` 变为 `22.14%/22.18%`，实际板块 HHI 从 `0.04144` 变为 `0.04176/0.04208`，最大 Top1 板块权重始终约 `9.48%`。这不是有效的市场拥挤度暴露，更不能解释为历史 PIT 板块择时。
4. **成本侵蚀稳定且近似线性。**D10 从 gross `24.05%` 降至 reference 5bps 的 `21.99%`，40bps shadow 为 `14.79%`。不过10bps以上 shadow 已出现现金缺口，不能当成真实自融资执行账本。
5. **硬止损在全部18个 model×bucket×lambda 单元中都降低复合收益。**D10 不止损为 `21.99%`；5%/10%/15%/20% 止损分别为 `7.48%/13.10%/18.45%/20.77%`。5%止损把年化波动从 `17.59%` 降至 `9.64%`，但也把平均投资权重降至 `66.76%`，并产生 `-158.38万元` 的 stop-vs-hold 反事实差额。
6. **S0 与原始 B0 没有稳定全网格胜负。**270组 S0-vs-B0 比较中，159组月均差为正、111组为负，但270组 bootstrap 区间全部跨越0。S0 更像降低了部分尾部风险，而不是在所有桶上稳定提高收益。

## 13. 执行与数据质量边界

1. **静态板块代理**：2025概念板块快照不是历史 PIT；全样本 target-union 还使早期月份依赖后续进入样本的股票。
2. **成本 shadow**：除5bps外，其他成本情景不改变成交股数和时点。它们回答纯成本敏感性，不是重新自融资后的真实组合。
3. **止损代理**：gap-first/intraday-low 使用日线近似；没有逐笔盘口和排队成交信息。
4. **复权映射**：全路径记录19个 raw/qfq ratio warning，最大相对 spread 为 `0.7353%`，低于1%的 block threshold，但仍应保留为执行质量 caveat。
5. **终点持仓**：主 NAV 不做强制清仓；terminal liquidation 只是成本估计。
6. **样本量**：只有21个月，且本 topic 历史已被反复观察；bootstrap 不能把 design-contaminated 历史升级为 OOS 支持。
7. **事件标签**：五个月是事后解释标签，不是事前可交易预测器。

## 14. Findings 与 AFML 决策含义

### 14.1 板块集中度不是当前主要效用杠杆

lambda 对 HHI、Top1 和收益的影响都很小，且跨模型/桶方向不一致。当前结果支持的是：在 `lambda<=1` 和单股权重约3%的设计下，板块倾斜太弱，既没有显著放大集中度，也没有稳定改善收益。

若未来继续研究，应先把问题拆成两个独立假设：

- PIT 行业/概念暴露是否具有 ex-ante 信息；
- 明确的组合集中度预算是否改变收益/回撤效用。

本轮静态 retrospective proxy 不能回答这两个问题。

### 14.2 D8 优势应降级为事件暴露线索

D8 的 full-sample 结果最好，但其相对 D10 的优势主要由五个已知事件月贡献，bootstrap 区间也未排除0。AFML 语义上，它更适合作为后续 regime interaction 或 meta-label 研究线索，而不是直接把持仓桶从 D10 切换到 D8。

### 14.3 硬止损是参与度压缩，不是免费左尾保险

5%止损确实降低波动、最差月和回撤，但通过把三分之一资金变成现金实现，并严重截断后续反弹。10%和20%的配对区间明确为负。若风险目标是控制资本暴露，应该将 participation sizing、风险预算与退出规则分开评估，不能只用事后收益挑一个止损阈值。

### 14.4 成本不是零，但也不是本轮收益差异的主要来源

5bps 相对 gross 令复合收益下降约2.06个百分点，显著但小于 D8-D10 的样本期收益差，也小于紧止损造成的收益损失。成本需要进入效用评估，但不能解释桶间和事件月形态。

### 14.5 当前最稳健的结论是“形态”，不是参数

当前可以保留的形态结论：

```text
D8/D9/D10 差异高度依赖事件月份
板块倾斜效应很小且不稳定
成本侵蚀单调
硬止损普遍截断复利和反弹
S0 倾向于降低尾部风险，但不稳定提高所有桶收益
```

当前不能保留的参数结论：

```text
选择 D8
选择 lambda=1
选择某个 stop threshold
将 break-even bps 当作可执行成本上限
把五个事件月变成动态切换规则
```

## 16. 最终回答

对最初四个问题，证据支持的回答是：

1. **交易成本敏感性**：收益随成本稳定下降；5bps下仍为正，但10bps以上 fixed-path shadow 已非自融资，不能直接解释为可执行回测。
2. **板块集中度敏感性**：lambda=0至1几乎没有改变实际集中度，收益变化很小且不稳定；没有证据支持把静态概念板块过度代表度作为主要加权杠杆。
3. **D8/D9/D10**：样本期 D8>D9>D10，但差异高度集中于五个事件月，配对 bootstrap 仍跨0，不授权切桶。
4. **硬止损**：四档止损都降低复合收益；紧止损主要通过增加现金和错失反弹来降低波动，不是无成本的左尾改善。

因此，本轮最有价值的产出不是一个新参数，而是排除了两个看似自然的修复方向：**静态板块倾斜没有形成足够强的组合变化，固定硬止损也没有改善 D10 的事件月效用。**
