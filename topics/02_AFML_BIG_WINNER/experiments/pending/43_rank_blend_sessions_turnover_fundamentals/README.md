## 共同账户与判读

- 收盘 t 以当时有效成分及资格出分，t+1 开盘成交，计划 t+11 开盘到期。单池按当日合格数 N 取 K=floor(N/10)，十份本金错峰，每段从1起账。800原生K与历史P1的300席数桥接分别记账。固定原始资格与代码破同分规则，预测时保留日后无标签者。沿EP42处理交易限制、公司行动、同股净额、现金、实际券商净买10 bp与净卖20 bp，另整账重跑双倍费用。禁止以事后开盘信息决定前夜的名单、优化参数或旧仓参考权重。
- 所有拟合按季度扩展、用成熟周标签，标签末端严格早于训练截止。选 b、λ 用外季前最近8个完整季的日频逐季折外分数，至少连续4季；每个内季重建当时模型、预处理和组合。不足时按各方向的基线回退，披露回退季与资本。候选在相同可估段、完整月及资金上按月均净收益选优，同值按机器表先后顺序。参数冻结一季，不在季度边界重置持仓。
- 300沿原两段 2021-01-11至2025-03-03、2025-03-03至2026-10-12。800沿2021-01-11至2023-06-15、2023-06-19至2025-03-03、2025-03-03至2026-10-12三段。某臂提前缺价则截至最后严格估值日，对比取共同完整月。完整月须有本段上月末净值，禁止跨缺口接净值。300参考49/18个月，800参考28/20/18个月；实际覆盖另报。
- 各方向固定一个首要比较（B2、L3、W3、F4），先报告各段及按有效月数加权的费后净差、毛差、实付费差、各段删最有利三个月的净差 drop3。段内按连续三个月成对重抽10,000次，种子4301，报告双侧95%百分位区间。四项作统一显著性判断时，单侧零均值检验使用居中块自助分布并作Holm校正，不能计算的主项按 p=1 保留位置。其余对照用于归因。历史推进需各段净差同正、汇总区间下界大于零并通过方向专属门槛；条件收益或跨段异号单列。
- 每项产物以编号命名。保留训练／标签截止、源版本、分数、排名、逐日目标和实际成交、十袖现金与持仓、净值、容量与受限资金。列每段逐年净收益、指数全收益和同池等权超额、回撤、完整月、费用、换手及触及资本。标签秩相关、单期每元损益、整账户月收益分别列示。无法出资、无标签、样本太少或无PIT来源各留状态及分母。
