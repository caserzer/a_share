# 方向2｜在训练端拆开日内与隔夜标签

### L1　逐股标签恒等式和成熟时钟

令 e=t+1，O、C取同一复权因子序列的开、收盘。对 j=e,…,e+9 计算 I=Σlog(Cj/Oj)，V=Σlog(O(j+1)/Cj)。逐股逐期验证 I+V=log(O(e+10)/Oe)，绝对误差≤1e−10。两腿各有10项，最后一晚计入V；不含买入前一晚。分腿简单复利为 exp(I)−1、exp(V)−1，毛财富因子相乘。校验拆并、停牌、缺开收盘与不可交易样本；缺有效端点标记未知。两腿与总标签主比较共用同一完整标签训练集；附原冻结总标签全样本账户，量化样本改变。每次训练所有腿统一以 e+10 开盘为最早成熟时刻，测试当日资格独立于未来端点。

### L2　同输入的两套Ridge

在每个训练截面用相同股票分别将I、V、I+V变换为居中收益秩 rank/(n+1)−0.5。用相同78列、正则、折内填补与标准化拟合三个Ridge。分别回放只用日内、只用隔夜、直接预测总秩与两腿预测等权相加四臂。系数、预测相关、各腿和总收益RankIC、D1/D10尾部及前K交集全部报告。λ=1是拆腿等权对照，总收益秩与两个秩之和通常不同。

### L3　合成系数的主检验

对每只股票直接用两套Ridge预测的居中秩分值合成 pI+λpV，再按同日总分取K。沪深300主比较为内层选λ的拆腿账户减同训练行的直接总秩Ridge，并列相对冻结R78和λ=1的差。λ候选依次1、0、0.5、1.5、2，内层成熟窗口与目标见总协议，不足用1。λ=0与隔夜单腿均留账。十袖全程保持原次日开盘交易和H10持有，允许模型分数改变名单。输出逐季λ、候选净收益、真实改动资金、毛差、费差与净差。

### L4　树预测隔夜的对照

固定日内Ridge，将隔夜腿换为相同78输入、普通平方损失、G2固定80轮树，先固定λ=1，再独立按相同内层时钟估λ；与对应双Ridge逐项比较。补列直接预测总秩的同配方树、原69项整树作为桥接。按预测隔夜风险五档查看实际隔夜贡献、日内反弹、流动性和新增资金。集合竞价中的交易者身份缺少数据，本项只识别价格时段。

### L5　能否减半且保住日内收益

逐日用实际份额把昨收到今开的旧仓损益、今开到今收的新仓损益及实付费加回净值，终止日按原开盘估值。以每段初始本金计，不把个股训练对数收益相加代替账户归因。300冻结R78的两段日内/隔夜为 +68.83%/−19.23%、+37.27%/−14.90%。主臂需各段保留至少100%基线日内贡献，隔夜亏损绝对额至多为基线的一半（约9.615%、7.45%，正贡献也通过），且达到公共费后条件。用未舍入原账判定。同时报告同实际持仓敞口归一的结果、隔夜持仓风险及现金比率。800用本池Ridge、同训练时钟和原生K复验，基线隔夜为正的阶段改报绝对贡献差，比例列不适用。[A4 分时原账](../42_regime_ridge_tree_alpha/scale/a4/REPORT.md)
