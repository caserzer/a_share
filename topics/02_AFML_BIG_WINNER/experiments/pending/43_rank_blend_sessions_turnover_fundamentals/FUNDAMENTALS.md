### F2　冻结六个锚和可用门槛

| 锚与正方向 | 算法 |
|---|---|
| 盈利收益率 | TTM归母净利润/当日总市值，亏损保留负值。 |
| 账面市值比 | 最近已知归母权益/当日总市值，非正权益单列并报覆盖。 |
| ROE_TTM | TTM归母净利/本财季末与四季前期末归母权益均值，两端权益须为正。 |
| ROE稳定性 | 过去8个连续季度的ROE_TTM取样本标准差，再取负值。 |
| 现金实现率 | TTM经营现金流净额/TTM归母净利，分母非正列未知；金融业可比性单列。 |
| 毛利率同比变化 | 同口径单季(营收−营业成本)/营收减上年同季，营收须为正；无同定义的行业列结构性缺失。 |

累计流量先用当时已公开同年度各期差还原单季，再取连续4季TTM。缺期不跳过，上述8季稳定性另需TTM预热。最近可用财期末距信号日超过180自然日列过期。所有分母、币种、数量级及报表类型可追溯。按每个信号日所有合格800股作分母，逐因子与六项联合分别报原值、严格PIT、行业中性可得的股票日、一日覆盖的P10、按年、按行业、原头部资本覆盖。全历史及各年严格股票日覆盖须 **>95%** 才称相应口径达标；若仅5项达标，按预列单项列结论，六项联合未达如实报告。缺失标志、填补和放宽到非金融子池均不计入达标分子。

### F3　与价格和行业的独立性

在交易日的历史申万一级行业内对各锚取平均秩/(有效数+1)−0.5，行业有效数不足10或行业未知则列缺失。与保留原分布的全池秩、缺失标志单独比较。报告同日与78个原特征、R78、pos60、dd60的Spearman相关，按年/行业列中位数与极值。将各中性锚对原78项及对数总市值做同日可见横截面残差化（含截距，观测数须多于设计矩阵秩），检验残差的H10 RankIC及头部增量。低相关的预登记描述量为每个锚对78列的最大绝对日均相关，界值0.30；纯市场共同列当日常数记不可定义。低相关与可赚钱分别判读。

### F4　800基本面增量主账户

### F5　低位股的质量过滤

冻结R78原目标，以当日全池 pos60、dd60 各自从低到高的百分位平均值最低20%定义低位股（执行前复核dd60越负回撤越深）。用四项质量行业中性秩等权，至少三项可见；其中质量居当日可评分池后20%的低位原目标才触发。顺序按原Ridge边界先处理，以同日同业、同为低位、质量可见且不在后20%的最高顺位候补无放回替换；无可比候补或原股质量未知保留原决定。分别对原R78、同日同业相同席数/票面的机械替换（固定按日期及代码哈希）、只用价格低位的规则比较。输出被过滤与买入股的真实资金、毛费、尾部收益、低位子池覆盖及全账户净差。A4的遮盖涉及38个中期输入，故另给只按pos60与只按dd60的固定诊断，不将整族利润归给两个变量。[A4输入与遮盖](../42_regime_ridge_tree_alpha/scale/a4/REPORT.md)
