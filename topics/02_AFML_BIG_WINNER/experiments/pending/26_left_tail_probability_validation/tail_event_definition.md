# 事件与收益标签冻结

主事件 `Y20=1[R_6m<−0.20]`，严格小于；恰好−20%不计入重大亏损。辅助Y10/Y30同理，主阈值不因表现改变。

已核对EP25 config.json的tail_threshold=−0.2及src/core.py的`atoms < threshold`和`actual < threshold`。两期主事件定义完全一致，可在相同股票、预测月和标签子集比较Brier。EP25完整分布的盈利概率或早期EP24五档边界不是本实验主目标。

沿用EP25 R10四期限面板中的y_6、target_6、end_6。月末收盘为预测起点；日期加6个日历月后，取首个市场交易日收盘；收益为前复权收盘比减1。目标日个股无价格仍缺失，不顺延，不假设零或全损。与EP24早期126交易日、次日开盘口径不同；不混用。数据冻结截至2026-05-29，预测2021-01至2026-04，先生成全部资格人群预测，再单独选择到期且标签存在的共同评分子集。

分布间接基线的p10/p20/p30从EP25原float64原子按严格事件求均值；B1、D_R及D_V/F/VF不重拟合、不重新量化。B0为原始成熟训练样本中事件发生率（ pooled stock-month expanding rate），不是200原子近似发生率，差异按定义披露。B0训练窗口、B1/D_R冻结人群及全部分类候选的人群相同。

所有直接分类候选p20原样保留。分别拟合的辅助分类概率仅作预先冻结的锚定修正：p10=max(raw10,p20)，p30=min(raw30,p20)，保证事件嵌套；保存原始值及修正比例，不能优化主概率。直接分类器不唯一决定收益分位数，不凭三个事件概率虚构Q05/Q10；辅助分位数研究原样评价EP25分布的Q05/Q10。

前复权价格代理不是完整总收益，退市/停牌/重整可能使重大亏损事件漏记。仅在已知标签上观察Y=0不意味着缺失股票安全；到期缺失的事件率及Brier界限另列。原历史股票池的幸存者与未来ST选择偏差仍在，主结果不是全A股无偏事件率估计。
