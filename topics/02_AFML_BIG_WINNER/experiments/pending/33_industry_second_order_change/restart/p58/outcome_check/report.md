# P58结果收尾：阶段替换有小幅变化，仍未建立独立筛选增量

复用P58封存分数/名单和P05同一旧标签，原模型/容量/母体不变。本核查曾在P59因用户明确市场下跌问题而后置，现已执行。12组原模型/期限的36项容量、已知数、日期等权胜率完全复现。

所有名单固定7,628行业周；未知差异来自替换成员，未填零。117个有成熟结果的日期、完整144周轴用于时间块统计，不把重复行业周称独立事件。

S替换相对旧S增加0.236pp，探索区间[0.036,0.462]pp；SD替换增加0.146pp，区间[−0.124,0.445]pp。这只说明修复影响不可完全忽略，不代表阶段相对无阶段基线有效。

真正的阶段消融：替换S减B为−0.070pp，区间[−1.420,+1.111]pp；替换SD减D为−0.057pp，区间[−0.848,+0.553]pp。两者仍未建立正向独立选择增量。63日差分别−1.715/−0.955pp，区间均负；252日−0.738/−0.635pp，区间跨零。不能挑选S修复效果的正区间，替代阶段增量问题。

## 反思和结论边界

P57输入版本审查有必要，P58显示名单小幅变化，本核查确认变化不足以建立相对基线的阶段优势。结束这一冻结模型数值修复分支，不以此启动校准或再搜索阶段阈值。

这仍不是完整修复价格重训验证：旧训练、非阶段输入及旧标签保持不变，有意用于隔离阶段替换影响。不能据此宣布所有阶段信息无用；也不能把混合版本55.79%称正式入池胜率。已反复使用历史、多重检验未校正，区间仅探索性。原高胜率池目标尚未完成、方法未获批，协议保持不变。

最新研究方向仍按用户澄清区分共同市场机会稀缺与行业同日选择增量。P60固定市场门槛也未通过；当前没有依据直接推进正式池，不能用数据核查完成代替目标完成。
