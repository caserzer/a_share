# P58：固定模型的阶段替换仅改变约1.30%前列名单

按预先计划，冻结P05的S（价格加阶段）和SD（再加扩散）全部24个季度模型，保留原价格/量能/扩散特征、旧候选母体和前20%容量，只替换P57重建的八个阶段变量。不读取未来收益，不训练或校准。

## 结果

|模型|行业周|分数变化行数|原选中行业周|被替换行业周|替换比例|同日排名相关均值|
|---|---:|---:|---:|---:|---:|---:|
|S|37,854|1,390|7,628|99|1.30%|0.9938|
|SD|37,854|1,173|7,628|99|1.30%|0.9939|

这是行业周名单替换，不是99次独立机会，也不是胜率改变1.30个百分点。两组99行不代表相同身份。S年度替换比例2024/2025/2026为1.85%/0.89%/1.13%；SD为1.78%/1.00%/1.08%。2026为现有截至10月16日的观察数据，不是全年。

至少95%的分数完全不变；最大单行分数绝对变化S为0.2535、SD为0.2327。整体稳定不能掩盖局部敏感性，也不能把原始分数变化解释为可信成功概率变化。

每组有1个旧候选行业周在P57没有完整重建状态，按计划保留旧阶段值并标记不可替换，没有删除。其余37,853行可替换。不同版本block未混作同一身份，连接使用分类制度、行业代码和日期。

## 反思与边界

本轮没有观察到仅修复阶段输入导致名单大范围改写，因此不能以P57连续变量变化为由宣称原阶段结论被推翻，或自动启动新的参数搜索。原P05未建立阶段/扩散额外排序优势的结论仍作为旧版本证据保留。

同时，少数名单变化可能影响微小的原增量，且本轮未重训，不能证明完整修复后的模型一定无增量。混合旧非阶段输入与新阶段输入仅用于控制变量的数值反事实，不作为可部署模型。P05从2024开始，不能由这轮推断2023的阶段模型表现。

下一步若核对结果，应先复用已经封存的本轮分数，在同一固定母体/同一标签版本上比较变化及未知影响；不能以这套混合输入当作新候选、重新优化阈值或直接进入概率校准。当前没有新方法通过第一阶段，最终高胜率研究池尚未交付。

## 核验

24模型合计75,708条旧分数重放与封存值在1e-12内一致；原容量与同分身份排序保持一致，逐日期名单通过独立Python排序集合核对。各输入、模型和输出哈希见receipt.json，额外名单验证见validation.json。计算一致不等于有效性。
