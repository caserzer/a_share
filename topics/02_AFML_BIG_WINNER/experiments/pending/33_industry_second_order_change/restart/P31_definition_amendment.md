# P31定义修正：在任何未来结果读取前去除机械数量缩放

预登记normalized_HHI=(sum(p²)−1/n)/(1−1/n)，对n个正涨幅，它恰等于CV_positive²/(n−1)。因此即使正涨幅相对离散程度相同，它也会随正收益成员数机械下降。原配对后分散组仍多7.92有效成员，不能直接解释为独立行业信息。

修正使用positive_gain_cv2=n*sum(p²)−1=(n−1)*normalized_HHI，即正涨幅总体方差/均值平方。重复同一正涨幅向量不会改变该值；仍可能与实际规模/广度相关，需要继续检查，不能宣称已因果控制。名称改为正涨幅相对离散程度，不冒称市值加权贡献HHI。分组规则、资格、日期、窗口全部不动，重新检查输入平衡，不读取未来成功标签。
