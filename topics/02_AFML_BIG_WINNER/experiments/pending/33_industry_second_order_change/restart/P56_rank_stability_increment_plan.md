# P56：短期排名持续性是否解释动量增量

P55只能排查2023特异性，不能否定非特异环境指标的用途。本轮不扫描窗口，保留P55唯一五日定义。假说：同日行业领先位置更稳定时，既有60日动量前20%名单相对全行业的未来联合成功率增量更大。反例是零/负关系，或关系仅来自市场趋势、年度混合。不同于趋势方向/参与度，这里检验横截面相对位置持续性。

复用P35同日固定名单结果与市场状态，不重选、不重新定义事件。主期限126，63/252敏感性；原树仅竞争对照。日期等权、全194周轴；只合并P55当时已知且有效rho，缺失不填值。执行前报告各年日期支持，至少两个完整年各26成熟日期才解释全期结果。

主统计是动量增量对rho的线性斜率（rho增加0.1时的百分点变化），同时报告加入当时市场126/21日收益的控制版本；年度简单斜率完整保留。不把描述回归称为事前预测器。26周循环时间块500次、种子3309、原周轴同步重采样rho/结果/控制；区间不做行业独立抽样。

只有主期限简单及控制斜率区间下界均正且2023–2025方向一致，才有理由提出下一步冻结验证；不按年度选择、不优化阈值、不由敏感性替代主检验。这是事后探索且已多次使用历史，即使满足也非准入批准。未满足则停止此定义的增量分支，不继续调窗。池标准、概率和早期性验收保持原状。
