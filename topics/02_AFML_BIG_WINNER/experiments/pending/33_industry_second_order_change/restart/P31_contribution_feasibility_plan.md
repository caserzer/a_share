# P31：涨幅贡献集中度——仅做新信息可行性审查

2026-11-11。不读未来成功标签、不训练、不新建准入规则。

旧研究核对：EP33 P05 D为上涨比例及变化；EP32 V18含按既定龙头/同业分组的收益差和广度。二者均属于扩散家族，本轮不是完全独立的新主题，必须保留此前无稳定增量的反证。待核查的具体区别是：在同样上涨比例/行业动量下，正收益幅度是否高度集中于少数成员。

固定定义：当前日期前月成员集合、实际qfq价格t和t−21同链且无冲突，观察覆盖>=.8且>=5有效成员。正收益r_i>0的贡献占比p_i=r_i/sum(r_positive)；positive_hhi=sum(p_i²)，concentration=(positive_hhi−1/n_positive)/(1−1/n_positive)，至少2正收益成员。指标只是等权成员正涨幅分布，不冒称市值加权指数贡献。特征不填陈旧报价，缺失显式保留。

假说限定于过去21日成员等权平均收益为正的观察：正涨幅贡献较分散可能比少数股票驱动更有延续性；竞争解释是只反映上涨比例、规模、动量或投机强度。先在P30当时可评分母体同日期按rate60三分位×有效成员数中位×上涨比例中位形成12格，格内至少6行业，按concentration排序分半，两侧各至少3条，平值按行业代码稳定排序。先统计配对覆盖、变量分布、与breadth相关、年份/日期支持，不读取未来结果或调整分组数。

若无数据或支持不足，停止该设计而不调整阈值。若支持存在，另冻结收益检验计划：同日同格比较、原价格/动量对照、早期性与唯一事件另审；不是立即批准概率池。不得把“可计算”当作有效。
