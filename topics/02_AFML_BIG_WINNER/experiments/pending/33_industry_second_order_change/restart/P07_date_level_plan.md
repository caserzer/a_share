# P07：跨日期共同分数与成熟基准率诊断

2026-11-11，执行前固定。仅诊断P05 B及P06原事件，不改模型、选择、门槛或校准。

预测对象为每观察日全价格可用行业的126日联合成功率。比较三个当时可得日期基准：B原始分数同日均值；全部已成熟历史的行业周先按日期平均、再日期等权；最近26个有成熟结果的历史观察周均值。26为原主期限约半年尺度，不搜索其他窗口。成熟记录要求end126严格早于当日，标签KNOWN；缺失路径不填0，估计条件于可评价历史，报告支持日期数及最近历史日期/标签终点。至少26历史日期才发布基准。

先封存当时可得基准及支持收据，再连接评价日期真实成功率。报告日期基准均方误差、绝对误差、年度偏差、预测与实际相关性；基准误差之差用26周时间块区间。相关性只属描述，不据负相关倒置分数。评价2024以后既有预测时期，未成熟未来周不参与误差。

同一已知样本上精确分解原始Brier为日期均值误差＋日期内中心化残差；分别报告当日全部行业评分均值和未来已知子集均值的差，防止缺失改变母体。禁止用真实日期基准替换原分数来宣布可交易或可准入效果。

对P06已固定top20及raw_gate事件，报告日期共同分数、行业中心化分数及日期真实成功率的相关/年度均值，帮助定位跨日期与同日排序。不得重新选事件。若简单成熟基准仍跟不上实际水平，就不能认为添加校准截距足够；需要新增可预测的市场背景证据，或承认绝对高胜率当前尚无可靠依据。原最终标准不变。
