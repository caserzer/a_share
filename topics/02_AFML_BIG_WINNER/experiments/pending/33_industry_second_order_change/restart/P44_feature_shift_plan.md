# P44：当时可见输入的分布迁移审查

2026-11-11。不训练、不按未来表现选特征、不改准入。P43显示旧分类训练占比高，需检查是否存在具体输入分布差异，不能直接以分类或年份为regime。

固定P30八特征，每季度以当时成熟训练样本为参考，日期等权，非空值内重新归一。计算加权1/25/50/75/99分位和缺失率；每个测试观察日期计算低于1分位/高于99分位比例、缺失率、样本中位数相对训练中位数的IQR位移。训练IQR为0保留位移未知，不以微小epsilon制造巨大标准分数。区间两端是描述性经验范围，不是准入阈值。

参考分全训练、训练SW2014、训练SW2021；各自重新日期等权，并列训练日期数。SW2021少于26日期标支持不足但仍显示描述，不当可靠分布估计。测试仅使用当日可见特征，汇总逐季度/年度。分类比较跨时期混杂，不能因均值不同就推断分类是原因。

只使用标签是否存在及终点决定训练资格，不使用标签正负，所有结果封存。核对训练行数、分位单调、同一日期市场值唯一、全测试行业身份及每日期范围比例的分母。下一步只有发现具体问题才登记对应对照，禁止按照异常图筛掉2023。
