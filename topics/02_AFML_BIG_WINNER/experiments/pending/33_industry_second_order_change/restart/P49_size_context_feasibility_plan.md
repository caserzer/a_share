# P49：指数相对风格与行业规模的本地可行性

2026-11-11。不同于市场绝对趋势/广度和members数量，待核查机制为行业成分规模与大盘/宽基相对风格的交互。仅核查已有数据和构造，不读未来收益，不训练。EP32已将沪深300作为收益基准使用，不能声称该指数是新数据；EP33检索未见该规模交互实现。

CSI_ALL/CSI300的126日对数相对变化作为宽基相对大盘的描述；不是纯小盘因子，也混合行业组成、权重等。主成功基准仍CSI_ALL，不替换。用EP32既有monthly panel的cap，按前一月行业成员计算成员log(cap)中位数与有效覆盖，至少5个有效成员、覆盖>=80%才标可用。share_effective_date<=当时月末价格date，月末date必须早于观察日；允许历史proxy，不认证公告known_at。成员数量不能代替市值，成员中位市值不等于行业总市值。

P30全部价格合格周保留，规模缺失单列。检查CSI300加工版与原缓存逐日close一致、日期/代码唯一、原JSON哈希与receipt、monthly panel证券/月唯一、成员连接无重复、份额有效日与价格日期、前月时序；报告年份覆盖及极端缺失。若可行，后续须比较价格基线、加风格、加规模、二者联合，防止仅规模/共同市场作用被叫作交互。先审查可得性，不直接启动收益模型。
