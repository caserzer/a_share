# P46：价格模型的实际排序偏好

2026-11-11。P45固定映射在2023排序失效，但不能仅因模型包含动量就称其为动量策略。本轮只读P45已封存无标签分数和P30当时特征，描述实际偏好，不评价未来收益、不改变准入。

固定/季度更新模型均按同日全体计算分数与8特征的Spearman相关，常数列相关记未知，不填0。对同日前20%报告各特征在当日全体中的平均百分位、rate20/60非正比例以及全体对应比例。全期及年度日期等权。排名并列以原行业身份稳定排序，分位用平均秩。

这些是相关和选择构成，不是特征重要性或因果贡献：多输入相关时不能将某一相关归因于模型仅依赖该变量。不得据相关方向倒置分数或重新选择有利因子。固定模型与更新模型并列，用来明确既有候选的研究含义；原量化验收标准不变。
