# 经营信息事件重建：首轮结果

现有1647家公司原始财务分区已离线重建；63346条可计算且在现有交易日历内可用的代理事件，49758条可用于按时点推进公司的当前报告状态。3123条缺少营收依赖、232条分母或数值不可比，未填补。

55454条由当前报告更新时点限制，4595条由更晚的历史依赖限制，3297条与当前公告时间对齐。更新时间滞后不能直接解释为修订，可能包含供应商入库延迟；这些分类只描述时间约束。公告对齐也不认证首次披露。日期延迟分布见delay_summary.csv。

计算单季同比及其变化时，累计转单季、同比与相邻季度的每个依赖都显式列出；使用所有依赖公告/更新最大时间后的首个交易日。交易日历开始前已经可得的记录另标left_censored，只能用于初始状态，不当作首日新消息。旧报告晚到且已被新报告覆盖时保留台账，但不推进当前状态。

已通过合成记录核查：公告对齐、历史依赖晚更新、缺少可得时间三种情况。当前只完成事件可观察性和时间构造，没有检验未来收益，也没有证明经营新信息有效。

下一步：用过去月份的行业成员构造固定队列，分别记录新增披露、旧状态驻留、成员改变和覆盖改变，再评估行业事件覆盖和可比较样本。若无法将这些因素分开，不进入收益效果检验。
