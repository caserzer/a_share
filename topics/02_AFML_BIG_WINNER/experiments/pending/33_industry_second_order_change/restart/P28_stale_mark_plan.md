# P28：明确估值假设的固定集合敏感性

2026-11-11。修正研究解释：用户允许历史代理和部分缺失，P24的“任一成员缺价整篮子未知”是保守方案，不是用户新增硬要求，不能因此停止所有价格研究。P23所说没有依据把缺行认证为停牌仍成立；估值代理可以在不认证停牌/成交的前提下另列。

固定月初有效成员集合保持不变。只对源无当日行（NO_ROW）沿用同月最后已知、同锚点复权链的价格，标记STALE_PROXY及连续缺行交易日数。月初锚点不得用未来或上月末前价格补齐。存在当日行但价格无效/冲突、复权链缺失或不同，不填；显式链变化后本月不再桥接。冲突后未知持续至出现同锚点链有效报价。缺行标价不是成交价、不是停牌认证、更不是收益真实值。

先在P23相同34个月、690日做原型，不计算成功标签，不搜索陈旧天数阈值，不以胜率选择填值规则。保留原动态均值、严格未知、陈旧估值三套值。验证全部价格完整日等价、成员权重不变、逐日前缀重放、缺行无虚构报价收益、恢复仅反映累计价格变动、已知冲突/链变化不跨越。披露陈旧日数/权重，不以“已估值”代替“已观察”。

如原型成立，全历史仍需另定月末陈旧估值与下月锚点连接规则，并分层报告标签端点/路径是否依赖陈旧估值。正式方法不能只挑对自己有利的估值版本；原60%等标准不变。
