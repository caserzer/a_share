# P17：2023有明显市场环境影响，但尚未得到可事前识别的失败regime

2026-11-11。固定P11原模型、名单及评价母体，拆分收益目标，检查当时可见的126日/21日市场趋势四格。全部是已查看历史上的探索，不是独立验证；未训练、校准或修改准入规则。

2023名单失败几乎全部属于绝对收益非正；2025非上涨信号之后大多已经上涨，主要瓶颈转为跑赢。对应信号日期的后续126日CSI_ALL平均收益依次为−7.70%、+10.27%、+22.27%。这些未来市场收益只用于解释结果，绝不能用于信号分组。年份是信号年，收益可能跨至下一年；重叠期限不是独立年份实验。

同时，2023模型相对跑赢率41.52%仍低于全行业45.43%，上涨率也低于全行业24.19%。因此市场环境解释了机会少，但不能替模型排序失效免责。不能从这张表推导市场的因果贡献比例。

## 自我反思与下一步

用户的regime问题比直接接入事件字段更接近当前信息缺口：同样的行业价格结构，在不同未来市场路径下，联合目标的约束不同。但“事后环境不同”与“当时可识别、可用来管理研究池”是两个不同命题。本轮支持前者，未证明后者。

停止对本轮四格扫描窗口/阈值，也不把2023剔除。下一项有理由的检验应聚焦市场内部参与度：在相似指数趋势下，行业上涨广度及其变化是否提供机会环境信息。广度并非全新字段（P05 D包含扩散变量）；若继续，必须先明确这是市场环境交互诊断，与旧D模型消融的区别，并审查跨年支持，避免换名字重跑。只有事前环境信息跨期成立，才考虑将概率拆成上涨概率与上涨条件下跑赢概率；目标联合成功、最终门槛和事件计数不变。不能仅因本轮展示了两个结果就开始双模型校准。

## 核验

原始连续行业块按次日入场重建三期限，126日联合标签与成熟终点逐行和原评价面板一致；60条独立原始路径×3期限检查，市场21日回看、同容量名单、失败分区恒等式、选择文件封存通过。另与P12的7个有输出年度/大状态联合胜率逐项对齐通过。完整结果见annual.csv、annual_broad.csv、comparisons.csv、daily.csv及validation.json。

首轮执行在选择封存前遇到NumPy字符串拼接不支持，改用pandas字符串拼接后运行；没有结果驱动的设计变更。验证只证明计算一致性，不证明经济有效性。原最终标准保持不变，目标active，尚未批准高胜率研究池。
