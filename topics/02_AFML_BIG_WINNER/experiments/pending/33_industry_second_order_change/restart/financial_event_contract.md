# 经营新信息：数据构造前约定

仅重建事件和可观察性，暂不查看未来收益。对单季营收YoY及其相邻季度变化，列出累计转单季、同比和相邻季度所需的全部报表依赖。可用日采用所有依赖NOTICE_DATE/UPDATE_DATE最大值后的首个交易日。未知日期、同报告期多条记录或无有效分母保留受限记录，不择优补值。

区分当前公告对齐代理、当前报告更新滞后、旧依赖更晚可得；即使公告对齐也不能认证首次披露。聚合前保留每个公司的事件时间、报告期、依赖清单和增长/加速度，后续在固定行业成员队列中比较新旧共同可观察公司，不能把新纳入公司造成的均值跳变解释为经营改善。

先核查事件数量、时间错位、源覆盖；再冻结泛行业对照实验。现阶段不会将某一事件直接纳入高胜率研究池。
