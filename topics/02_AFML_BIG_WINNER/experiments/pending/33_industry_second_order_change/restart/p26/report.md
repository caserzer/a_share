# P26：新版价格固定基线重放未改善准入效力

2026-11-11。完成特征重建、支持审查和原参数滚动重训。未取得可推进概率准入的结果，不继续调参或校准该基线。

## 可比性和训练支持

新版符合资格的63,536个历史行业周，在共同完整窗口中的8项B输入与P13旧版逐项一致（最大价格率数值误差约3.6e−15）。这符合P25机制：新版主要屏蔽不可比较路径，不是在完整路径中产生新价格信息。volume_ratio沿用旧当时量能描述并对齐，尚未研究量能构造。

2023Q1有7,698条成熟训练记录、206个日期，所有16个季度均满足原最低500行/26日期/两类要求。模型clone原P05实际参数，采用2017起扩展训练和日期等权，终点严格早于训练季度。预测先封存再评价，没有选择新超参数。

2023起全目录65,272条行业周中，37,791条可评分，其余27,481条保留DATA_INSUFFICIENT。可评分仍只是RESEARCH_SCORE_NOT_APPROVED，原始分数不是校准概率。各年可评分10034/10531/9477/7749，目录母体分别16771/17176/17861/13464。

## 自我反思

P22—P26完成了数据问题发现、可追溯重建、覆盖审计和固定模型重放。实质结论是：旧价机械跳变必须隔离，但采用固定集合保留未知会损失大量样本；共同完整价格信息并未增加，重训没有带来稳定选择优势。不能将数据清理当作新的预测机制。

此基线的调参、概率校准和门槛修补继续停止。未来要推进原泛行业目标，必须拿出区别于已有失败分支的可观察信息依据，同时解决未知路径的评价识别，或有新的本地数据证据支持更准确的估值处理。不能因为现有模型失败就降低60%/5pp/覆盖要求，也不能把完成数据工程当作完成研究池目标。

当前全目录状态文件用于保留研究和缺失信息，尚缺可信概率、正式准入方法及完整失效条件，不是最终交付的高胜率池。目标active、未完成。
