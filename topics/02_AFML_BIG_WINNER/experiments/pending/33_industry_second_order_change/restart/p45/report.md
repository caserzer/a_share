# P45：固定价格映射后，2023排序失效仍存在

2026-11-11。冻结P30的2023Q1模型，对2023起相同51,046行业周评分；不重训、不选择冻结日期、不反向排序。分数在当时可计算，但此次研究使用已反复查看历史，不是独立验证。

## 固定映射的跨期表现

126日，同日期等权，AUC只在同日成熟标签有两类时定义：

|信号年|成熟日期|固定模型AUC|更新模型AUC|固定前20%胜率|全行业基准率|固定前20%增量|
|---|---:|---:|---:|---:|---:|---:|
|2023|50|0.423|0.434|20.51%|27.03%|−6.52pp|
|2024|51|0.521|0.533|63.54%|58.03%|+5.51pp|
|2025|53|0.500|0.540|46.10%|47.65%|−1.55pp|
|2026成熟部分|13|0.554|0.579|23.16%|18.89%|+4.27pp|

AUC=0.5表示此指标下没有排序区分力，不表示50%成功概率。2023固定模型AUC的26周块描述区间[0.400,0.449]，更新模型[0.418,0.451]，均低于0.5。固定前20%增量区间[−7.67,−5.42]pp。这说明2023失败既包含低基准率，也包含所学映射排序错误，不能只归于市场上涨机会少。

2024固定AUC区间[0.455,0.583]跨0.5，2025[0.484,0.516]接近无区分。即使2024前20%表现为正，也不能用不同排序统计的单项显著性选择结论。2026仅13个成熟日期，不把短样本区间用于全年认证。年度50多个周对应大量重叠半年结果，不能当50个独立周期。

全期固定AUC0.488，区间[0.450,0.530]；前20%胜率41.98%，增量−0.43pp。更新模型全期AUC0.509，区间[0.466,0.554]；前20%胜率45.51%，增量+3.11pp区间跨零。这里是持续名单日期等权，不与P30唯一边沿46.02%/−0.71pp混用。63/252全部敏感性保留，不改主期限。

## 可以和不能推断什么

1. 季度换模型不是跨期排序差异的唯一来源。固定映射在2023依旧失败，市场共同机会率也明显随时期变化。
2. 这与价格状态对应的结果关系随时期变化相容，但不能单凭AUC证明经济机制或严格的条件分布漂移。不同期特征组合、行业构成、代理质量和模型初始估计误差仍是竞争解释；P44只检查了单变量分布。
3. 没有当时可见的状态识别器，因此不能按年份倒置排序、切换固定/更新模型或删2023。AUC低于0.5是事后反证，不是反向策略授权。
4. 此模型是统一诊断尺度，不是新增准入候选。没有重新进行概率校准、最终事件验收或覆盖宣传。

## 对推进方向的约束

P43–P45已把“regime可能有影响”进一步限定为三个可复核事实：半年反馈滞后、单变量输入未明显越界、固定映射在2023仍失效。尚欠缺的是能在当时观察到并跨阶段复现的区分信息，不能用再加一个状态标签代替它。

后续若提出环境机制，必须先说明它与既有市场趋势、参与度、beta、同行上下文、抗跌和退出窗口有何实质不同，并预先规定支持范围与竞争对照。没有该依据，不继续遍历状态数、年份切分或模型版本。原泛行业目标和量化验收不变，目标active且无达标池。

## 核验

2023Q1预测与P30逐项复现，训练最大标签终点早于2023-01-01。先保存51,046条无未来标签分数再连接评价标签。半年167个成熟日期均有正负两类；334项固定/更新模型AUC通过独立Mann–Whitney平均秩恒等式核对。源和输出哈希见prediction_seal.json、validation.json。块区间沿完整周轴保留未知；未做多重检验校正，计算正确不等于可交易。
