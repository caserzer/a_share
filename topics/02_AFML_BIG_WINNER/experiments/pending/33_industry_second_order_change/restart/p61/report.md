# P61：修复标签没有改变既有市场机会率预测的失败结论

P19已预测未来半年全行业绝对上涨比例和联合成功比例，与用户的市场下跌问题直接相关。本轮固定其全部预测，仅将评价目标替换成P59修复价格版本，保持至少95%标签覆盖、194周轴、日期等权以及全期限26周块500次。不重新训练。

## 反思与决策

标签版本变化没有挽救这组既有市场特征和固定模型。停止以价格修复为理由重新调整其窗口、正则或过滤阈值。该结论局限于固定旧训练/输入的预测，未证明所有市场机会预测都不可能，也不能代替完整新版模型验证。

应修正“先判断市场是否有足够机会”的表达：这是需要检验的研究问题，不是必须先攻克的宏观预测前置条件。最终行业联合成功概率可以包含共同市场因素；独立市场门控只是可选方法，不能因它失败就使整个泛行业研究长期滞留于大盘预测。用户的价格/动量初筛优先仍有效，允许少入池/空池但必须有事前证据，不能强制填满或按年份删除。

当前已测名单和市场门槛都没有达到原目标；没有准备好进入校准或正式池的候选。任何后续研究需明确实质不同的信息依据，不能把同一组特征反复换包装。目标未完成，pool_metric_v1保持不变。
