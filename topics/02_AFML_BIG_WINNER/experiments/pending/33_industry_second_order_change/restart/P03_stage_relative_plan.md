# P03：在线价格阶段与低点以来相对改善

执行前登记，2026-11-11。P02发现早期状态并不等于已上涨，也未建立行业区分力。本轮问：在同一天的早期候选内，已出现价格上行确认及低点以来跑赢市场，是否增加后续联合成功率？这不同于R10固定20日速度/加速度，区别仅为EP32在线阶段及随阶段变化的回看起点；不是新的经济机制证据，不称首次独立验证。

只用已有EP32 V7状态（15%转折、候选低点后三个月在线资格）、P01价格特征和EP33标签。同一行业日期不同频率必须状态完全相同后才去重；不使用未来自然周期低点。使用2021—2026可用三级行业周，单列2021—2024-09旧共同期及其后期间，后者也已被查看，不称holdout。

固定2×2划分：状态方向+1为已确认上行，−1为未确认修复候选（可能仍在下跌，不能称已修复）；候选低点至今行业涨幅减中证全指同期涨幅>0为相对改善，否则为未改善。零归未改善。保留所有四组，不搜索阈值/窗口，不挑最好组作为准入方法。

主信息检验：同日同阶段内，相对改善减未改善的126日联合胜率差；同日同相对方向内，已确认上行减未确认候选的差。每组两臂各至少5条当时记录；按可同时评价的日期等权，26周时间块95%描述性区间。报告63/252敏感性、配对日期、未来缺失和年度，四项对比均完整呈现；不把粗分层当作精确控制或因果效应。

四组另报告周状态及126交易日冷却的首次观察入池：胜率、同日全行业增量、同日全部早期候选增量、成功行业周覆盖、未知、每周规模。全部组用同一计数规则、次日收盘收益；63/252沿用126日计数，252存在重叠。记录候选低点年龄、已上涨幅度、前63日涨幅。不能用不同组中位年龄之差宣称同一机会的确认延迟；该问题需后续同机会跟踪。

在连接未来标签前封存特征和选择。先检查各组规模，若不足只能报告证据不足。只有有一致信息线索时才考虑下一轮验证，不校准概率，不改变最终验收。市场上涨仅作为预定分层诊断，不选结果最优市场状态。
