# P14：现有事件资料可观察性与行业覆盖

2026-11-11。只盘点与构造覆盖，不检验收益、不改价格候选。已知本地EP30源目录含财务、公司行动、收益率曲线、估值；该受检目录没有已识别的泛行业政策/新闻冲击结构化历史。公司行动日期不自动视为首次公告，收益率曲线是状态而非发布事件。

对已有financial_events重建资产，使用state_accepted且非left_censored事件；known_date为完整依赖可用后首个交易日。每行业周使用前月固定成员，所有可匹配成员都保留在分母，未解析成员计入未知。报告过去21交易日内至少一次可用更新的成员数；另报notice_to_available_days<=7的近公告代理，仅是时间质量分层，不认证首次披露，也不据此偷偷倒移延迟记录。

分别报告全部价格母体、固定P11 top20和NONUP候选：至少1成员更新、至少3成员更新、3成员且占成员>=30%的覆盖（后者沿用旧财务覆盖尺度，仅诊断）。同日固定队列消除把新成员加入当新公告的混淆；成员缺失不填无事件。按年统计，保留所有空档。known_date>观察日的更新不可用，窗口外旧状态不当新冲击。

财务更新不等于意外冲击，营收加速度不等于超预期；本轮不将财务公告等同全部事件。若覆盖与时间语义不足，不直接开展收益模型。
