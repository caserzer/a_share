# EP33：基于现有数据的行业二阶变化发现与配置研究候选筛选（允许历史代理）

创建日期：2026-11-11（Asia/Shanghai）。

状态：**原始目标仍保持开放。** R00–R05是收益筛选旁支；纠正后已执行R06–R08，形成连续案例、时机与确认代价证据，见reports/onset_process_report.md，尚未找到统一二阶起点指标或机制解释。2026-11-11用户确认偏离在于“优化收益筛选，却没有真正研究变化如何开始”。本修订纠正目标排序，保留旧实验，不以其收益结果作为原目标完成证据。仍仅用现有数据，允许历史代理与部分缺失，并保持想法—实验—数据—反思—调整循环。

## 1. 用户确认的目的与范围

本实验承接 EP32，用户明确的优先级是：

> 帮助决定配置哪些行业；这是进入研究 pipeline 的起点。优先寻找变化的起点，尤其是二阶变化。只利用现有数据基础；不要求严格 PIT，接受部分数据缺失。

**主目标：研究行业变化如何开始，尤其是变化速度何时、如何发生改变；重建当时可观察的先后过程，区分早期迹象、后续确认与相似的短暂扰动，形成值得进入配置研究 pipeline 的可检验假设。**

输出首先回答“什么在变、何时第一次可观察、证据如何发展、什么解释可能被推翻”。配置价值是最终用途，未来收益是后续检验；不能由收益改善反推已经发现起点，也不能为提高收益而无记录地推迟发现。

用户尚未指定持有期限、每期研究名额、假警报容忍度，以及两类二阶变化的优先顺序。不得将这些选择写成用户已确认的要求；探索中可以比较并修正这些设定，但须记录理由与完整结果；用于确认性评价的设定在该次验证前冻结。

## 2. 要寻找什么变化

区分变量水平、一阶变化与二阶变化：水平描述当前状态，一阶变化描述改善或恶化，二阶变化描述改善或恶化速度的改变。

并列研究两类候选，分别报告，不先假设哪类更有价值：

1. **恶化减速／转向候选：**状态仍弱或一阶变化仍为负，但恶化速度下降，可能接近转向。
2. **改善加速候选：**一阶变化已为正，改善速度进一步上升，可能进入增强阶段。

二阶变化是待检验的信号假设，不等于已经确认的拐点。变化可中断、反复或反转；单次正二阶差分不构成成功。

分别识别以下证据对象：

- **价格与交易变化：**相对表现、波动、回撤修复、成交状态及其变化速度。
- **行业内部扩散：**改善是否从少数公司向更多同业扩散，改善比例及扩散速度是否变化。
- **基本面变化：**仅在已有字段具有可靠披露时间与历史版本证据时研究，例如经营指标增速的变化。
- **市场预期变化：**只有现有数据确实包含可追溯的预期记录时才直接检验；价格、PE 或成交变化不能替代盈利预测修正或预期差的认证证据。

若只能观察价格与扩散，应明确输出“价格／扩散二阶变化候选”；不得称为已证实的盈利、需求或经济景气拐点。

## 3. 数据约束：仅使用现有数据，保留时序纪律与质量标记

### 3.1 已有来源与当前已知边界

优先核查 EP30 已归档数据及 EP32 已有输入的来源链、版本与读取接口：

- [EP30 数据基础说明](../30_pit_data_foundation_v1/README.md)：身份、历史状态、行情、公司行动及部分财报版本；各域质量不同。
- [EP30 D2-v5 封存入口](../30_pit_data_foundation_v1/outputs/pit_v5/release.json)：前复权价格推断数据，既有质量标记为 Historical-proxy，不能因位于 PIT 项目中而自动准入严格结论。
- [EP32 综合报告](../32_industry_rotation_cycle_observation/reports/consolidated_20261109/report.md)：行业构造、成员、价格状态、扩散特征与既有模型的可复核定义。
- [已有 TTM PE 覆盖报告](../30_pit_data_foundation_v1/extensions/v6_ttm_pe/reports/ttm_pe_coverage.md)：历史财务分母版本未认证，不默认作为 PIT 估值特征。

上述来源报告的数据终点为 2026-10-21；这是文档记载，不代表 EP33 已核实实际文件或之后覆盖。执行时记录本地实际可读取的 release、哈希、字段覆盖及终点；本地不存在的归档不得视为已取得。

### 3.2 准入规则

1. 不新增外部采集、不购买数据、不引入新闻、研报、订单调查或新供应商；允许对已有合格数据进行离线派生。
2. 按字段和记录区分 `PIT-certified / PIT-reconstructed / Historical-proxy / UNKNOWN`，同时区分经济生效时间、公开可得时间和本地取得时间。
3. 允许供应商历史回溯和历史重建输入，不因缺少完整版本链阻断价格主实验；输出明确 Historical-proxy。仍不得主动引入未来记录，不以财报期末日期代替披露日期。财务版本不明须披露，不将其解释为已认证基本面拐点。
4. 行业成员、分类制度、证券身份、股本排名和公司行动同样需审计。不得用今天的行业成员或市值排名倒填历史；SW2014 与 SW2021 不强行拼接。
5. 今日重锚的复权数据不能让未来公司行动改变过去特征；截断未来数据后，旧时点特征和候选应保持不变。价格比例对重锚不敏感本身不足以认证整个来源的 PIT。
6. 用户已授权 Historical-proxy 进入 EP33 主探索，无需另立项。部分缺失允许保留；逐日期、年度、行业和特征报告覆盖，缺失不填零，不因未来结果选择完整样本。
7. 缺失、冲突、未成熟保留 UNKNOWN。基本面不可用时停止对应分支，不用价格或 PE 冒充基本面变化；仅当实际缺少可计算的行业身份或价格输入时阻断相关分支，不因未达到严格 PIT 认证而阻断。

本修订依据用户追加授权放宽数据质量准入；不改变缺失处理、反前视、成熟标签和如实报告的要求。R00 严格门槛的审计结果保留作历史记录，不再作为主实验启动障碍。

## 4. 研究对象与待检验假说

以全部可准入的申万三级行业作为配置候选的主观察层，二级行业仅作独立稳健性／层级关联分析；这是继承细分行业用途的初始研究设定。公布全目录、可用、缺失和受阻清单，不设事后成功行业池，不把父子行业当独立机会相加。若实际可用范围有限，结论仅覆盖该范围。

以下是重启时的研究问题，尚未形成固定筛选规则：

| 问题 | 需要观察的证据 | 必须保留的反例 |
| --- | --- | --- |
| 恶化如何开始减速 | 原趋势、速度变化及首次可观察时间的连续轨迹 | 减速后继续恶化、短促反弹、纯噪声 |
| 改善如何开始加速 | 从原状态到变化的过程，而不只是某天加速度排名 | 加速迅速消失、只有少数公司跳变 |
| 各种迹象按什么顺序出现 | 相对价格、行业内部扩散、成交和可用财务信息各自的出现/可得时间 | 顺序相反、不同步、缺失而无法判断 |
| 更多确认是否牺牲早期性 | 首次异常到后续确认的时间、期间已经发生的变化 | 确认虽提高收益表现，却已错过研究介入阶段 |

价格动量差分只是一个候选代理，不能先将它定义为真实变化。已有财务字段可以用于解释顺序；缺失或修订不明时保留“无法判断”，不编造基本面机制。

## 5. 研究循环与方法原则

### 5.0 想法—实验—数据—反思—调整

**迭代探索是 EP33 的主体。实验结果用于更新对问题的理解，并决定下一轮实验；不要求一开始就知道最终正确的变量、窗口、标签或模型。**

每轮按以下顺序执行，并形成独立的研究记录：

1. **提出想法：**说明观察、机制猜想、与配置研究的关系，以及什么证据会支持或推翻它。后续轮次须引用上一轮的具体发现。
2. **设计最小实验：**选择能区分当前想法与竞争解释的比较，记录输入、数据范围、变量、参数、评价口径和预期现象。优先一次改变一个关键设计；需要联合改变时明确解释。
3. **取得数据结果：**保留完整结果、覆盖、失败和反例；先确认实现与数据是否可信，再解释统计现象。不仅输出一个综合分数。
4. **自我反思：**先检查本轮是否仍在研究变化如何开始，是否用收益改善或趋势确认替代了发现起点，再对照原预期解释哪些发现改变了认识。至少检查：假说是否不成立、指标是否表达错了概念、数据是否不足、结果是否来自动量或市场共振、是否仅由少数样本驱动、是否因反复选择产生偶然改善。结果好也必须反思，不能把上涨或显著自动视为机制成立。
5. **调整实验：**根据反思选择保留、修改、分支、放弃或进入验证。可以调整特征、窗口、标签、候选规则和模型，但须说明调整解决哪个问题、预期出现什么新证据，以及下一轮如何区分竞争解释。
6. **进入下一轮：**登记新的实验版本及其父轮次，不覆盖旧结果。若没有可检验的新解释或现有数据无法区分解释，应收束为无效、不确定或数据受阻，而非不断调参直到得到正结果。

每轮最小记录为：`round_id / parent_round / 想法 / 可证伪预期 / 实验设定与数据版本 / 完整结果 / 反例与竞争解释 / 自我反思 / 下一步及修改理由`。反思必须引用本轮结果，不接受“继续优化参数”这样的空泛结论。

**探索与验证分工：**探索可以反复使用已知历史、根据结果修改方法；这些结果是形成假说的证据。候选方案趋于稳定后，冻结该版本再进行验证，并披露验证数据此前是否已被查看。看过的验证结果若用于下一轮调整，该数据就进入探索记录，不能继续声称对新版本独立。没有未使用的数据时，报告探索性或历史模拟证据，不虚构独立验证。

每轮结尾检查是否继续：有明确、可由现有数据检验的新问题则继续；发现数据错误先修复并标记受影响轮次；关键输入不可得、有效样本不足或剩余方向只有无理由的参数遍历时停止相应分支。资源预算和最大轮数在执行计划中记录，耗尽时交付当前认识与未决问题，不把轮数用尽当成研究成功。

固定的是配置研究目的、仅用现有数据（允许历史代理与部分缺失）的范围、时序正确性与完整留痕；具体研究方法可以在循环中演进。若需要改变用户目的或扩大数据范围，另行讨论。

### 5.1 从可解释变化指标开始

- 区分当前水平、历史斜率、斜率变化、持续时间和覆盖宽度；先检验二阶信息相对一阶信息的增量，再考虑组合模型。
- 对二阶变化做尺度与噪声控制。每轮采用有限、事前记录的窗口／平滑方式；允许根据反思在下一轮调整，保留全部尝试，不只报告最优组合。
- 财务变化须处理季节性、低基数、零／负分母及一次性项目；无法处理时标明不可比，不产生虚假高加速度。
- 所有平滑为单边回看，不用居中窗口或事后确认拐点生成特征；标准化、阈值和模型只在当次训练信息集中确定。
- 可设置“发现”和“确认”两个状态；分别评价提前量、假警报、确认延迟和候选质量，不把增加等待时间的改善免费计入收益。

### 5.2 先重建过程，再提出可计算假说

从具体行业连续时间轨迹开始，按当时可见信息逐步回放；先记录观察与判断，再打开后续数据检查它如何发展。不能只选后来大涨的行业，也不能只研究旧筛选器报警的日期。

案例抽样须在查看本轮后续结果之前记录：按行业/时期/数据覆盖选取连续片段，兼顾不同时期和缺失程度，不按未来收益筛选。完整保留无明显变化、短暂扰动和持续变化片段。研究者已经见过历史，应明确这是模拟遮蔽回放，不是独立盲测。

每个片段分开记录：

1. **原有状态与观察到的变化：**变化前是什么状态，哪项观察首先偏离该状态。
2. **首次可观察时间：**只有当时数据时，最早能提出什么假设，证据和未知是什么。
3. **后续发展与确认时间：**后来的数据强化、修正还是推翻了假设；新增确认花费了多久。
4. **事后参考转折：**如需用未来路径定义转折，仅存于评价侧；允许多个合理定义及起点区间，不将一个事后低点当作唯一真值。

先在案例中形成可以被推翻的过程假说，再用更广行业面板检验。不是先确定一个二阶公式，再不断调参直到未来收益更高。

### 5.3 主要评价与对照

主要评价的是变化发现：首次提示相对事后参考转折/后续确认的提前或滞后、提示时已有变化幅度、漏掉的变化、未演变为持续变化的提示、反复报警负担，以及证据顺序的可重复性。分类定义和参考时点须说明，不把单次差分符号当成成功标签。

“早期提示”和“等待确认”在同一批连续片段中比较，同时报告假警报减少和确认延迟；只降低误报而未衡量延迟，不算改进发现能力。动量排序及R00–R05规则作为参照，检验其何时才开始注意到这些变化，不以其收益作为新的主优化目标。

未来固定期限收益、回撤和机会成本放在次级配置价值评价中。126交易日、K=10、21日差分和8/10日持续条件都仅属于旧旁支的选择，不自动继承为新主线默认答案。不得为了得到更好的收益曲线而改写起点或案例定义。

## 6. 时间验证与结论标准

1. 按时间滚动训练与评价，禁止随机打散。仅使用拟合时点已成熟的标签；特征、标签、缺失处理和选择规则保存版本与时间戳。
2. 处理持有期重叠、重复行业事件和横截面共同冲击；报告按时间分块的不确定性及有效样本量，不把行业周数当独立样本数。
3. 每轮查看结果前记录本轮假说、端点、候选数、窗口、对照、阈值与统计方法；结果之后必须反思并决定下一轮。累计披露尝试数量、选择路径和多重比较影响。确认性验证另冻结完整方案，不把探索中选出的最好结果直接当作确认性证据。
4. 既有历史已经被 EP32 等研究反复使用。时间滚动回放仍属于历史模拟验证，不称独立前瞻证据；本次仅使用现有数据，不能承诺获得未来验证结果或自动启动采集。
5. 首先检验是否更早、更准确地识别变化过程，同时报告误报、遗漏、确认延迟和覆盖；然后单独评价后续配置价值。收益显著不替代起点识别证据。
6. 结论允许 `SUPPORTED_HISTORICAL / UNSUPPORTED / INCONCLUSIVE / BLOCKED_DATA`，附每个分支的实际数据质量；没有新时段证据时独立前瞻保持 `FORWARD_PENDING`。数据不足不是假说被否定，历史支持也不是投资策略已成立。

## 7. 研究 pipeline 的预期输出

每个候选生成可复核的变化假设卡，至少包含：

- 行业、连续观察区间、原状态、首次提示时点、后续确认/否定时点及数据质量；
- 什么变量在变：水平、一阶变化、二阶变化、持续性和扩散范围；
- 当时为什么开始值得调查，新增证据相对上一观察时点改变了什么认识；
- 已有证据、竞争解释和现有数据无法回答的问题；
- 后续研究需验证的具体问题，以及当时即可写明的失效条件；
- 同类行业关联、重复报警身份、待到期的评价期限与状态。

不得填造订单、调研或盈利预期结论。后续待验证事项可以超出现有数据能力，但 EP33 本轮不执行新增数据采集。变化假设卡的市场表现可评价候选质量；整个研究 pipeline 是否改善最终配置，仍需后续决策记录验证。
