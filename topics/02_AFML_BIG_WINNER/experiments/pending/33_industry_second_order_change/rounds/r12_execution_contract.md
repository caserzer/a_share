# R12 执行补充：运行前冻结实现细节

主协议pool_metric_v1不变。此补充在本轮任何模型结果产生前写入。

- 数据：既有R11面板，恢复price_eligible为全行业价格准入；不要求财务完整，不把财务子池当全池。公司数量>=3且财务覆盖>=30%才使用营收增长/加速度，否则特征缺失；财务覆盖与缺失标记保留。
- 标签仅126日用于训练和校准；63/252是同一研究池的期限敏感性，不以各期限重新训练后择优。无行业身份哑变量，不针对个别行业拟合规则。
- 测试从2024Q1至现有2026Q4完整周，每季度首日固定一次拟合。以拟合日减18个月作为校准观察期起点；训练记录的126日标签终点必须早于校准起点，校准记录日期>=该起点且标签终点严格早于拟合日。这样训练标签不跨入校准观察区，且测试时不存在未成熟训练/校准标签。
- 最低训练500条/12个日期、校准500条/12个日期、两者各至少两个标签类别。不足则该折UNKNOWN，不更换分割救结果。每个训练和校准日期总权重相同、整体权重均值归一到1，控制截面大小差异。
- 模型共6个：matured_base（拟合日全部成熟标签的日期等权基准率）；logit_price（一阶价格/市场/覆盖）；logit_levels（加营收当前增长与财务覆盖）；logit_second（再加价格、扩散、营收二阶信息）；tree_levels与tree_second（同对应特征，非线性消融）。
- 一阶价格特征：rate5/rate20/rate60、breadth21/breadth63、volume_ratio、vol60、market126、market_breadth_up_fraction、coverage、members。层次特征再加growth、finance_coverage。二阶特征再加rate_change、low_count_change、breadth_change5/20、finance_acceleration。这些已有特征是代理，不认证经济机制。
- 预处理仅在训练集拟合：中位数缺失填补、保留空特征、缺失标记；逻辑回归再标准化，C=0.1、L2、max_iter=2000。树为HistGradientBoostingClassifier，max_iter=100、learning_rate=.05、max_leaf_nodes=7、max_depth=3、min_samples_leaf=100、l2_regularization=10、early_stopping=False、random_state=3312。
- 各非基准模型用独立时序校准集拟合单调非降Platt校准：logit(p)斜率>=0，固定轻微L2惩罚；不允许测试结果选择校准方法。拟合系数及损失单独保存。
- 先封存逐行预测（无未来结果字段）、模型/校准参数、训练/校准/测试索引和输入/代码哈希，再启动评价脚本读取标签。全行业平均预测值只用同日期当时可评分的价格合格行业计算。
- 模型季度更新造成的入池单独计数；第一观察周或价格/预测缺口后的边界不作为已知首次入池。126交易日冷却敏感性基于当时首次进入事件顺序，不看后续标签。
- 原协议的主验收指标按首次入池事件计算。全行业基准以同日全部价格合格行业已知结果均值为参照，按可评价入池数量加权；同时输出按原入池数量选出的同容量动量对照（不能用成熟数量反向选样）。
- 时间块区间使用26周整周截面圆形块重采样1000次。报告实际成熟事件数、日期数和有效块数量，区间不当多重比较认证。年份/季度、概率分箱与全池Brier完整输出。样本及历史已使用，不称前瞻独立验证。
