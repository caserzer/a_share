# R01 结果与反思

详表见 outputs/r01/paired.csv；以下为月度等权的日期配对差值，126交易日主端点。

- 改善加速：加速度排序减同池动量排序 +0.3812个百分点，六个月块区间 [-0.9495, 1.6921] 个百分点；不足以支持增量。
- 恶化减速：-1.1595个百分点，区间 [-1.9169, -0.4206]；本轮大加速度筛选较差。
- 全池：+0.6202个百分点，区间 [-0.9126, 2.2543]；不确定。
- 63日改善加速为正，但这是辅助期限，不能替换主端点。全部9项比较属于已知历史探索；未做多重比较调整，不以一个正区间宣称发现规律。

反例：恶化减速候选的描述性平均超额为正，也不能说明加速度有用，同池动量对照更好。不能只报告候选涨了多少。

反思：加速度 = 本期相对变化减前期相对变化，较大值可能来自前期跌得深，未必来自持续改善；对比动量并未严格控制风险和一阶水平。完整配对日期会排除部分未来路径未知的日期，选择偏差仍需诊断。周频及长持有期高度重叠，区间不是独立机会计数，252日应另做更长时间块敏感性。

下一轮 R02：保留21日尺度、126日主端点和10个名额，分别引入“近10日加速度至少8日为正”与“同业上涨宽度改善且改善速度为正”。做单项与联合消融，检验假警报是否来自短促、未扩散的价格反弹。若无改善，不继续盲目调阈值。随后 R03 处理动量/波动混淆和缺失敏感性，而非搜索窗口。
