# R08反思：确认的收益很有限，研究介入损失却不可忽略

同一批2914个已知pressure_easing事件，在共同第5–8周终点下：全部早提示有49.07%未形成持续相对改善；前4周等到广泛确认者为46.11%，只减少约2.97个百分点，但只保留1484个最终持续事件中的1024个(69.0%)，漏掉460个，已接受事件中位多等2周。长周期确认未持续率47.46%，只保留37.6%；旧10名名单保留12.7%，中位等3周。该比较是观察性过程评价，不是因果或独立预测证明。

短期反弹基线覆盖四周局部低点参考77.94%，中位滞后1周；pressure_easing为64.79%、1周。单纯恶化减速为77.87%、0周。pressure_easing未匹配该参考比例较低(33.77% vs slowdown41.18%)，代价是减少覆盖并推迟，不能说全面更好。“未匹配参考”也不等于永远没有有用变化。

27.20%的正相对速度行业周，绝对上涨宽度仍不足一半；可见市场背景的广泛确认中约50.96%处于至少70%行业同时宽度上升的周。绝对扩散不是行业独特改善的充分证据。既有财务代理期内1817次加速度由非正转正，其中341次同时发生>=10个百分点覆盖变化；这不能证明全部由缺失导致，但必须阻止“财报确认了起点”的轻率叙事。

回到原问题的认识：
1. 变化通常是一段多证据不同步的过程，首次可疑迹象、方向反转、扩散和长期确认是不同时间，不应压成同一个“起点”。
2. 新低减少并非比所有简单观测更早；它更像降低杂乱提示的确认环节。当前未发现稳定、独一的二阶起点指标。
3. 原收益筛选偏离的重要原因得到直接证据：严格确认/少量排名会舍弃大量后来形成持续变化的早期研究机会。
4. 改善中的二阶转负不等于趋势结束；恶化减速与已有改善加速应保留不同的原状态及解释。

本轮完成过程诊断，未证明经济机制或全新预测能力。下一阶段若继续，应针对“相对扩散与共同市场反弹如何区别”或“旧窗口退出造成的机械减速与新信息变化如何区别”各提出一个具体可证伪假说；不自动增加阈值去优化收益。本轮将收益描述放在附表，输出之后不再据其调整本轮方法。
