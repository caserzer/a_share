# R03：状态筛选、动量排序与二阶残差信息

父轮次R02。最后一轮本阶段价格探索；不搜索新参数，不当独立验证。

共同特征池要求R01资格及已有63日波动、63日相对表现可计算。按每日期、两类状态分别对加速度回归截距+21日相对动量+63日相对表现+63日波动，使用当日特征横截面，不读取任何未来标签；至少20行业。残差排序检验二阶信息是否只是这些特征的线性组合。

比较 residual、acceleration、velocity 三个前10名单；joint_velocity与joint_acceleration采用R02固定联合条件。同日配对比较时各取 min(10,双方已选数量)，未满10与空信号都披露；不按未来收益已知性改变名单。主期限仍126交易日。各年、全期以及未来结果共同完整日期和各自已知样本分别报告，6及12个月时间块区间仅描述探索不确定性。所有结果不进行择优拼接。

预期：若联合状态+动量优于单纯动量但残差无效，应收束为“状态过滤候选”，不声称二阶幅度有稳定排序优势。若年份符号不稳定或缺失敏感，则维持不确定。
