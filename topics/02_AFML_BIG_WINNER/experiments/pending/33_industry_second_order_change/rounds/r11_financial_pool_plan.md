# R11：现有营收二阶信息的研究池增量

执行前登记；父轮次R10，依据r10_reflection.md。不新增财报采集，复用R04的行业季度营收YoY、相邻季度变化及公告/更新/依赖日期约束，历史代理而非严格PIT。此前历史均看过，不是独立验证。

假说：价格二阶差分增量不稳定，营收增长速度变化可能提供不同信息。反例：只是当前增速水平、财务覆盖选择，或同一批小样本重复造成高胜率。

固定规则：价格合格且财务有效公司>=3、覆盖>=30%、growth与finance_acceleration均已知。七个分支：全财务可用、加速度>0、加速度<=0、增速>=0、增速<0、增速>=0且加速度>0、增速<0且加速度>0。后两者分别作为改善加速、恶化减速的财务代理；不能认证盈利/需求机制。

按R09三个期限、周状态和首次进入分别报告。同期全财务可用池与同容量价格动量作对照；额外按同日当前增长正负、价格速度正负及组内价格速度五层匹配，估计加速度相对同类的增量。公布匹配层样本量和单例比例，不把单例零差当支持证据。覆盖>=50%仅作预登记敏感性，全部报告，不从30/50中择优。

财务覆盖下降越过阈值时退出该财务分支、状态保留UNKNOWN，不称经济转差；首次跨入财务可用状态单独标记，不能视为已知新改善。报告原全行业覆盖、财务可用覆盖与每期容量，不把财务子池结论外推全部行业。

成功标准是跨期限与年份相对匹配对照的一致增量、可用覆盖和早期性共同支持，而不是最大的一行胜率。没有一致证据则拒绝批准准入规则，保留下一轮可检验问题。
