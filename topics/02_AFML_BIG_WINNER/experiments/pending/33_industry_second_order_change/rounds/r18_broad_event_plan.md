# R18：扩大观察事件宇宙，保留正式准入标准

执行前登记，父轮次R17。依据r17_reflection.md及coverage_ceiling_audit.csv。pool_metric_v1完全不修改，仍只用现有数据。

## 唯一改变的主设计

移除R15观察阶段的旧概率门槛，改为R07已有的泛行业价格变化提示：price_eligible且rate_change>0。它同时涵盖恶化减速与改善加速，仅是价格变化代理，不声称经济机制。

按照原R15逐时点状态机：首次有已知前周false的true提示建立126交易日观察簇，第二个提示生成唯一候选决策；第三次及以上不新增候选；断档清空、到期不自动触发。观察提示不等于正式研究池。

候选事件上沿用R17同一3个条件、同一固定正则与事件概率模型：确认耗时、确认期间相对表现、当时市场126日收益；两个原始逻辑模型仍是R12封存的levels/second，不重训、不换参数。非事件行使用同一全局状态映射。唯一候选阶段不再由旧概率60分截断，校准模型能在更广事件上学习。

新模型正式准入依旧必须新概率>=60%且高于同日全行业均值至少5个百分点，并通过全部原验收数值。获准后的状态仍需观察簇有效、原候选状态和当前新概率门槛同时成立。拒绝的同一机会不在后续日子重试。

## 时序、支持和比较

模型每季度只使用该日之前成熟的历史事前事件预测。100事件/12日期等支持门槛不改；不够则整折UNKNOWN并保留在全期覆盖分母。先封存观察事件、特征和预测，再评价。

与R17比较时同时报告候选数量、校准支持起点、父观察状态的覆盖上限、实际准入胜率/校准/覆盖及同日期基准。不能把观察宇宙扩大误称预测能力提升。事件次数、126日期限、3个特征、正则强度均固定，不按结果筛行业。

这仍是已被反复查看的历史探索。若失败则据证据收束当前校准/候选设计，保留未达目标的状态，不降低标准或通过更换主期限“达标”。
