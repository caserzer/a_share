# R17：事件条件能否改善高分候选区分

执行前冻结，父轮次R16。pool_metric_v1不变，两个基础模型、原始唯一事件目录、校准支持门槛、季度截止和全部评价范围不变。R16 event_platt作同折对照，不搜索新参数。

## 唯一新增内容

事件概率logit(p)=a*logit(raw_p)+b+gamma*M，a>=0。M只有3个事前可见变量：
- delay_fraction=(确认日day_i−首次提示day_i)/126；
- relative_move=确认日行业/市场对数相对路径−首次提示的同一路径；
- market126=确认时中证全指过去126交易日收益。

特征由R15已封存的anchor_row_id及旧面板派生，要求同一行业/分类/价格块且anchor_date<=确认日期。只在唯一候选事件行应用，不能当作经济机制认证。

仅在本季度之前结果已成熟的唯一事件拟合；事件等权。事件特征标准化仅使用这些训练事件，预测标准值截在[-3,3]并报告超范围比例。模型L2=0.05，(a,b)向本折全局状态映射收缩，gamma向0收缩，与R16 event_platt的强度和先验一致。没有额外调参或模型择优。

非事件行业周仍使用同一成熟非事件训练集的全局状态映射；当日全行业参考概率按实际各行条件下的概率均值计算。所有候选只有原来的第二次确认一个决策时点，拒绝后不能在同簇较晚日子重试；准入后的研究池周状态仍要求当前概率及原池状态同时成立。

## 判定

对比R16 event_platt的主验收、同期间对照、全部候选与准入子集概率误差/Brier、高分分箱、年份及机会覆盖。只有均值误差改善、只有更少事件或只有某个年份改善都不算完成。全部原门槛保留，不通过则明确否定/不确定，不继续在同一历史上遍历事件特征组合。
