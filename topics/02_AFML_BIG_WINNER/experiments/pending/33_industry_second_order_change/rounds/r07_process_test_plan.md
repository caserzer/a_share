# R07：从案例到全行业过程检验（计算前记录）

问题来自R06，不优化收益：减速/新低减少是否更早提示，等待确认花费多久；改善后加速度回落是否等于趋势结束。

范围：既有L3连续价格块，观察2021–2025年完整交易周，后续最多8个有效市场周可延伸至现有数据终点。展示全体和抽样片段以外结果；这只是案例外扩展，不是独立样本。任何未来窗口缺块/缺周标UNKNOWN，不串接分类。

当时可观察的五类提示（都不是交易规则）：
- slowdown：20日相对速度<0且相比5日前改善。
- pressure_easing：slowdown且过去10日创20日相对新低次数较5日前减少。
- improvement_acceleration：20日相对速度>=0且速度改善。
- broad_confirmation：20日相对速度>0且绝对上涨宽度>=0.5。
- long_confirmation：broad_confirmation且60日相对速度>0。

另记录旧R03最终10名名单首次何时注意到变化；不读取其收益。提示以false→true记episode，同类8个市场周内重复触发单独统计为抑制，不当新增独立机会。所有状态周保留，以区别等待时间与重复负担。

过程评价：从提示后8周，分别记录20日相对速度为正的周数；>=6为“窗口内持续相对改善”，0为“未见改善”，1–5为“短暂/尚未持续”。这是操作性价格状态定义，不是真实经济周期，也不能直接将后两类叫作永久失败。正速度的改善阶段单列；对未来全窗口缺失保持UNKNOWN。

每个pressure_easing提示追踪8周内首次broad_confirmation、long_confirmation和旧名单出现时间、期间相对价格变化；确认尚未出现保留未确认。计算提前量时仅在确认者上有延迟数值，但必须同时给全部提示及未确认分母。

事后参考转折仅用于评价：
- trough_w2/w4：相对价格是前后2/4周局部最低点；此前4周斜率<0；未来8周至少6周高于此点且斜率>0。
- acceleration_break：此前4周相对斜率>0，之后4周斜率更大，并且未来8周至少6周高于当前点且整体斜率>0。
每种参考同一行业8周内只计第一个，非独立机会；其后向窗口是标签，绝不进入提示。主匹配区间为参考点前后4周，同时列前后2/8周敏感性，不按最好结果选定义。报告首次提示相对参考的滞后、覆盖/遗漏及提示未匹配比例。参考极值不同定义结果若变动大，应降低结论强度。

先后诊断：在pressure_easing后的8周中记录短期方向、中期方向、宽度、长周期方向首次出现及未知。把“起始周已满足”记为0，不伪称后来新增证据。按年分解。P3检查正20日速度但速度变化<0时接下来8周仍持续改善的比例，不由收益判定。

副诊断：标记同一周有>=70%可观察行业宽度上升的共同扩散周；比较确认延迟，不把绝对宽度当相对宽度。财务来自当周已有代理，另查覆盖跳变，不能给未覆盖行业编造基本面顺序。
