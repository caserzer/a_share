# R16：唯一入池事件的事前概率校准

执行前登记。父轮次R15，用户要求继续执行并保持pool_metric_v1全部数值不变。只用已有数据、原12季度测试范围、126日主标签和63/252敏感性。原协议文件不修改。

## 假说与对照

全行业周状态校准不能保证筛选后的唯一确认事件概率准确。固定R15的levels/second恒等映射所定义的唯一二次确认事件，原始模型、事件簇、第一次观察和第二次确认时点都不重训、不移动。只改变其概率映射与是否准入。

历史校准记录必须是R15历史模型当时已生成的预测，且该记录的end126严格早于本季度拟合日。未来季度事件、尚未成熟标签、同一期测试结果不得进入拟合。用所有当时已成熟候选事件而不是仅过去被新校准器接受的事件，避免不断强化自己的筛选偏差。

## 固定6组映射

两个原模型各三种映射：
1. state_oof：只用成熟的非事件行业周，以日期等权拟合全局单调Platt映射，正则固定0.05、收缩到恒等映射；对事件也使用它，作为对照。
2. event_offset：全局映射不变，在唯一事件上另拟合一个logit截距偏移；事件等权，L2=0.05收缩到0。
3. event_platt：全局映射不变，在唯一事件上拟合单调斜率及截距；事件等权，L2=0.05收缩到全局映射参数。

本轮不加市场变量、不搜索正则强度或时间窗口。非事件与事件映射分开：事件映射只应用在事前固定的唯一确认决策行，不外推为“所有行业假如成为事件”的概率；其他价格可用行业周使用全局状态映射。全行业平均预测概率由这些当时条件下的实际预测共同计算，维持原协议全行业参照定义。

各组使用相同支持门槛：至少100个已成熟唯一候选事件、12个事件日期；非事件成熟样本>=500且>=12日期，两边标签各有两类。不足则整折MODEL_CALIBRATION_UNKNOWN，不回退原始分数冒充事件校准。2024折会因预先核查到的成熟事件不足保留未知，不从全期机会覆盖分母删除；另与R15在共同可评分季度对比，防止因测试时段不同产生假改善。

## 准入管理

R15第二次确认仅提供一次候选决策；只有新概率>=0.60且较同日全池均值>=0.05才正式准入。被拒的同一机会后续不重新尝试，以免挑选有利日子。获准后在原机会有效期内，仍需原R15池状态与当前新概率门槛同时满足才计入研究池周状态；后续状态恢复只更新，不增加首次入池。

主评价仍为唯一首次准入的真实126日联合成功率。全部原门槛不变，覆盖按实际新池状态计算，边界/未成熟/缺失/校准不支持分别报告。新校准先封存、再评价。单独报告全部候选事件的概率误差/Brier以及实际准入子集误差，防止只靠筛选掩盖概率失真。

## 反思规则

如果误差改善但胜率、增量或覆盖下降，不得宣称目标完成。若与共同季度的R15对照差异主要来自时段或全市场基准，明确说明。根据结果提出下一项最小实验，不能用当前测试事件重校准自身，也不降低门槛或改变主期限。
