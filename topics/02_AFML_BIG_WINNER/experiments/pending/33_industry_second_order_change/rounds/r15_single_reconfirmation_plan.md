# R15：每个机会仅一次二次确认准入

执行前登记，父轮次R14。依据r14_reflection.md。用户要求的pool_metric_v1不变，不重新校准、不训练模型、不改变成功标签/期限/分数门槛/统计验收数值，不选择第三、第四次提示。

## 假说

R14簇内重复部分超过60%的表面胜率，可能来自确认信息，也可能来自有利市场时期和反复计数。每个126交易日机会簇只允许第二个原始false→true提示作为一次正式入池，后续第三次及以上永不增加本簇机会数。

## 当时即可执行的状态机

逐行业、逐连续价格块按周读R14已封存概率。原始gate仍是p>=0.60且比当日全行业均值>=0.05。

1. 第一个有已知前周false的true提示建立观察簇，记录anchor_day、日期与价格，此时仅观察，不正式入池。
2. anchor后不足126交易日内，第二个原始false→true提示触发本簇唯一正式准入；等号126归下一簇。未出现第二次提示则不入池。模型换版触发次数单独报告。
3. 入池后在本簇有效期内且原始gate为true的周属于研究池；gate为false时转为跟踪状态，之后再为true只更新原机会，不新计入池事件。达到anchor+126自动结束本簇；之后必须有新的原始false→true才能建新簇。不能因期限到期自动发新机会。
4. 数据或预测断档清空本簇，边界true不触发；分类或价格块变化不拼接。

每周仍有原始模型分数、全行业参考概率和相对门槛；加设的是正式准入的证据要求，不降低原阈值。原始false→true协议结果作为对照保留。正式首次入池主指标按唯一机会ID计算，后续重复更新不再算首次。另列研究池从false回到true的原始边沿，防止用相同机会多次重算胜率。

## 验收与时机代价

同样要求胜率>=60%、同期增量>=5个百分点、>=100个成熟机会、95%时间块增量下界>0、校准误差<=5个百分点。成功行业周覆盖>=10%必须按本轮实际研究池状态重新计算，不能沿用R14更宽的原始状态。

全部6组R14映射均执行，不按结果只保留最优。统计63/126/252日、年度、未知分母、全池/同容量动量对照、平均每周研究负担、概率分箱及Brier。配对记录每簇第一次提示和第二次正式准入的间隔、期间行业涨幅/超额涨幅；比较同一最终入池簇在两时点的标签，未确认簇保留不随未来补选。用原始确认前价格衡量已发生变化，不把事后低点当可见信息。

本轮是自适应历史探索。即使整体指标通过，也须说明确认延迟与早期性、反复实验及未独立前瞻验证；不能直接生产发布。若不通过，保留失败结论，不继续遍历第几次提示、冷却长度或门槛。
