# EP32 V23：按周期等权的训练目标

用户目标不变：precision≥23.50%，周期recall≥41.25%，时点召回和延迟同步报告。V22审计37模型×17政策仍无达标；保召回的最好历史网格点precision17.63%、周期recall50.18%，但识别更晚。

当前逐时点损失会对同一周期的多个早期观察重复计权。新假设不是加入外部经济信息，而是使训练更接近“每个周期至少检出一次”，避免易识别、重复出现的周期主导正例损失。保持原V18扩散树38项特征和240树/15叶/深4/最小叶200/学习率0.03/L2=25/seed32参数，不根据本轮结果调整。

固定三个候选：

- event_equal：负例保持原日期/层级权重；对已成熟正例按phase_id×benchmark分组，各组正例权重总量相同；组内相对权重保持原日期权重。最后恢复原正例总权重，避免单纯改变类别先验。
- event_early：同样周期等权，但组内原权重乘以2-clip(距周期起点自然日/90,0,1)，适度强调较早观察；各事件总权重及全体正例总权重仍同event_equal。
- event_blend：event_equal与原diffusion_tree概率各50%。

phase_id、起点日期只用于已经成熟的训练标签构造样本权重，绝不进入预测特征或测试时筛选。每季度先过滤label_available_at<季度起点，之后才计算权重；不能用后来成熟的周期计数归一化当前训练。未成熟标签仍未知，早期可行状态过滤保持。

每个季度审核：正例总权重和原权重一致、负例权重逐行不变、正例各周期总权重相同、权重均有限正值、最新训练标签成熟时间严格早于季度起点。季度滚动完整2021—2026，主评价2021—2024年9月固定24个月随访。

17项选择政策完全沿用V17，前10%和全池≥0.15为预定主要观察。所有结果、失败与覆盖披露；不按目标结果选择年份、行业或重新标注。继续保留严格PIT BLOCKED_DATA与独立前瞻FORWARD_PENDING。V22及前序结果先冻结。
