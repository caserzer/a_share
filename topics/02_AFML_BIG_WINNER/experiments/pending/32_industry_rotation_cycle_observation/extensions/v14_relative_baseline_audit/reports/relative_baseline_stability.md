# EP32 V14：相对原RD基线的稳定性与原门槛分开审计

**在已解决标签的历史样本中，已找到稳定优于原RD的固定方法；原完整验收门槛仍未通过。** 不能用前一结论替代后一结论，也不能声称独立前瞻确认。

若优先考虑相对原RD的稳定性，风险模型与阶段过滤各50%的固定融合值得保留；它在69个可评价任务年度中67个误差更低，最差回退约1.62%。风险/过滤/先验的组合命中率略高，但回退组合更多。

周期层面也存在取舍：任务等权的事件检出率从原RD约36.96%升至固定50%融合的45.83%；各任务内首次检出的中位延迟再取平均，从约32.61天变为37.88天。融合检出更多周期，但通常晚一些；这仍在前三个月定义内，不是提前一个月预测启动。原始分任务数据见[事件结果](../../v13_completed_history/outputs/event_detection.csv)。

方法执行顺序：

1. 按原历史行业成员篮子更新净值，只用截至观察日的价格维护候选低点和已确认上行起点。
2. 如果已不可能处于起点后三个日历月，概率置零；其他行业保留原RD的概率，得到简单阶段过滤概率。
3. 使用原V8的19个状态/价格特征，加V12固定的八个波动尺度变量，按季度只用当时已成熟标签拟合固定树。频率重合记录先去重。
4. 输出概率为上述风险树与简单过滤各50%，权重没有按年度结果调整。周/双周/月观察仍分别更新，按日期/行业层级选前10%。

这不是识别基本面盈利景气，也不是保证以后持续上涨；目标仍是事后可被确认的6—18个月价格阶段起点后三个月。此前采用的2倍提升、逐年优于所有基线、两阈值与两市场基准完整门槛，三种方法均未通过。

相对原RD的全部18个候选一并审计，并与不重复的旧检验一起校正，共39项。设计已经多次看过这些历史，校正不能消除探索性；此审计的q值不替换原来“相对简单过滤增量”的失败结果。

主要评价2021年至2024年9月，统一24个月跟踪；2021分类断点使已知标签覆盖约37%，未解决标签保留未知。底层训练数据从2017年起，严格PIT仍BLOCKED_DATA，独立前瞻验证FORWARD_PENDING。
