# EP32：行业轮动、长景气周期与行业前三

启动日期：2026-11-05，Asia/Shanghai。

用户原始研究问题：

> ep32 是一个关于行业轮动的假设和猜想，就是A股中存在行业轮动现象，不是短期的，而是12个月到18个月的景气周期切换，在景气周期中行业前三的标的都会有不错的涨幅，而且持续时间会长达9个月到12个月。先根据PIT数据查询是否观察到这种现象。

本轮已确认：

1. “前三”按观察时点行业内总市值排序，不按未来收益挑选。
2. 第一阶段先检验行业价格轮动，再核查是否对应基本面景气。
3. “不错”“持续”先展示连续分布，不预设通过阈值。
4. 用户追加：一级行业太宽，使用二级或三级行业。以申万二级为主、三级并列复核，禁止用宽行业结果替代。

第一阶段是现象观察与数据准入，不是交易策略或确认性预测检验。必须区分行业轮动、12—18个月典型周期、前三共同上涨、9—12个月持续性四个子问题。未来需另定义真实景气及独立验证。
