# R24：当前信息集下的分位数分布与风险标准化

R23完成且双20%未达标，累计53个已评分候选。本轮方案在新预测生成和评分前固定，原B、原股票/日期、1/3/6月四项相对20%门槛不变，不改为收益率点预测或策略收益。

R01/R05/R10已经试过CatBoost MultiQuantile，旧四期限报告发现过度自信；不能把分位数回归称为首次尝试。当前检验的是新增历史盈利预期、信用/估值、市场状态信息下，逐月重训、月份等权、相同训练行的分布表达对照。CatBoost官方文档确认MultiQuantile支持分位点向量及样本权重：[回归目标说明](https://catboost.ai/docs/en/concepts/loss-functions-regression)。本地1.2.10已完成单次可运行性/耗时测试，未用测试结果挑参数。

固定3个拟合，每个报告原始分布和与B各50%混合，共6候选：

1. quantile_control：R23较大模型的35个对照输入，直接学习简单收益分位点。
2. quantile_scaled：同输入，训练log(1+历史已到期收益)/(该起点已知vol63×sqrt(21h))；查询时按当时vol63逆变换。vol63仅以0.001作数值下限，不用未来实现波动率。该处理改变训练损失的隐含权重，并非单纯无影响的单位变换。
3. quantile_paths：对照输入加R23的16个量价/路径输入，直接学习简单收益分位点。

固定25个均匀中点分位水平0.02、0.06、…、0.98；200棵、深度4、学习率0.03、L2=50、种子24，无测试期早停。与R23两个相同输入/深度/树数的多类别模型原样对照，但不同损失的优化与参数维度不相同，不能声称所有容量细节完全相等。最少1000训练行和18个已成熟起点月；所有标签结束日严格早于预测日，月份等权。不足时逐值保留B。

分位点发生交叉时排序，再按固定概率网格插值为200个等权原子；两端常值延展，简单收益支持下限-1。对数风险版本先在标准化空间插值再逆变换。所有上涨/下跌/零收益、五档概率及CRPS从同一有限分布计算。25点不能识别最极端2%的真实形状，常值端点可能损害尾部评分，明确保留为方法限制。取消50%混合用于检查旧分布约束，不事后选择混合权重。

将核对原人群与标签不变、固定源哈希、训练成熟日期、原参考逐值一致、从缓存原始分位点与当时风险尺度重建全部概率和评分。仅技术核验通过不代表预测改进。仍是同一历史窗口的重复探索，未解决历史版本/股票池偏差，也未验证12月双20%。本轮尚待实际完成与评分，不提前增加已评分候选数。
