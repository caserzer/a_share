# 国内期权成交与持仓数据检查

上交所每日统计的2018-12-28、2021-04-01、2026-04-29三个历史查询成功，逐条核对认购加认沽等于成交／持仓总数，以及公开的认沽／认购百分比。2021-04-01的两标的合计数，还与官方2021年4月统计月报四个数值在公布精度内一致。

|2021-04-01，万张|日度接口合计|官方月报|
|---|---:|---:|
|认购成交|193.0065|193.01|
|认沽成交|158.9610|158.96|
|认购持仓|222.3124|222.31|
|认沽持仓|207.2156|207.22|

原预测面板的88个月，加3个月变化预热，共91个快照已取齐，得到168个标的日。每个快照固定取预测日前第二个交易日；50ETF在全部91个日期均有值，300ETF上市前的14个快照不应有该标的，不用零填补。全部返回日期、标的身份、成交与持仓加总和公布比例均已核验。

新增特征仅为两只固定标的各自的成交认沽／认购对数比、持仓认沽／认购对数比、成交／持仓对数比，以及前两项一个月、三个月变化。没有合并后来新增的中证500、科创50等期权，避免统计组成变化。原37,018行输入、27,600个评价股票月和收益标签逐值保留；四个日期的未来数据截断重建通过，2021年起全部新增特征有值。148项测试、768次成熟训练核验和331,200条新概率重建通过。四候选均未达到双20%目标，累计131个完整评分候选；见[结果](option_activity_models_report.md)。

这些数据不是隐含波动率，也不能解释为净资金流或净看空头寸。每笔期权交易都有买卖双方，统计没有直接说明投资者的交易动机；到期换月和产品发展仍会影响比例。两个交易日滞后是保守的可用时点假设，不等于认证全部历史发布版本。官方月报仅用于核对字段和单位，不用于把后来出版的报告倒填为当日信息。
