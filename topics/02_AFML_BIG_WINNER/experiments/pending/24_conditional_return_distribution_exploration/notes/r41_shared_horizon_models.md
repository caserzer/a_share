# R41：跨期限共享概率模型，评分前方案

R40完成，139候选均未达到双20%。本轮原R15 B、27,600股票月、1/3/6个月各自三项概率误差下降20%与方向命中率相对提高20%的12项门槛不变。属于重复历史探索，不是独立确认集。

假设：逐期限拟合丢失不同期限间可共享的特征关系，成熟较快的短期标签可能帮助长期学习。每个预测月分别构建1/3/6个月池和1/3/6/12个月池；只纳入各行origin < prediction_date、该期限end_h < prediction_date且y_h已知的标签。同一股票起点不同期限是相关观测，不能把扩大行数解释为独立样本增加。12个月只作为辅助训练，本轮不新增12个月验收结果。

原38控制输入加数值horizon_months。原收益七档阈值保持不变，不做事后收益标准化。每个期限内部起点月份等权，每个期限总权重相同；整个训练池总权重固定为同预测月原3个月成熟训练行数，因此两个训练池及两个算法权重总量一致。相比原逐期限模型仍存在标签组成、期限特征占用容量及有效正则变化，不声称只有样本数变化。输入由各历史起点原记录提供，不从未来记录更新。

两种固定算法：CatBoostClassifier depth2、100棵、lr=.03、L2=20、seed24、四线程；ExtraTreesClassifier 96棵、depth6、min_leaf150、max_features=.7、Gini、无bootstrap、seed24、四线程。Extra训练内中位数填补并追加缺失标记，Cat沿用原生缺失。没有搜索参数或测试期早停。两个池×两个算法，共四新增候选，都与精确float64原B各50%混合。两个原样对照复用R31 catboost_reference/extra_reference。

每月每个共享模型一次拟合，分别输入h=1/3/6生成概率。每个目标期限的档内32个全局幅度原子仍由该期限单独的成熟训练按原月份权重确定；不把不同期限的幅度混在一起。各目标期限要求>=1000行且>=18个成熟月份；12个月辅助期限至少12个月，首个预测月实际有13个月。缺失12个月标签不填补；完整保留原评估股票和日期。

保存计划/面板/原对照哈希、每期各期限成熟行及月份数、最大标签结束时间、训练特征/标签/权重/填补哈希及全部预测概率、原子、键。核验新增331,200条预测及各期限全量标签一致，证明较长期未到期标签未借短期观测混入。测试覆盖逐标签成熟、原点时间限制、不同训练池的权重守恒、期限顺序与查询编码、未来标签扰动不影响历史训练。配对比较四候选对自身原算法及加入12个月的边际效果，月份等权、12月块2000次seed24区间不变。
