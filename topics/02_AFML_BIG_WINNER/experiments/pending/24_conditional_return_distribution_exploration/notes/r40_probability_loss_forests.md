# R40：概率评分驱动的森林分裂，评分前方案

R39已完成，135候选均未达到双20%。本轮保持原R15 B、27,600股票月和1/3/6个月分别三项概率误差下降20%、方向命中率相对提高20%的全部12项门槛。仍为重复历史探索，不是独立留出验证。

假设：分类Gini分裂未直接利用收益档位顺序，也未同时针对实际验收的三项概率误差。用相同38项控制、成熟训练、月份等权、训练内中位数填补和缺失标记，换成多输出ExtraTreesRegressor的平方误差分裂。96棵、深度6、最小叶150、max_features=.7、seed24、无bootstrap、四线程不变。对照原样复用R31 extra_reference。两种新损失分别输出独立分布及50%原B混合，共四候选；不搜索参数，不筛选股票或时段。

1. ordinal：六个标签I(七档类别<=k)，k=0..5。多输出平方误差即离散有序累计概率评分的常数倍。
2. joint：输出上涨指示、五档one-hot和连续收益CDF的32个区间中点指示。区间端点由成熟训练收益的月份加权CDF中心插值分位点0,1/32,...,1确定，去除重复端点；只使用训练信息。CDF各维乘sqrt(区间宽度/训练无条件近似CRPS)，上涨维乘sqrt(1/训练无条件上涨Brier)，五档维乘sqrt(1/训练无条件五档Brier)。每项归一化分母最低1e-8，三项无条件平均贡献相等。不同输出数造成统一常数缩放，不改变平方误差分裂排序。该CRPS是训练网格的中点积分近似，不能称精确CRPS最小化。

每棵树在预测叶内使用原月份权重计算成熟训练七类频率，再对树等权平均。七档幅度仍用同一成熟训练全局32个中点分位，因此只改变叶划分和类概率，不引入局部幅度变化。精确零独立成类，全部概率由非负叶质量产生，避免累计概率交叉。独立与混合分布统一导出方向、五档及精确离散CRPS。树的分裂优化、有限深度和全局幅度近似意味着训练目标改善不保证样本外改善。

保存训练/测试叶号、模型输出、概率、网格、归一化分母和原子；重新从叶号、原训练标签及权重重建概率及多输出预测。核验成熟时点、输入/填补哈希、原参考与原B缓存、全量键和标签、全部331,200条新预测。测试覆盖权重、零/边界、联合损失等价、无测试信息影响网格和叶概率重建。配对报告各新候选相对原参考、同损失独立相对混合、joint相对ordinal；月份等权和12月块2000次seed24区间不变。
