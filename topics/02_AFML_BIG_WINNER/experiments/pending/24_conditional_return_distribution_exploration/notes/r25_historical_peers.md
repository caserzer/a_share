# R25：历史联动股票的近期状态

R24的1个月完整阶段评分已确认六个候选未达标，3/6个月仍按原方案运行。本轮准备新增信息，不调整R24。冻结B、27600测试股票月、1/3/6月四项20%门槛继续保持不变。

此前四时点探查表明，按过去价格联动可为约84%—95%的原共同人群找到至少10只相似股票，但与自身动量仍有较多重合，不能称为已确认行业或预测增量。本轮将完整构建112个月的历史信息，并设置自身动量对照。

每个决策日只用当时历史500只股票成员。取最多252个交易日收益，减去这些成员的同日收益中位数；至少126对有效观测计算相关系数，排除自身，选择相关系数大于0.2的最多20只股票。至少10只有效同行才计算近期21/63/126日动量均值。所有缺失输入保留缺失，不删除原预测行。

固定两个形成窗口：窗口0截至决策收盘；窗口63在最近63个交易日之前结束，减少形成股票关系与近期21/63日动量使用同一批收益的机械重合。两组都使用决策日已知的近期动量，不使用未来走势。每组输入为3个相似股票动量、平均相关度、相似股票数及可用标记。价格联动股票不是官方行业成分；当前已知成员回看过去的相关窗口不等于每天历史全市场行业样本。

在看到本轮预测效果之前固定4个候选：

1. 自身动量对照：R23浅层成交均值模型的35个输入，加个股自身mom21/mom63/mom126。
2. 对照加窗口0相似股票信息。
3. 对照加窗口63相似股票信息。
4. 对照加两组信息。

统一深度2、100棵、学习率0.03、L2=20、种子24；月份等权同时用于7类别预测和类别内分布；新分布与B各50%。至少1000行和18个已到期起点月，训练结束日期严格早于预测日，历史不足逐值保留B。逐值复用R23浅层均值模型作为参考，以便分开判断自身动量和额外股票信息的作用。不添加更大模型或事后挑选混合权重。
