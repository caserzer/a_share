# R36：股东户数水平与变化（评分前固定）

此前117个完整候选未达到双20%目标。新一轮检查公开股东户数能否提供个股间概率差异。户数并非持仓集中度，也不能直接解释为机构或散户的资金流。

冻结原R15 B、原27,600股票月、1/3/6个月全部12项门槛。原38项控制不变，不按户数覆盖筛掉股票，不使用未来实际收益作为输入。来源为已获取的1242只股票公开查询，其中1216只有历史记录、26只明确无记录；源文件哈希、两份官方年报四条数值抽核已留存。来源版本仍有局限，部分公告日期晚于首次披露，保留供应商日期，不回填更早日期。

每次预测仅使用公告日期严格早于预测日的记录，保守排除公告早于统计日的记录，选择最新统计期。最新统计期距预测日不超过180个日历日才提供数值特征，否则保持缺失。变化的比较数必须来自当时独立可见的前期记录，不直接信任供应商附带的前期值。

输入检查修正（尚无完整期限评分）：发现年度比较含有上市前少量私人股东，不能直接作为上市后公众股东户数的可比基数。已中断并隔离原中间缓存，正式候选数未增加。重新构建时，所有当前与比较记录的统计日均须不早于该股现有原始行情的首个正收盘价日期。这个日期是保守的行情覆盖边界，并非声称核验了精确上市日；老股票行情可能从2017年才开始。保存全部行情源哈希与边界，不通过某个户数数值阈值或预测结果筛选。

新增7项：公共时点信息2项（统计期年龄、公告滞后天数）；水平1项（户数自然对数）；变化4项（最近两期户数对数变化及统计期间隔、约一年前户数对数变化及其间隔）。最近两期最大间隔370天；年度比较在最新统计日前305—425天内选择最接近365天的已公布记录，等距离取较近一期。当前或比较记录缺失则相应特征缺失，不填户数0。所有缺失行保留。

三组消融：时点+水平、时点+变化、全部7项。在原浅层CatBoost和ExtraTrees两个固定算法上各跑三组，共6个新增候选。算法参数沿用R33，月份等权成熟训练、全局七类各32个加权分位点、与精确B各半混合；两个不加户数的同算法参考逐值复用R31。不按结果调阈值、选股票或改混合比例。

核验原始字段与标签逐值保留、训练标签严格早于预测日成熟、源记录按公告时点对齐、真实历史前缀特征不变，以及全部新分布可重建。原B与同算法参考分别比较，避免把算法效果归因于新信息；完整保留各期限和分阶段结果。反复历史探索不是独立确认；12个月双20%仍需另行验证。
