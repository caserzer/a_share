# R39 个股历史偏差收缩校准：评分前方案

固定目标仍为原R15 B、原27,600个股票月、1/3/6个月各自三项概率误差下降20%与方向命中率相对提高20%，同一候选通过全部12项。重复历史探索，不是独立留出验证。不调整股票池或只报告有历史股票。

问题：已有模型使用个股特征，但没有单独检验“该股历史结果相对同期可比股票的概率偏差”能否补充个股差异。固定四候选：原B、R31极端随机树原对照，各自乘以七档或二档方向校准因子；两原对照不变。没有超参数搜索。

使用原historical_peer_panel，每个预测月只纳入origin < date且end_h < date的已成熟标签。波动vol63与市值log_cap按各历史起点全体样本的平均秩百分位分四组（floor(4*rank)，上限3），缺失单列为−1。同月、同波动组、同市值组的其他股票为比较对象；不足10只时退回同月其他成熟股票。二档模式剔除真实零收益后形成比较频率。自身标签不进入自身比较组的频率。

每只股票累计实际各档次数O、逐月比较组概率之和E，倍率=(O+alpha/K)/(E+alpha/K)，alpha=20*h，K为7或2。每只股票每月最多一条记录，因此自身月份等权。20*h是预先固定的强收缩与重叠期限启发式，不是有效独立样本量证明。未知股票倍率1；精确保留原预测。七档沿用既有分档。二档只重分配非零质量，保留原零收益质量。七档对原分布各原子乘相应倍率后归一化；不移动收益原子。

保持原B的float64修复缓存。R31极端随机树分布由原类别原子、原概率与50%B混合重建，首先核验与原评分及方向逐值一致。输出完整分布概率及原有评分；检查概率质量、未来标签截断、留一法、缺失历史回退、零质量保护和全量键一致性。每个预测月记录成熟训练范围、历史覆盖、校准倍率缓存和哈希。

配对消融分别对自身原对照，并比较七档相对二档；按月汇总，使用既有12月块、2000次、seed24配对区间。诚实报告所有四候选与时段差异，不拼接最佳指标。风险：股票身份效应可能随时间失效；可比组只是粗略控制，原模型可能已经包含同类信号；样本来自原研究股票池，不能外推全部A股。
