# R38：国内期权成交与持仓结构（评分前方案）

R37公告时间与标题四候选未达到目标，也未显示稳定的信息增量。本轮测试不同的市场信息：上交所50ETF与沪深300ETF期权的认沽／认购成交和持仓结构。它们是交易活动统计，不是隐含波动率、净资金流或投资者净方向，不预设高认沽比例对应上涨还是下跌。

仍以原R15 B为20%目标基线，保持同一27,600股票月及1/3/6个月评价。采用两种原算法及原38项控制，各做50ETF七项、再加300ETF七项，共四候选；原样复用R31同算法参考。月份均衡训练、已成熟标签、每类32个原子和50%精确B混合保持不变，不按结果改窗口或组合。

每个预测月份取原有交易日历中预测日起往前第二个交易日的官方统计快照；另取三个预热月份供变化计算。使用固定的两只期权标的，避免后来新增标的改变合并统计口径。300ETF期权2019-12-23上市，之前及缺少比较基数的变化保持缺失，不当成零；已上市后的必需数据缺失或失败则停止，不用较旧日替代。

每只标的七项：认沽/认购成交量对数比、认沽/认购持仓量对数比、总成交量/总持仓量对数比；前两项分别相对上月和三个月前的变化。变化只在两个独立历史快照都有值时计算。原始数值、日期、各类加总和公布认沽/认购百分比需核验；特征只加入原面板，不改变样本和标签。

2018-12-28、2021-04-01、2026-04-29三个可行性查询已成功。2021-04-01两只标的合计的认购/认沽成交与持仓四个数值，与官方2021年4月统计月报在公布精度内一致。这个交叉检查不等于全部历史版本认证；两个交易日滞后是保守可用时点假设，仍应保留修订和披露延迟边界。

完成全部快照及时间前缀重建后才拟合；完整评分和概率重建后才把四候选计入累计。仍是重复历史探索，不能替代独立留出验证。当前已完成127个候选，尚无同时达到双20%的方案。
