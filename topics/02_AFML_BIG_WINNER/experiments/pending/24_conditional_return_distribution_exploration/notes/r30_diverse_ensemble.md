# R30 多来源分布组合与方向校准（评分前固定）

原R15 B、27,600股票月、1/3/6个月全部12项双20%门槛保持不变。此前82个正式候选未达标。R22只组合三条旧流并优化七类Brier，本轮加入后来产生的不同算法和信息源，并直接覆盖原三项概率误差。仍是反复历史探索，不能称为独立确认。

## 七个固定组件

按方法/信息族纳入，不逐期限挑表现最好的候选：R15 B；R25自身动量提升树原始未混合分布；R28随机森林局部独立分布；R28极端随机树局部独立分布；R26分层方向独立分布；R27两融两组同时加入的原始提升树分布；R29海外两组同时加入的原始极端随机树分布。后两者及R25直接读取已冻结的原始类别预测缓存，去除固定50%B混合，避免七份组件重复包含B。这些组件不是本轮单独宣称达标的新候选。

保留各源完整有限原子分布。每个源的当月输入、原人群与标签必须一致；所有源/cache哈希记录。只用已到期旧预测学习元模型：origin<当前日期、label_end<当前日期且actual已知。至少12个已到期起点月；历史不足时所有学习版本原样回退到当月固定七源等权分布。月份等权，未到期结果不得训练。

B原始缓存以float32保存原子，原始报告用线性样本分位，而组合用加权CDF分位。源准备阶段在2021-08发现少量原子舍入后跨过分档边界，故在任何本轮元模型拟合/评分之前增加精度恢复：只按原R15面板、成熟训练键及B算法重建float64原子，要求重建评分逐条匹配冻结B，且再次转float32必须逐位匹配原缓存；原报告和旧缓存不变。R30的B组件使用恢复版；旧模型中曾混合的B只在来源核验时沿用其旧缓存。量化旧缓存对原B分档和四项评分的影响，三项训练尺度及最终验收仍使用冻结B原始评分。

## 五个正式候选

1. 七源固定等权完整分布。
2. 扩展历史学习非负、和为1的七源权重。
3. 最近24个可用已到期起点月学习同样权重。
4. 扩展历史对固定等权分布作方向概率校准。
5. 最近24个可用已到期起点月作同样方向校准。

权重目标：当时成熟历史的上涨Brier、五档Brier、CRPS分别除以同段B误差后等权平均，另加0.01倍权重偏离等权的平方和。三项基准尺度只从该次训练历史计算。SLSQP解约束问题，不使用全测试期选权重或超参数。

精确有限分布公式：D_ij=积分(F_i-F_j)^2；组合CRPS=Σw_i CRPS_i−0.5 Σw_i w_j D_ij。D由排序后的原子CDF差积分得到，不是把各模型CRPS简单加权。将以直接组合原子评分验证恒等式。CRPS定义依据[原始评分规则研究](https://sites.stat.washington.edu/people/raftery/Research/PDF/Gneiting2007jasa.pdf)。

方向校准固定使用七源等权CDF，和学习组合权重分开，避免先在同批标签上选权重再二次校准。三类为跌/零/涨，以等权分布的log概率为offset；输入为各源clip(log(p_up/p_down),−6,6)，加截距。拟合三类月等权log loss，参数向0收缩，L2=0.01；截距界限±1.5、其他系数±2，L-BFGS-B。校准只改变三种方向的质量，各方向内的幅度形状保持原等权CDF。缺少某方向支持时停止，不编造幅度。决策仍为p_up>p_down，平局判跌。

报告五候选的全部门槛，并比较学习组合/方向校准相对等权的增量。保持早期回退样本、所有股票和完整时期；不把某段或某个期限当作整体达标。输出训练历史边界、参数/权重、数据哈希和逐条概率重建。
