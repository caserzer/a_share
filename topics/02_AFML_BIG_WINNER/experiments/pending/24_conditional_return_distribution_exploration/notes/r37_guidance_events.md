# R37公告时间、修订及标题信息消融（评分前方案）

本轮只测试公开“业绩预告相关公告”的时间与标题信息。金额解析原型在首批深市40份样本中仅提取11份，尚不接入金额、盈利增速或前瞻收益率数值；这不代表已完成公司盈利预测金额因子的检验。

固定原R15 B、同一股票月份、1/3/6个月逐月重训和原双重20%门槛。所有新增特征只使用严格早于预测起点的公告。可用日期取交易所公布日期与PDF归档路径日期的较晚者。原预告及后来修订各自保留，不把修订值倒填。

输入分为两组：

- 时间与修订6项：最近365天内最新匹配公告的距今天数；过去30/90/365天匹配公告份数；过去90/365天标题包含修正或更正的份数。
- 标题4项：过去90天标题包含“业绩预增／预减／预亏／预盈”的各自份数。它们是标题文字计数，不等于数值盈利预测，也不把预减等同亏损。

计数零仅表示完整查询范围内没有匹配记录，不证明当时没有任何业绩预告。部分公告使用不同标题，部分预告嵌在其他报告中；已知“业绩修正预告”等变体仍属于来源边界。主目录和补充标题目录按公告编号及文件去重；相关致歉、补充说明等若符合标题条件仍是公开事件，不宣称它们都是新的金额预测。零计数不造成删样本，最新日期不存在时年龄保持缺失。

四个候选：提升树、极端随机树分别增加时间组6项和全部10项。原38项控制、两种算法参数、成熟训练样本按月份均衡、每类32个金额分布原子及50%原B混合全部沿用。原样复用R31两种同算法无新增因素参考；同时与原B比较。禁止按效果挑股票、月份、期限、特征窗口或混合比例。

先完成两家交易所目录分页与哈希检查、已有巨潮缓存交叉核对、完整样本保持及时间前缀重建检查，再启动拟合。四个候选在三个期限全部评分并重建概率后才计入累计候选。当前123个已完成候选均未达标，本轮也是反复使用历史窗口的探索，不能当独立留出验证。
