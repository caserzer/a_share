# R08：市场方向与个股超额是否混在一起

依据R05—R07暴露的问题，追加这一探索性诊断：绝对收益分布失准可能主要来自共同市场波动，个股相对收益预测是否仍有价值？

直接预测 `个股126/252日价格代理收益 - 同期沪深300价格收益` 的条件分布。正收益概率在此表示跑赢基准的概率，不能称为个股上涨概率。真实未来指数收益仅用于已经兑现的训练标签和事后评估，不能进入预测特征。

沿用R05模型参数、同样本特征要求、季度重训、成熟标签和200原子表示。超额收益没有-100%下界，不沿用绝对收益分布的下界截断。

同时输出2021—2023探索段与2024以后阶段，后者已在其他任务中查看过，明确标为事后诊断，不能重新宣称独立验证。不根据本轮结果调参。

只有相对收益预测在这两个阶段均有可辨认的改善，才值得进一步检验相对收益驱动的选股；否则保留失败结果，不进行大规模模型搜索。
