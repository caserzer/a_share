# R26：直接方向学习与分层概率分布

R24与R25均已完整完成且没有达到双20%。本轮继续固定R15 B、原27600股票月、1/3/6月四项相对20%门槛，不移动方向判定阈值，也不按期限拼接模型。

此前主要比较7类别和分位数损失。本轮检验直接学习下跌/持平/上涨3类概率；只使用R25自身动量对照的38个输入和相同训练行，不加入新的数据或联动信息。原样保留R25自身动量对照作为参考。

固定两个分布结构，每种分别报告独立分布和与B各50%混合，共4候选：

1. sign_reweight：新3类方向模型决定各方向总概率，负收益内/正收益内的三个幅度区间比例沿用冻结R25对照模型；类别内部的32个分布原子也保持不变。
2. sign_hierarchy：复用完全相同的方向模型，另外在已到期负收益、正收益训练样本内各拟合一个3类幅度模型。相乘得到完整7类别概率，类别内部原子仍与对照一致。

每个拟合固定深度2、100棵、学习率0.03、L2=20、种子24，使用原训练月份权重。方向模型至少1000行/18个成熟起点月，条件幅度模型至少300行；条件样本权重直接取原权重子集。单一类别或条件样本不足时使用该已成熟训练子集的加权频率，不使用测试结果。没有训练支持的方向在方向模型中概率为0，因此其条件幅度的占位分布不产生实际质量。

两个结构的上涨、下跌、零收益概率必须相同，幅度模型只能改变五档与完整分布评分。输出涨跌概率按共同方向模型及混合权重直接计算，与原子分布的数学边际相同，以避免不同浮点求和在恰好相等时改变判定；方向规则仍为p_up>p_down。精确零收益继续只从命中率中排除，概率评分保留它。

分层结构具有不同的拟合数量，不能将比较称为仅改变损失且模型容量完全相等。相同输入和训练行让架构差异可检查；相同方向模型让幅度增量可隔离。将全量核验来源、成熟训练标签、所有概率重建、条件幅度样本与类别映射、方向边际不变及原参考不变。仍为重复历史探索，不是独立新验证，原数据版本/股票池偏差和12月未完成限制保留。
