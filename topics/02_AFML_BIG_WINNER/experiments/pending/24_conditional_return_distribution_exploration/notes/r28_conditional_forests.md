# R28 条件分布森林（评分前固定）

目标仍为同一R15 B、原27,600股票月、1/3/6个月全部12项双20%门槛。此前70候选未达标，本轮不是独立确认集，不改方向阈值、不筛选股票。

假设：提升树七分类的档内幅度来自全体成熟样本，可能丢失条件尾部分布。检验随机森林及极端随机树，并比较同一分类概率下的全局档内分布和叶节点局部分布。

复用R25自身动量对照38项输入及原样冻结预测，包含信用、估值、盈利预期和市场/个股行情。此次不增加两融或联动股票输入，以免混淆方法变化。缺失输入仅用当期成熟训练行的逐列中位数填补，全缺列填0；追加每列缺失指示，与森林统一使用，不能用测试期拟合预处理。

固定两种拟合：RandomForestClassifier(bootstrap=True)和ExtraTreesClassifier(bootstrap=False)，均96树、最大深度6、最小叶节点150样本、max_features=.7、Gini、seed=24，无类别平衡，无调参。沿用月份等权样本权重。训练标签到期严格早于预测日，至少1000行/18个月。

当前本机scikit-learn 1.9.0：随机森林在bootstrap抽样时按sample_weight给出抽样概率，叶内有效权重为抽样次数，不能再次乘月份权重；无bootstrap的极端随机树直接采用月份权重。读取实际estimators_samples_，以每棵树有效叶内样本权重的平均构造条件经验分布，逐行核对其七类概率等于predict_proba。版本或语义改变应报错。依据[官方森林文档](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.RandomForestClassifier.html)及本机实际源码核验。

全局版本：同现有方案，七类分别用全体成熟训练的加权32个中点分位代表幅度。局部版本：每个预测股票按森林叶内权重，七类分别取32个中点分位；类概率保持精确不变。分位插值采用加权CDF中心，与原方法一致。无质量的类用固定占位且权重0；精确零单独一类。局部是经验分布的有限分位近似，不能称为精确完整CDF。

每种森林固定3个版本：全局幅度与B各半、局部幅度与B各半、局部幅度独立，共6个新增候选。全局/局部混合版本的方向边际必须逐值一致；用解析边际避免浮点求和破坏完全相同概率的平局处理，不改p_up>p_down规则。未选全局独立版本，避免只为候选数量重复试验。

报告完整目标评分和同模型局部/全局、局部独立/混合的配对增量。概率核验包括训练时点、原人群/标签不变、训练内填补、bootstrap语义、类质量、所有预测缓存重建。测试验证算法正确性，不作为目标已达成证据。
