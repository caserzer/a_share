# R47：成熟历史学习的神经网络概率校准，评分前方案

R46完成163候选均未达到双20%。继续原R15 B、原27,600股票月、1/3/6月各自三项概率误差降低20%和命中率相对提高20%的12项要求。本轮不更换基线、筛股票或剔除校准预热月份；所有结果仍是重复历史探索。

R46将总体概率强制对齐原B，6月部分改善却损害1月。本轮检验从成熟历史学习偏移能否避免错误地假设B总体概率正确。固定复用R45 alpha=16独立/50%B混合两个分布，各做方向截距与七档校准，四新候选。基础网络不重训，不新增外部数据。

每一当前预测月，只使用原预测起点date<当前日期、label_end<当前日期且actual已知的原始R45预测；最近36个有成熟标签的起点月。方向拟合还排除真实零结果（但预测时保持零概率），按过滤后起点月均衡权重。至少12个成熟起点月才拟合；不足时逐值保留原预测，不能借用训练内结果或删掉预热月。滚动历史可包含之前的评估期观测，但必须已经到期。

方向：保持斜率1，只拟合条件上涨logit的共同截距b，以月份等权二元对数损失+0.01*b^2最小化，b限制[-2,2]。用导数单调性检查边界，否则brentq求根，xtol=1e-12；保持各股零质量以及涨/跌方向内幅度形状。该变换保留条件上涨排序，不声称p_up-p_down排序完全相同。

七档：完整复用R22校准器，softmax(a*log(max(p,1e-6))+b_k)，a在[.25,4]，七个b_k在[-2,2]，月份等权多类对数损失+0.01*||(a,b)-(1,0)||^2；L-BFGS-B上限300、ftol=1e-12、gtol=1e-7。优化失败即显式失败。只替换各档质量，档内幅度原子形状不变。七档版不保证上涨排序不变。

校准每次从同一恒等先验开始，无测试期参数选择或期限分别选优。源输入由原缓存重建，源预测及训练截止已在R45核验，当前再次核对哈希和成熟期。保存成熟历史键/概率/标签摘要、参数、目标损失、有效标记和每份预测。独立核验768个时点/候选、预热逐值原样、全部331,200条新预测以及完整原样本，月份等权、12月块2000次seed24配对区间。方向/七档各对自己的原分布，七档对方向；最终目标仍只相对原B。

不把预热后子集替代全样本验收，不把回顾性已看到的R45结果当成独立留出确认。记录校准有效月份、参数范围、方向排序、阶段及概率可靠性。继承原数据版本与基础网络有限轮数未确认收敛的边界。
