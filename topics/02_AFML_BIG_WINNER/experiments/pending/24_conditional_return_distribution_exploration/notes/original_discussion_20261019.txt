# A股个股条件收益分布预测与动态仓位管理——完整研究总结

研究讨论整理｜2026年10月19日

## 一、研究背景与核心目标

### 1.1 最初的问题

我们希望建立一套适用于中国A股市场的投资决策系统。

在选择某只股票时，综合分析以下信息：

- 估值信息：PE历史分位数、PB、盈利收益率E/P、前瞻估值。
- 基本面信息：公司财报、EPS增长、ROE、自由现金流、盈利预期变化。
- 市场环境：牛熊状态、流动性、风险偏好、市场风格。
- 信用与利率环境：信用利差、信用收缩与扩张、利率水平及变化。
- 技术指标：价格趋势、均线、动量、成交量、波动率。
- 前瞻收益率：未来6～12个月潜在投资回报。

通过这些信息，判断一只股票未来可能上涨或下跌的幅度及概率，从而形成投资赔率，再根据赔率决定应投入的资金规模。

研究的最终目标不是简单判断“股票便宜还是贵”，而是解决以下四个问题：

1. 未来可能发生什么？ 不同上涨、下跌情景及其概率。
2. 这笔投资是否值得承担风险？ 预期收益、超额收益、尾部损失。
3. 应当投入多少资金？ 单只股票仓位及组合边际风险。
4. 模型的预测是否真的可靠？ 通过严格样本外实验进行验证。

### 1.2 研究中的关键转变

讨论中形成了一个重要认识：

不应该直接将PE、信用利差、财报、技术指标等转换成0～100分，然后机械地按照评分决定仓位。

这种做法存在几个缺陷：

- 不同指标可能包含大量重复信息。
- 高评分不一定意味着高胜率。
- 高胜率不一定意味着正的预期收益。
- 相同预期收益可能对应截然不同的尾部风险。
- 单只股票看起来赔率很好，不一定适合已经持有的投资组合。
- 对预测的不确定性没有充分处理。

因此，整个研究应从“多因子评分”升级为：

条件概率分布预测 → 概率质量验证 → 投资价值计算 → 组合仓位优化。

## 二、整体理论框架

输入层

估值 · 财报 · 宏观 · 信用 · 技术 · 行业

所有数据必须是投资决策时已知的信息

核心研究层

预测未来收益的条件概率分布

\\(F\_{i,t,h}(r)=P(R\_{i,t,h}\leq r\mid X\_{i,t})\\)股票 i 在 t 时点，未来 h 期的收益分布

概率分布验证层

Calibration · CRPS · PIT · 尾部分位数

证明预测不仅合理，而且优于简单基线

投资决策层

期望收益 · 风险溢价 · 尾部损失 · 预测置信度

区分高回报机会与高风险补偿

资金管理层

凯利准则 · Black-Litterman · 组合优化

结合现有持仓、资产相关性及风险约束确定仓位

这套体系涉及四条主要研究路线：

| 研究领域    | 英文名称                           | 主要解决的问题         |
| ------- | ------------------------------ | --------------- |
| 资产收益预测  | Expected Return Forecasting    | 哪些信息能够预测未来收益    |
| 概率预测    | Probabilistic Forecasting      | 未来不同收益结果的概率是多少  |
| 贝叶斯资产配置 | Bayesian Asset Allocation      | 如何根据预测置信度修正收益预期 |
| 最优仓位管理  | Kelly / Portfolio Optimization | 如何把概率优势转化为资金配置  |

### 2.1 核心模型的数学形式

对于股票 \\(i\\)，在时间 \\(t\\)，预测未来 \\(h\\) 个月总收益率：

\\[ R\_{i,t,h}=\frac{P^{TR}\_{i,t+h}}{P^{TR}\_{i,t}}-1 \\]

其中 \\(P^{TR}\\) 为处理了分红、送转等因素的总收益价格序列。

预测模型不是输出单个收益率，而是：

\\[ \boxed{F\_{i,t,h}(r)=P(R\_{i,t,h}\le r\mid X\_{i,t})} \\]

\\(X\_{i,t}\\) 包括当时可以观察到的全部有效信息。

从这个条件分布中，可以推导：

| 预测变量               | 公式或含义                 | 投资用途      |
| ------------------ | --------------------- | --------- |
| 预期收益               | \\(E[R]\\)            | 判断潜在回报    |
| 上涨概率               | \\(P(R>0)\\)          | 判断盈利可能性   |
| 超额收益概率             | \\(P(R>R_b)\\)        | 判断跑赢基准的概率 |
| 收益波动率              | \\(\sigma(R)\\)       | 衡量整体不确定性  |
| 左尾分位数              | \\(Q\_{05},Q\_{10}\\) | 评估极端亏损阈值  |
| Expected Shortfall | 最差5%情景下的平均损失          | 衡量尾部风险    |
| 预测置信度              | 模型参数和预测分布的不确定性        | 防止过度配置    |

这里特别强调：

预测收益率的不确定性，与收益率本身的波动性，是两个不同的概念。

即使某模型预测未来一年收益波动范围很小，也不能说明它的预测准确性很高。

## 三、如何定义真正的投资赔率

### 3.1 用情景概率代替单一目标价

讨论中使用了一个假设案例。

某股票当前价格100元，预测未来一年：

| 情景 | 发生概率 | 未来价格 | 对应收益 |
| -- | ---- | ---- | ---- |
| 乐观 | 30%  | 150元 | +50% |
| 中性 | 45%  | 115元 | +15% |
| 悲观 | 25%  | 70元  | -30% |

则期望收益：

\\[ E(R)=0.30(50\\%)+0.45(15\\%)+0.25(-30\\%) \\]

\\[ \boxed{E(R)=14.25\\%} \\]

上涨概率是75%。

假设低风险收益率为2%，预期超额收益约为12.25个百分点。

但这个股票并不因为上涨概率达到75%，就自然值得投入大量资金。

原因在于：

- 盈利概率只描述方向，没有充分描述盈利和亏损的幅度。
- 左侧尾部损失可能很大。
- 模型本身可能过度自信。
- 已有持仓可能高度暴露于相同风险因素。

真正有价值的是整个收益分布，而不是胜率或者预期收益单独一个数字。

### 3.2 高胜率不代表高赔率

举一个更极端的例子。

假设某策略：

- 90%概率赚5%；
- 10%概率亏60%。

那么：

\\[ E(R)=0.9(5\\%)-0.1(60\\%)=-1.5\\% \\]

虽然胜率达到90%，预期收益却是负数。

相反，一个胜率只有40%、盈利时赚60%、亏损时损失20%的策略：

\\[ E(R)=0.4(60\\%)-0.6(20\\%)=12\\% \\]

反而具有正的期望收益。

因此，研究中必须同时关注概率、收益幅度及尾部风险。

## 四、如何利用PE、财报、宏观和技术指标预测收益分布

### 4.1 不同因子承担不同角色

| 因子类别  | 典型指标           | 主要作用         | 需要注意的问题         |
| ----- | -------------- | ------------ | --------------- |
| 估值    | PE、PB、E/P、历史分位 | 估值回归、潜在风险溢价  | 低估值可能源自盈利恶化     |
| 盈利质量  | ROE、利润率、FCF    | 判断未来盈利增长与持续性 | 财报数据存在披露延迟      |
| 盈利预期  | EPS增长、盈利修正     | 判断未来现金流变化    | 需要有历史时点数据       |
| 市场环境  | 流动性、趋势、风险偏好    | 识别状态和估值变化    | 不同状态之间会发生切换     |
| 信用环境  | 信用利差、信用扩张      | 判断融资压力和风险溢价  | 短期风险与长期收益可能方向相反 |
| 技术指标  | 动量、均线、成交量、波动率  | 趋势、入场时机及风险   | 与市场状态可能重复       |
| 前瞻收益率 | 盈利及估值共同推导      | 定价锚、预测输出     | 不应当与原始因子重复计分    |

### 4.2 财报与估值的基本分析框架

对适合PE估值且盈利为正的企业：

\\[ P_t=EPS_t\times PE_t \\]

未来股价变化可以分解为：

\\[ \frac{P\_{t+1}}{P_t} = \frac{EPS\_{t+1}}{EPS_t} \times \frac{PE\_{t+1}}{PE_t} \\]

例如：

- 未来EPS增长20%；
- PE由20倍收缩为18倍。

则：

\\[ 1.2\times\frac{18}{20}-1=8\\% \\]

企业盈利增长20%，不代表股价也会上涨20%。

价格回报取决于盈利增长和估值倍数变化的共同结果。

若进一步考虑股息，则得到更完整的总回报预测。

因此，条件概率模型本质上需要预测两个高度相关的随机变量：

1. 未来盈利增长的概率分布。
2. 未来估值倍数变化的概率分布。

也可以不显式拆解这两个变量，而直接学习未来总收益的条件分布。

直接学习最终收益分布更容易建立基线；显式分解则更便于解释投资逻辑。

### 4.3 PE历史分位数不能直接对应上涨概率

例如：

> 当前PE处于过去10年的第10百分位。

不能直接解释为：

> 未来上涨概率为90%。

PE分位数只是一个条件特征。

需要通过历史数据实证验证，在相似估值、盈利、行业及市场环境下，股票未来12个月收益分布是否存在系统性差异。

还必须区分估值低是由市场错误定价造成，还是由于盈利处于周期高点、未来利润即将下滑造成。

### 4.4 信用利差的作用可能是非线性的

之前讨论了一个重要问题：

信用利差上升不一定同时意味着短期和长期股票预期收益都下降。

它可能对应两种不同机制。

| 机制          | 市场影响          | 对股票预测的作用      |
| ----------- | ------------- | ------------- |
| 信用收缩、融资压力上升 | 风险偏好下降，估值压缩   | 短期收益和尾部风险恶化   |
| 风险资产被重新定价   | 风险溢价上升，资产价格下降 | 未来较长期预期回报可能提高 |

因此不能简单规定“利差上升扣10分”。

更合理的方式是将以下变量同时纳入：

- 信用利差绝对水平。
- 信用利差变化幅度。
- 信用利差变化速度。
- 市场风险偏好。
- 当前股票估值。
- 预测时间跨度。

并研究信用利差是否只在某些市场状态下具有预测能力。

中国信用市场还存在隐性担保、信用风险定价不充分等特征，因此不能直接照搬美国高收益债利差模型。

### 4.5 技术指标的两种使用方式

讨论中提出两条竞争路线：

路线A：技术指标主要用于仓位和入场决策。

例如股票估值与财报显示未来收益分布有吸引力，但价格持续破位，则降低初始仓位，等待趋势确认。

路线B：技术指标直接参与收益概率预测。

例如动量、换手率和波动率可以改变未来收益分布的均值、离散程度及尾部形态。

两种方法均有研究依据，不能先入为主认为某一种一定更好。

应通过样本外预测效果与最终投资效果来选择。

## 五、从收益概率分布到投资金额

这是整个体系的第二个研究阶段，不应在概率预测尚未验证前就作为首要任务。

### 5.1 凯利准则

对于简单的二元赌局，凯利公式为：

\\[ f^\*=\frac{bp-(1-p)}{b} \\]

但A股具有连续、不对称且可能肥尾的收益分布，因此更加合适的是连续收益形式：

\\[ \boxed{\max_f E[\ln(1+fR)]} \\]

其中：

- \\(f\\) 为投资仓位；
- \\(R\\) 为该资产未来收益率；
- 目标是最大化长期财富对数增长率。

如果同时持有多只股票，则扩展为：

\\[ \boxed{\max\_{\mathbf w}E[\ln(1+\mathbf w^\top\mathbf R)]} \\]

多资产形式必须考虑股票之间的相关性，以及它们在极端情景下同时亏损的可能性。

在某些简化假设下，凯利仓位可以近似为：

\\[ f^\*\approx\frac{\mu-r_f}{\sigma^2} \\]

但它对于预期收益参数极为敏感。

如果错误地高估了预期收益，就很容易计算出不合理的大仓位，甚至是杠杆仓位。

因此，可以研究部分凯利、仓位上限和风险约束，而不是机械执行完整凯利公式。

### 5.2 Black-Litterman与预测置信度

Black-Litterman可以作为控制收益预测不确定性的参考框架。

其基本思路是：

- 首先确定一个基准预期收益。
- 使用估值、财报和其他信号产生新的收益判断。
- 根据这些判断的置信程度修正基准预期。
- 将调整后的预测输入组合优化。

例如：

模型预测某只股票12个月预期收益20%，但历史验证表明这一类预测误差较大。

那么不应直接使用20%决定仓位，而应向较保守的基准预期收缩。

需要注意：标准Black-Litterman主要融合预期收益及协方差相关的信息，它本身并不直接解决完整非正态收益分布的优化问题。对于肥尾、多峰分布，仍需要情景优化、稳健优化或其他扩展。

### 5.3 仓位必须从组合角度优化

单只股票预期收益很高，并不意味着新增它一定提高组合的风险调整后收益。

例如，原有组合已经大量持有新能源汽车产业链，新增另一家电池企业可能进一步集中：

- 同一行业盈利风险。
- 相同原材料成本风险。
- 同一市场风格风险。
- 相同政策及融资条件风险。

所以，最终应回答的是：

新增一个仓位对整个组合的预期收益、波动率、最大回撤和尾部损失会产生什么影响？

个股条件收益分布是必要输入，但不足以完成多资产仓位优化。

还需要资产之间的相关性、共同风险因素和联合尾部情景。

# 六、如何验证未来收益率的条件概率分布

这是整个讨论中最重要的部分。

我们最终将研究重心确定为：

> 先证明模型能够可靠地预测A股未来收益的条件概率分布，再研究如何根据该分布决定仓位。

仅仅回测获得正收益，不能证明概率分布预测正确。

原因是一个概率预测系统即使没有预测能力，也可能因为某段时期市场整体上涨而赚钱。

同样，一个概率预测准确的模型，也可能因为资金管理方式不合理而亏损。

因此必须将预测质量和投资表现分开验证。

## 6.1 验证体系分为四个层次

| 验证层次   | 核心问题             | 主要指标                            |
| ------ | ---------------- | ------------------------------- |
| 概率校准   | 预测的上涨概率是否可信      | Reliability Diagram、Brier Score |
| 分布校准   | 预测的收益幅度和尾部风险是否可信 | PIT、分位数覆盖率                      |
| 增量预测能力 | 因子和复杂模型是否真的有用    | CRPS、样本外评分差异                    |
| 投资有效性  | 概率预测能否改善仓位管理     | 净收益、回撤、Calmar、风险调整后收益           |

## 6.2 第一层：上涨概率校准

假设模型预测500只股票未来一年上涨概率，其中某组股票的预测概率介于65%～75%。

需要观察这组股票一年后实际有多少上涨。

如果模型预测概率的平均值为70%，那么在样本充分且条件合适的情况下，实际上涨频率也应接近70%。

例如：

| 预测上涨概率 | 实际上涨频率 | 解释         |
| ------ | ------ | ---------- |
| 30%    | 32%    | 接近预测       |
| 50%    | 49%    | 接近预测       |
| 70%    | 62%    | 模型偏乐观      |
| 90%    | 67%    | 可能存在严重过度自信 |

这些都是示意数据。

其中Reliability Diagram（可靠性图）用于展示各预测概率区间和实际发生频率之间的关系。

Brier Score则通过预测概率与最终二元事件结果之间的平方误差进行评分：

\\[ BS=\frac{1}{N}\sum\_{i=1}^N(p_i-y_i)^2 \\]

其中 \\(y_i\\) 取0或1，评分越低越好。

不过，概率校准准确不意味着模型一定有用。

如果一个模型永远预测60%上涨，而市场确实有60%的股票上涨，它可能校准良好，但没有多少区分个股投资机会的能力。

因此必须同时检验模型的区分能力和预测信息量。

## 6.3 第二层：收益分位数覆盖率

相比单纯预测上涨概率，更重要的是验证未来收益分布的不同分位点。

假设模型预测某只股票未来12个月收益分布：

| 分位点 | 预测收益率 |
| --- | ----- |
| Q05 | -35%  |
| Q10 | -25%  |
| Q50 | +8%   |
| Q90 | +42%  |
| Q95 | +60%  |

如果长期观察模型输出的Q05，理论上应该有约5%的实际收益结果跌破各自预测的Q05。

也就是：

\\[ P(R\_{\text{actual}}\<Q\_{05})\approx5\\% \\]

如果实际跌破比例达到9%，说明模型可能严重低估尾部风险。

但不能只检验覆盖率。

一个预测区间极其宽泛的模型可以获得不错的覆盖率，却缺乏实际投资价值。

因此需要同时评价预测区间是否准确、是否过宽。

## 6.4 第三层：PIT检验完整分布

PIT，即Probability Integral Transform。

定义：

\\[ u\_{i,t}=F\_{i,t}(R\_{i,t}^{actual}) \\]

将实际收益代入模型事先预测的累计分布函数。

对于理想的连续型概率预测，PIT在总体上应呈现0～1的均匀分布。

| PIT形态  | 可能的问题             |
| ------ | ----------------- |
| 近似均匀   | 整体分布校准较好          |
| U形     | 模型预测分布可能过窄，低估极端收益 |
| 中间凸起   | 模型预测分布可能过宽        |
| 向某一侧倾斜 | 预测分布可能存在系统性偏差     |

但总体PIT分布均匀并不能保证条件校准正确。

例如模型可能在牛市中低估收益、熊市中高估收益，两个方向相互抵消，使得整体检验结果看起来正常。

因此必须按市场状态、行业、估值区间和波动率环境分别进行验证。

## 6.5 第四层：CRPS评价完整收益分布

CRPS（Continuous Ranked Probability Score）是讨论中选定的核心模型比较指标。

其定义为：

\\[ CRPS(F,y)= \int\_{-\infty}^{\infty} [F(z)-\mathbf1(y\le z)]^2dz \\]

与只检验上涨方向的指标不同，CRPS会评价整个预测分布与最终实现结果之间的差异。

主要特点：

- 同时考虑收益方向和收益幅度。
- 对预测分布的位置与离散程度进行评价。
- 可以用于不同模型之间的直接比较。
- 分数越低越好。

CRPS采用一致的收益率计量单位时可以比较模型，但不能跨不一致的目标变量、收益尺度或测试样本直接比较。

建议将CRPS作为主要模型选择指标，同时保留上涨概率校准和尾部分位数覆盖率作为约束指标。

# 七、怎样证明PE、财报、信用利差具有真实增量价值

这个问题比简单检验模型能否赚钱更加重要。

例如一个复杂模型预测准确，可能只是因为它学会了：

- 高波动股票未来收益范围更宽。
- 小市值股票收益分布更分散。
- 牛市期间股票整体更容易上涨。

这些信息确实有用，但不能证明PE分位数或者信用利差具有独立的预测作用。

因此我们提出采用 Ablation Study（消融实验）。

## 7.1 逐步加入因子的对照实验

| 模型 | 增加的信息          | 验证目的         |
| -- | -------------- | ------------ |
| M0 | 历史收益分布、市场及行业基准 | 建立最低预测基线     |
| M1 | 市场状态、波动率       | 市场环境是否改善预测   |
| M2 | PE分位数、E/P、PB   | 估值信息是否有增量价值  |
| M3 | ROE、盈利增长、现金流   | 财报信息是否改善预测   |
| M4 | 信用利差、利率        | 信用与资金环境是否有价值 |
| M5 | 动量、均线、成交量      | 技术指标是否进一步改善  |

所有模型必须：

- 使用相同的预测时间点。
- 使用相同的股票样本。
- 预测相同的未来持有期。
- 使用完全一致的真实收益标签。
- 遵守相同的数据时点限制。

比较每一次增加因子之后的样本外CRPS变化，以及校准和尾部风险预测是否改善。

需要强调，逐步加入因子的顺序本身会影响测得的边际贡献。

因此，如果要判断信用利差是否具有独立价值，还应该在不同因子组合下重复移除或加入信用利差，不能只依赖M3与M4的一次比较。

## 7.2 检验条件预测能力

信用利差是最值得做条件验证的变量之一。

例如：

- 在信用扩张时期，信用利差对未来12个月收益预测可能没有明显帮助。
- 在信用收缩时期，信用利差可能明显改善左尾风险预测。
- 在信用压力高位但开始改善时，信用利差可能对未来风险溢价具有不同的解释力。

如果总体平均CRPS改善很小，但在某些市场状态下改善显著，那么信用利差依然可能是有价值的条件变量。

应该重点检验：

\\[ P(R\mid PE,\text{Credit Spread},\text{Regime}) \\]

与：

\\[ P(R\mid PE,\text{Regime}) \\]

之间是否存在稳定的样本外预测质量差异。

研究中可以采用预测损失差异检验、分组分析及时间块Bootstrap估算统计置信区间。

相关理论参考：

[Giacomini & White（2006）：Tests of Conditional Predictive Ability](https://doi.org/10.1111/j.1468-0262.2006.00718.x?utm_source=chatgpt.com)。

# 八、已经找到的公开模型和开源项目

这是我们讨论的最后一个重要进展。

目前存在多种可以直接用于实验的开源预测模型，但需要区分：

1. 能直接预测收益分布的公开模型架构。
2. 已经针对中国A股训练并充分验证的成品模型。

前者比较丰富，后者尤其是在未来6～12个月条件收益分布预测方面，还没有找到可以直接作为成熟标准的公开权重模型。

## 8.1 公开模型总体对照

| 模型                       | 类型       | 输出内容           | A股适配难度 | 主要用途      |
| ------------------------ | -------- | -------------- | ------ | --------- |
| 历史条件经验分布                 | 非参数统计    | 经验CDF与分位数      | 低      | 最低基准      |
| CatBoost MultiQuantile   | 梯度提升树    | 条件收益分位数        | 低      | 第一版主要模型   |
| NGBoost                  | 概率提升模型   | 参数化概率分布        | 低—中    | 参数化基线     |
| Quantile Neural Networks | 神经网络     | 多分位数及重建的分布     | 中—高    | 学术研究基线    |
| GARCH / EGARCH-t         | 传统金融时间序列 | 条件波动率及假设下的收益分布 | 中      | 传统模型对照    |

## 8.2 重点论文：Quantile Neural Networks

Forecasting Stock Return Distributions Around the Globe with Quantile Neural Networks

Jozef Baruník、Martin Hronec、Ondřej Tobek

前面检索到的2026年版本；arXiv编号2408.07497。

[论文](https://arxiv.org/abs/2408.07497?utm_source=chatgpt.com)[GitHub源码](https://github.com/ondrejtobek/quantile-neural-networks?utm_source=chatgpt.com)

它与我们的目标高度相关。

该研究不是只预测收益率均值，而是利用公司特征、市场信息及波动率等数据，对股票未来收益的多个条件分位数进行预测。

然后通过插值等方式构造连续收益概率分布。

进一步可以计算：

- 期望收益和方差。
- 收益偏度及峰度。
- 上涨概率。
- 极端亏损概率。
- 不同收益分位点。
- 其他分布统计特征。

论文研究以未来一个月收益分布为主要预测对象。

这与我们希望预测未来6～12个月收益分布存在一定差异，因此需要重新训练、重新定义预测目标，而不能直接套用原模型结论。

作者公开的代码包括：

| 文件                            | 用途              |
| ----------------------------- | --------------- |
| `ChampionModel.ipynb`         | 核心模型示例          |
| `02_QuantileNN_Estimation.py` | 分位数神经网络估计       |
| `03_GARCH_Estimation.py`      | GARCH对照         |
| `04_DistributionMoments.py`   | 收益分布统计矩         |
| `06_RobustnessGBRT_RF.py`     | 梯度提升树和随机森林稳健性检验 |

其优势是已经包含相对完整的研究流程，而不是只有一个模型定义。

限制在于：论文使用的部分数据涉及WRDS等外部数据库，公开代码并不意味着所需数据和训练后的A股模型均已公开。

## 8.3 CatBoost MultiQuantile

[CatBoost GitHub](https://github.com/catboost/catboost?utm_source=chatgpt.com)

这是我们最推荐优先跑通的机器学习基线。

理由：

- 原生支持多分位数回归。
- 对财务和估值类表格数据较友好。
- 可以结合数值变量、行业分类和市场状态。
- 实验复杂度相对较低。
- 容易进行因子消融和特征重要性分析。

示例：

```
from catboost import CatBoostRegressormodel = CatBoostRegressor(    loss_function=(        "MultiQuantile:"        "alpha=0.05,0.10,0.25,0.50,"        "0.75,0.90,0.95"    ),    iterations=800,    depth=6,    learning_rate=0.03,    verbose=False)model.fit(X_train, y_train)quantiles = model.predict(X_test)
```

这里：

- `X_train` 是预测日已知的估值、财务、宏观和技术信息。
- `y_train` 是对应未来12个月已经实现的收益率。
- `quantiles` 是模型对测试集股票输出的各个收益分位数。

需要进一步解决分位数交叉、插值、概率校准及分布两端尾部外推问题，才能形成真正完整的CDF。

## 8.4 NGBoost

[Stanford NGBoost](https://github.com/stanfordmlgroup/ngboost?utm_source=chatgpt.com)

NGBoost直接预测概率分布的参数，并可通过分布对象计算CDF及分位数。

优点是概率预测接口较自然。

主要限制是它依赖所选分布族。

如果使用简单正态分布，可能无法描述A股收益的肥尾及不对称性。

因此，NGBoost适合作为参数化概率回归基线，但必须检验尾部拟合质量。

## 8.5 GARCH / EGARCH-t

[ARCH Python](https://github.com/bashtage/arch?utm_source=chatgpt.com)

GARCH类模型主要用于条件波动率预测。

在指定均值、波动率模型和误差分布后，可以通过多期模拟形成未来12个月收益分布。

它对于财报、PE及信用利差等横截面信息的利用不如专门的因子模型直接。

但它是一套非常重要的传统金融计量基线：

必须证明复杂的概率机器学习模型不只是复制了传统波动率模型可以获得的信息。

## 8.6 Microsoft Qlib

[Microsoft Qlib](https://github.com/microsoft/qlib?utm_source=chatgpt.com)

Qlib与上述模型的定位有所不同。

它主要负责：

- A股量化数据处理。
- 因子构建与特征计算。
- Alpha158、Alpha360等特征体系。
- LightGBM等基线模型。
- 回测工作流。
- 策略评价与实验管理。

Qlib主要面向收益预测与排序，并不天然提供完整概率分布评估流程。

因此，建议把它用作实验基础设施，而不是把传统的LightGBM点预测当成概率预测模型。

# 九、最终确定的基线实验方案

经过比较，我们形成了以下建议。

## 9.1 第一阶段采用四套主要基线

| 编号 | 模型                       | 核心作用        | 优先级  |
| -- | ------------------------ | ----------- | ---- |
| B0 | 历史条件经验分布                 | 最低性能基准      | 必须   |
| B1 | CatBoost MultiQuantile   | 主要可解释非线性模型  | 必须   |
| B2 | NGBoost                  | 参数化概率分布比较   | 建议   |
| B3 | Quantile Neural Networks | 与公开学术研究方法对照 | 第二阶段 |

另外，GARCH-t用于传统时间序列模型对照，Qlib作为数据和实验框架。

### 为什么B0极其重要？

B0可以只根据行业、市值、市场状态和历史波动率，选取相似历史样本，估算未来12个月的经验收益分布。

例如：

在当前市场环境下，找出历史上具有类似行业、市值与波动水平的股票，观察它们后续12个月收益，构建条件经验CDF。

实现时应设置最小样本要求，并对稀疏分组进行平滑和向更大样本组收缩。

如果复杂模型在严格样本外检验中不能稳定优于B0，那么没有理由因为它更复杂就认为它更可靠。

## 9.2 第一版统一预测输出

每次预测都应保存：

\\[ \boxed{ \left[ E(R), P(R>0), P(R>R_b), Q\_{05},Q\_{10},Q\_{50},Q\_{90},Q\_{95} \right] } \\]

同时保留完整的分布表示（CDF参数、可重建的分位点或模拟样本），而不是只保存上述摘要。

原因是后续需要继续计算CRPS、任意亏损阈值概率、Expected Shortfall，以及投资决策中的其他风险量。

## 9.3 不建议一开始就采用大量复杂模型

研究重点不是寻找最高复杂度的算法，而是回答：

- 增加估值数据是否改善预测？
- 财报是否产生独立预测价值？
- 信用利差是否能够识别收益分布的变化？
- 是否存在随市场状态变化的预测规律？
- 在12个月预测期限下，复杂模型是否优于简单统计模型？

如果这些问题没有被回答，继续增加机器学习模型只会提高研究成本与过拟合风险。

# 十、A股历史回测的实验设计

## 10.1 推荐研究时间范围

在前面讨论中，我们提出以下初步时间安排：

2012—2018

初始训练期

研究基础关系、构建初始模型与数据处理规则。

2019—2021

验证期

模型选择、超参数调整、概率校准和因子组合选择。

2022—2025年9月

最终预测起始日测试期

冻结研究规则并进行滚动样本外预测，12个月收益结果截至2026年9月已基本可以观察。

这里有一个重要的实现细节。

对未来12个月收益进行预测时，训练集必须只包含已经完整实现的12个月收益标签。

例如，在2022年1月31日训练模型时，不能使用2021年12月形成的12个月预测样本的最终收益，因为那时结果尚未发生。

训练、验证之间还应考虑样本标签重叠带来的信息泄漏，使用与持有期一致的时间隔离或Purged Walk-forward方法。

### 10.2 使用滚动样本外验证

研究流程如下：

2022年1月：形成全部股票预测

只使用当时可获得的数据和已经成熟的训练标签。

2022年2月：向前移动一期

按预先规定的重训练规则更新模型，再形成新的预测。

逐月滚动到测试期末

保存全部预测分布，不允许根据未来表现反向修改已保存的预测。

集中评价样本外预测

检验概率校准、CRPS、尾部风险及不同市场状态下的稳定性。

模型的结构选择及调参规则应在最终测试阶段前固定。滚动重训练可以进行，但必须遵循事先约定的规则。

## 10.3 A股数据需要特别防范的问题

| 风险     | 产生的偏差            | 处理原则             |
| ------ | ---------------- | ---------------- |
| 财报未来函数 | 提前使用尚未公布的利润和财务指标 | 按真实公告日期及可用时点获取   |
| 估值未来函数 | 使用后来修订的利润或历史分位参数 | 采用历史时点数据和滚动计算    |
| 幸存者偏差  | 排除已退市股票，高估表现     | 保留历史退市股票         |
| 涨跌停与停牌 | 预测收益可能无法实际交易获得   | 区分预测收益与可实现交易收益   |
| 交易成本   | 高估投资策略实际收益       | 纳入佣金、交易税费及冲击成本   |
| 行业结构变化 | 不同时期估值不可简单对比     | 使用行业、上市时间等条件     |
| 极端PE   | 盈利接近零时分位数失真      | E/P、盈利稳定性及替代估值处理 |
| 收益标签重叠 | 统计显著性被高估         | 时间块抽样与稳健推断       |
| 股票共同涨跌 | 横截面样本不独立         | 按日期和市场状态联合检验     |
| 反复试验模型 | 最终测试集被间接用于调参     | 独立测试与事前研究规则      |

特别强调一个统计问题：

如果有3000只股票，每个月形成一次12个月收益预测，那么一年可能获得36,000条预测记录。

但这绝不是36,000次独立实验。

因为：

- 很多股票受到相同市场因素影响。
- 相邻月份的12个月收益包含大量相同交易日。
- 行业内部股票的收益具有相关性。

因此不能简单以预测条数计算置信水平。

# 十一、模型是否验证成功：验收标准

此前讨论形成了一个初步验收体系。

| 验收维度   | 通过条件              | 失败信号          |
| ------ | ----------------- | ------------- |
| 上涨概率校准 | 预测频率与实际频率相符       | 预测高概率组持续过度乐观  |
| 分位数覆盖率 | Q05、Q10、Q90等覆盖率合理 | 左尾损失明显超出预测    |
| PIT    | 无明显系统性分布失真        | U形、偏斜及条件失配    |
| CRPS   | 样本外优于简单基线         | 复杂模型不如经验分布    |
| 因子增量   | 估值、财报等改善有重复性      | 仅训练集存在效果      |
| 状态稳定性  | 不同市场环境下误差可控       | 熊市或信用收缩期失效    |
| 投资经济价值 | 在费用及风险约束后改善组合表现   | 预测指标改善但实盘价值不足 |

这里需要进一步明确：目前这些是建议的验收方向，并非已经完成检验的结果。

例如可以预先设定：

- 在最终样本外测试中，主要模型CRPS改善必须具有统计支持。
- 左侧5%尾部分位点不能持续系统性低估损失。
- 与B0相比，模型必须展示有意义的增量预测能力。
- 预测优势不能完全由某一特殊市场年份贡献。
- 在不同投资组合约束下，仓位策略改善具有一定稳定性。

具体允许的概率误差和分布评分改善门槛，需要结合实际样本量、有效独立观测数量和投资用途预先制定，不宜随意指定一个统一的百分比。

# 十二、建议的三个核心研究实验

## 实验A：PE分位数对A股未来12个月收益的预测价值

建议优先开展

核心假设

在控制行业、市值、企业盈利增长和市场状态后，估值水平仍能提供关于未来12个月收益分布的增量信息。

方法

首先构建不含PE的条件经验分布基线，再增加PE历史分位数或E/P。

对比完整收益分布预测的CRPS、分位数覆盖率及条件概率校准情况。

最值得验证的问题

当前PE处于历史低位，究竟对应：

- 更高的未来上涨概率？
- 更高的收益中位数？
- 更厚的右侧尾部？
- 更大的左侧风险？
- 仅仅是更高的风险补偿？

这几个结果在经济意义上截然不同。

## 实验B：信用利差与市场状态的条件作用

核心假设

信用利差能够改变股票未来收益的条件分布，但影响可能依赖预测期限及市场状态。

方法

比较相同股票在高低信用利差、信用扩张收缩及估值状态下的未来收益分布。

重点关注：

\\[ P(R\_{12m}< -30\\%\mid X) \\]

以及不同市场状态下的CRPS改善。

核心价值

验证信用利差究竟提供短期风险预警、长期风险溢价预测，还是两种功能兼具。

## 实验C：概率预测是否可以改善仓位管理

核心假设

相对于简单等权或固定风险仓位，使用经过校准的条件收益分布可以改善风险调整后的投资表现。

测试至少包括：

| 仓位方案 | 定义                     |
| ---- | ---------------------- |
| S0   | 等权投资                   |
| S1   | 固定风险预算或逆波动率仓位          |
| S2   | 根据估值分层设置仓位             |
| S3   | 根据模型预期收益设置受限仓位         |
| S4   | 根据完整预测分布优化仓位           |
| S5   | 根据预测分布、模型不确定性和组合风险联合优化 |

对比：

- 年化收益率。
- 最大回撤。
- Calmar Ratio。
- 收益波动率。
- 尾部损失。
- 换手率与交易成本。
- 行业和风格风险暴露。

需要注意的是，S4和S5不能只把个股分布简单拼接到一起，还必须引入资产之间的依赖结构或联合情景。

# 十五、尚未解决的重要研究问题

整个讨论明确了研究框架，但以下问题仍然开放。

### 15.1 预测期限的选择

我们希望预测未来6～12个月收益，但股票价格的短期波动和中长期价值回归机制可能完全不同。

需要分别研究：

- 1个月的收益分布是否更容易预测？
- 3个月、6个月与12个月的条件信息价值是否不同？
- 信用利差在不同期限下是否具有方向不同的预测能力？
- 是否应该建立多个独立预测期限模型？

特别注意：不能简单把12个独立月度收益分布相乘，当作12个月收益分布，因为收益序列存在动态相关和市场状态变化。

### 15.2 市场状态究竟如何定义

可以使用流动性、信用利差、市场波动率、趋势等构建Regime。

但市场状态也可能是连续变化而非离散标签。

需要比较：

- 不引入市场状态。
- 人工规则定义的风险开启、风险关闭、过渡状态。
- 利用市场变量连续建模。
- 隐马尔可夫模型等自动状态识别方法。

市场状态的划分本身也必须进行时点安全验证，不能利用未来完整行情给历史月份重新打标签。

### 15.3 盈利预测与估值变化是否应该分别建模

第一版可以直接预测股票未来总收益分布。

未来可以进一步研究：

\\[ EPS\_{t+h}\quad\text{与}\quad PE\_{t+h} \\]

的联合分布。

这样可以判断某一投资机会的回报主要源自盈利增长、估值扩张还是风险溢价变化。

但分解模型更复杂，而且两个变量之间可能存在明显依赖关系。

### 15.4 个股分布如何转化为组合联合分布

即使对每只股票的边际收益分布预测准确，也不能保证组合尾部风险预测准确。

例如市场流动性突然收缩时，多只原本相关性不高的股票可能同时大幅下跌。

因此后续必须研究：

- 条件协方差矩阵。
- 行业与风格共同因子。
- 下跌相关性。
- 联合尾部情景。
- 组合Expected Shortfall。
- 模型参数不确定性。

### 15.5 收益预测与可交易收益的区别

一个概率模型可能预测某只股票未来一年上涨概率很高，但股票出现连续涨停时可能无法建立仓位。

同时，停牌、退市、流动性不足等事件可能影响实际投资结果。

因此需要区分三个目标：

1. 个股未来收益分布的统计预测。
2. 可执行交易的实际收益分布。
3. 纳入组合后的边际收益与风险分布。

它们彼此关联，但不能混为一个问题。

# 十六、最后形成的研究结论

整个讨论可以归纳为四项明确结论。

结论一：存在成熟的学术与开源技术基础。

条件分布预测、分位数神经网络、CatBoost MultiQuantile、NGBoost、GARCH、贝叶斯资产配置和凯利准则，都已经有公开研究或开源实现。

我们不需要从零发明整个概率预测方法。

结论二：当前真正缺少的是经过严格验证的A股6～12个月条件收益分布模型。

虽然有公开研究和模型架构，但仍需要完成A股数据适配、重新训练、概率校准和样本外验证。

不应把公开模型存在直接等同于其已经拥有可用于A股实盘投资的预测能力。

结论三：模型价值取决于增量信息，而不是复杂程度。

必须以条件经验分布为最低基准，证明PE、财报、信用利差等因子能够持续改善预测。

如果复杂模型不能在严格样本外测试中超越简单统计模型，就应该优先使用简单模型。

结论四：先验证概率，再优化仓位。

概率预测与仓位管理属于两个不同研究问题。

只有概率分布预测具有足够的可信度，才有基础将它用于凯利准则、风险预算、Black-Litterman或其他组合优化。

## 最终建议：第一版研究任务书

## A股未来12个月条件收益分布预测 v1.0

将整个研究收敛到一个可以被证伪、可复现的核心实验。

研究问题

在控制行业、市值、市场状态和历史波动率后，加入估值、财务、信用与技术信息，能否显著改善A股个股未来12个月总收益率的条件概率分布预测？

研究范围

| 市场   | 中国A股                   |
| ---- | ---------------------- |
| 预测期限 | 12个月为主，3/6个月辅助         |
| 训练数据 | 建议从2012年开始             |
| 测试方式 | 滚动样本外预测                |
| 最低基线 | B0 条件经验分布              |
| 主要模型 | CatBoost MultiQuantile |
| 竞争模型 | NGBoost、Quantile NN    |
| 核心评价 | CRPS、PIT、概率校准、尾部覆盖率    |
| 框架   | Qlib + Python          |

验收目标

证明模型在未见过的未来样本中，能够输出比简单基线更准确、更稳定，并且在关键市场状态下合理校准的股票收益概率分布。

暂不纳入第一版验收

凯利最优仓位、实际资金投入量、组合杠杆及自动交易。这些应在预测验证之后单独研究。

最终，这项研究所追求的不是一个能够告诉我们“这只股票应该买8%仓位”的黑箱，而是一个能够说明：

> 根据今天已经知道的估值、财报、信用和市场状态信息，在历史上可比的条件下，这只股票未来一年出现不同收益结果的概率分别是多少？这些概率预测在样本外究竟有多可靠？相对于不使用这些信息，我们获得了多少可验证的预测优势？

只有先把这三个问题回答清楚，我们才能真正从经验式的“感觉赔率不错”，走向能够验证、校准和持续改进的概率化投资决策。
