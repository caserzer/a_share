# R37：原始公司业绩预告的数据可行性检查

目标仍为同一方案在原样本1/3/6个月概率误差下降20%、方向命中率相对提高20%。本页记录来源可行性检查；后续轻量候选见[评分前方案](r37_guidance_events.md)。来源检查与方案冻结时尚未查看任何新增模型成绩。

巨潮全量目录被拒绝后停止请求；替代来源使用两家交易所独立公开披露目录及文件。深交所两起修订案例的四份PDF与已核验的巨潮文件逐字节一致。

- 深市：原709只股票及有官方证据的000043→001914代码映射；先按“业绩预告”标题检索2017-01-01至2026-04-30。
- 沪市：原533只股票；按季度查询全市场“业绩预”标题，再保留原股票。这样涵盖预告、预增、预减、预亏等常见表述。历史分类存在差异，不能用当前分类过滤整个历史。
- 每页保存原始响应；检查数量、日期、身份及重复。失败即停止相应进程，不记成无公告。不重试已拒绝访问的巨潮接口。
- 两份目录全部完成后，与已取得的巨潮目录交叉核对。查询分页完整不等于所有公告类别完整；正文嵌入式预告、不同标题公告和未收录文档均需保留边界。
- 在不使用收益标签的前提下，每个市场×年份×原始／修订标题分组，以URL哈希排序固定抽取两份文件，最多80份。先检查下载、解析和原文一致性，再决定是否扩展金额解析。抽样失败和不支持格式全部保留。

实际进展与范围调整：深市主体10,261条，加上预增/预减/预亏/预盈四类补查149条，共10,410条，覆盖691只股票；与已有巨潮缓存中2,984条对应标题公告全部匹配。首批深市40份固定抽样已下载并检查，仅11份产生解析候选值，尚未逐份完成金额核验，其余29份格式不受当前解析器支持。为保持探索节奏，暂停扩大金额解析和余下沪市正文抽样，先测试目录时间与标题信息；保留首批选择和所有结果，不宣称完成80份金额认证。这项调整发生在任何新增模型评分之前。

金额可用日期必须基于原始版本，严格早于预测起点。目录取回日期不参与历史特征。原预告与修订公告分别保存，修订值不能倒填。初始四份文件的解析器只能视为小样本原型，不能直接宣称全样本可用。

目录完整性与输入核验通过后，按已冻结的轻量消融执行；仍使用原1242只股票对应的完整预测样本、相同历史月份和原B基线。数据恢复不计入模型候选数量，不属于准确率改善。
