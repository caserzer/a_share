# R33口径澄清（不改变输入或模型）

评分前方案中“相较12个月前同口径合计”的措辞过强。实现使用同一下载序列的12月滚动合计相除，并没有重建历次社融统计扩围的可比口径。因此该项应称“按当前下载序列计算的社融年度变化代理”，不能称央行官方可比口径同比。此澄清不改变已固定的公式、日期、样本或参数。

45天滞后只是保守可用时点假设，原值可能后续修订。对官方原文12条数字的抽查不等于认证所有历史版本。本轮是新增信息探索，不能据此直接宣称严格历史实时预测已经验证。

扩大贷款分项核对：136个重叠月中135个月在亿元取整精度内吻合；2022年6月东方财富贷款字段30540亿元与商务部社融人民币贷款分项61759亿元明显不一致。早先“贷款口径已确认”的表述只得到部分样本支持，不能推广到全序列。两项贷款分项从未进入模型特征，保留原始数据，不作事后修补。实际使用的社融总量2022—2025年度汇总分别320099/355874/322558/356033亿元，均与官方32.01/35.59/32.26/35.6万亿元在公布精度内一致；年度汇总吻合仍不能认证每个月的历史发布版本。完整证据见[扩展核验](../outputs/r33_domestic_macro/financing_scope_audit.json)。
