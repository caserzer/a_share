# R46：当期股票池概率水平锚定，评分前方案

R45累计159候选均未达到双20%。本轮继续使用原R15 B、同27,600股票月以及1/3/6月各自三项概率误差降低20%、方向命中率相对提高20%的12项门槛。不筛股票或预测月份，不换基线。重复历史探索不等于独立验证。

假设：R45 alpha=16网络3/6月月内AUC点估计提高，但总体方向较差，可能存在同期概率水平偏移。本轮不重训网络，固定复用该强度的独立/50%B混合两个完整分布，分别施加方向/七档总体概率锚定，共四个候选。原两分布保留为对照，不增加新数据。

锚是同一预测月、同一原始股票池的原B预测分布，绝非实际未来上涨比例。全部股票等权，预测月整体处理；先形成所有股票的预测才能校准。不会使用当前月或之后的实际标签，不需要新拟合历史。

方向：令每股原非零质量m_i=p_up+p_down，条件上涨概率q_i=p_up/m_i。共同增加一个logit截距b，令sum(m_i*sigmoid(logit(q_i)+b))/sum(m_i)等于原B股票池sum(p_up)/sum(p_up+p_down)。每股零质量不变，上涨/下跌内的幅度相对权重不变。保留q_i的排序；因各股零质量不同，不声称p_up-p_down的排序完全不变。求根区间[-100,100]，xtol=1e-12，maxiter=200，无法满足即失败，不用结果选择偏移。

七档：求共同类别乘数c_k，使q_ik=p_ik*c_k/sum_j(p_ij*c_j)的逐类截面均值等于原B逐类截面均值。目标零质量类别设为精确0，其余要求原分布具正支持。迭代更新log(c_k)+=log(target_k)-log(mean(q_k))，重定中心避免漂移；最大10,000次、均值绝对误差<=1e-10，否则失败。保留每股类别内幅度分布以及活跃类别两两赔率在不同股票之间的相对比值；不保证合并上涨概率排序不变。

从原子分布汇总类别质量，在原子位置不变的前提下替换质量，所有预测仍对应一个完整一致分布。参考R45原缓存和哈希，保存校准前后类别质量、方向截距/七档乘数、目标、残差及原输入凭据。独立重建768份校准和331,200条预测，核验两个参考原样、全部原键、共同赔率约束和锚定误差。统一月份等权、12月块2000次seed24配对区间，另看月内AUC、上涨判定比例和阶段表现。

消融：四新候选各对自己的原分布，七档对同来源方向版；验收仍只相对原B。锚可能本身错误，因此这是对一个可用预测的约束，不是已证明的市场概率校准。仍继承R45有限轮数优化及所有历史数据版本/样本边界。根求解采用[官方scipy brentq接口](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.brentq.html)，新纯概率函数以合成数据验证归一化、精确零目标、截距与赔率不变量、失败边界。
