# R35：训练内秩变换与正则化联合概率（评分前固定）

此前109个候选未达到目标。R34的联合输入在两套树容量上没有改善概率评分。本轮检验不同假设：同一组输入中的可加弱信号，能否通过有界变换与更强收缩保留。不是重选测试样本或只报告方向较好的期限。

仍固定R15 B、原27,600股票月、1/3/6个月和每模型12项双20%门槛。直接复用R34经过核验的面板，原38项控制及全131项分别建模，不新增数据或改变可用时点。

每期仅使用标签严格早于预测日成熟的训练行。每个训练起始月总权重为1（不是所有股票行总权重为行数）。连续输入按这个权重的训练经验分布作中点秩变换至[-1,1]，缺失映射0并为每列追加缺失标记；缺失标记不表示真实值为零。行业仅使用训练中出现的类别做独热编码，未来新类别全部0。所有变换只拟合训练集。

多项逻辑回归，L2惩罚，C固定为1和10，lbfgs，max_iter=1000、tol=1e-6。C的意义受总样本权重影响：本轮每月总权重1，比原来每行权重均值1的拟合具有更强收缩。两种输入各两档，共四次模型拟合/预测月份；不会看测试结果选C。每份输出保留独立分布和与精确B各半混合，形成八个新增候选。以R34浅层控制/联合混合版作原样算法参考，不计入新增候选。

类别仍为七档（精确零单列），各类幅度用同一成熟训练中的32个加权分位点；沿用原始方向判定p_up>p_down。三项概率误差和命中率均按原预测月等权计算。保存系数、截距、类别概率和输入矩阵摘要；审计用原面板重建变换与softmax概率，再重建全部评分。收敛失败必须显式失败，不能静默用未收敛模型。

主要消融为每档C下全输入对原控制、同输入下两档C、每个拟合独立对混合。仍继承公开数据修订、缺失、行业分类空档和原股票池限制；反复历史探索不是独立确认，12个月双20%也未因此获证。
