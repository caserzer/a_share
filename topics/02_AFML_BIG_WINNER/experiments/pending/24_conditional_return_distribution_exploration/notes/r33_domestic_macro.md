# R33：国内景气、通胀与融资信息（评分前固定）

原R15 B、原27,600股票月、1/3/6月分别12项双20%标准不变。此前96个候选未达标。本轮加入从未在此前输入中使用的国内宏观序列，不能把数据接通当作预测有效。

## 数据与口径

PMI、CPI、PPI和M2来自东方财富公开历史API；社融增量来自商务部公开数据中心。保留原始响应与URL/参数。各序列是现时取回的历史表，不是原始发布版本库。统计所属月份和历史可用日期分开：统一假定所属月末45个日历日之后可用，且严格早于预测日。此保守滞后是探索假设，不是逐月发布日期认证，也不能消除后续修订风险。

抽查官方原文：2020年12月PMI制造业51.9、非制造业55.7，M2同比10.1%；2025年12月PMI50.1/50.2、CPI同比0.8%、PPI同比−1.9%；2025年8月M2同比8.8%；2020/2021全年社融34.86/31.35万亿元。金额按官方原文精度验收（两位小数万亿元对应±50亿元）。各原文URL及抽查结果另存。

新增贷款接口与2020年末全部人民币贷款报告存在差异，进一步核对其数值与社融中的实体经济人民币贷款吻合；不把两种口径混用，本轮只使用社融总量。M1自2025年起修订统计口径，本轮不纳入。社融包括政府债券，不能称为纯企业信用或直接入市资金；社融历史覆盖口径和修订仍是限制。M2同比只是货币供应信息，不等同于股票购买力。

## 固定输入

全部为月频历史值，3期差为精确三个统计月之差，不按有值行数跨缺口计算。百分数除100，PMI转为(指数−50)/100。

- 景气通胀组9项：制造业PMI水平及3月变化、非制造业PMI水平及3月变化、CPI同比及3月变化、PPI同比及3月变化、PPI同比减CPI同比。
- 融资组5项：M2同比及3月变化；过去12月社融增量合计/M2余额及其3月变化；过去12月社融合计相较12个月前同口径合计的比例变化。金额统一亿元。分母须正；缺月不填零。
- 合并组：上述14项。

三个输入组分别追加到原38项输入，使用原浅层CatBoost（depth2/100/lr.03/L2=20/seed24）和ExtraTrees（96树/depth6/min_leaf150/max_features.7/seed24，无bootstrap），共6个新候选。相同成熟训练样本、月份等权、全局类别内32分位、50%精确B混合。Extra仅使用训练内中位数与缺失标志。两个参考复用R31已按精确B统一过的无新增因素对照，不重训、不换样本、不修改基线。

先核验连续月序列、单位、官方抽查、严格滞后、历史前缀及所有原行保留，再评分。覆盖不足或字段不匹配时先修数据，不通过删样本得到更好结果。主表相对原B，信息增量表相对同算法参考；所有历史探索与多重试验限制继续保留，12月双20%没有因此获验收。
