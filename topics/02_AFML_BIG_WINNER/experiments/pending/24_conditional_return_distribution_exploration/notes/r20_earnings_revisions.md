# R20：盈利输入的匹配分类消融与预期修正

**状态：6个新候选、三期限同样本实验完成，均未达标；累计35个候选。** 结果见`../earnings_revision_report.md`，下面先记录评分前设计，再记录结果。

延续同股票日期、同R15 B、同1/3/6个月的双20%门槛。R19新增5个方法仍未达标；其中分类模型缺同架构移除盈利输入对照，因此其6月+3.13%方向改善尚不能归因盈利信息。

本轮预先固定6个新候选，另逐值复用R19分类模型作为参考：

1. 同R19盈利可用样本、同浅层分类模型，移除盈利增长、估值锚与亏损信息，保留行情/信用/估值、报告年龄和口径标记。
2. 同R19覆盖、分类模型追加预期修正。
3. 全部原训练/测试股票月，缺失预测保留为空，只有行情/信用/估值及报告元信息。
4. 相同全量样本追加原始盈利预测。
5. 相同全量样本再追加预期修正。
6. 第5种的纯候选分布版本，不与B混合；其余版本新分布/B各占50%。此权重对照在评分前固定。

全部使用100棵深度2的CatBoost七类别模型、相同学习率/正则与随机种子，每月只使用已到期标签。第5/6种共享同一拟合结果，仅混合权重不同。完整27600个测试股票月不删除；同覆盖版本缺数据/训练不足逐值回退B，全量模型用缺失指示保留数据不足的行。

修正定义为同机构、同股票、相同财政年Y与Y+1的预测增长对数之差。它是增长预期修正，不是EPS绝对水平上调/下调：共同每股单位变化会在增长比中抵消。前一报告必须在更早决策月已被观察到，发布时间也必须早于当前报告，报告间隔不超过365日；当年及次年预测均为正数，EPS与归母利润不跨口径比较。原始报告历史仅限先前每月最新报告，不声称完整机构覆盖或一致预期。

初始修正特征覆盖7,237个股票月；极端值原文核对发现EPS“078”与同句PE关系不一致，排除对应2027年值后为7,235/27,600（26.2%）。没有猜测小数点；确认该第三年值未被R19年度配对使用，因此参考预测保持逐值不变。报告选择与特征构建不用未来实际收益；同机构、财政年、时点、股数口径与亏损处理4项专项测试通过。

最终54项测试通过；全量核验覆盖源报告同机构/股票、两篇原文发布时间和此前实际观察日期、逐行修正算术、成熟训练标签、匹配组训练/预测范围、缺失回退、原参考逐值不变、冻结B与完整测试人群。6候选72个20%单项门槛均未通过。上轮参考只复用，未重复计入新增候选。

同覆盖6月无盈利/有盈利/加修正的方向命中率为51.47%/51.59%/51.76%；后两步增加约0.12/0.17个百分点，12月时间块配对区间均跨零。完整模型相对B方向改善3.46%，概率评分改善不足1%；仍弱于固定始终下跌54.29%的方向参考。全量不混合模型同月AUC约0.537，较B的0.517略高，但整体命中率更低，说明相对排序信息不能解决整体市场方向与校准问题。
