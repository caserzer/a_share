# R15：信用利差、PE分位、前瞻收益率的三因素消融

用户要求增加三个因素并做对应消融。沿用1/3/6个日历月、逐月walk-forward、当时已知信息、实际收益仅用作验证标签；不使用策略收益或仓位。

## 运行前固定构造

基础B：63交易日波动率、总市值对数。

C信用利差组：3年期AAA中短期票据收益率减3年国债收益率，以及该差值相对63个观测日前的变化；仅取严格早于预测日、最多7日以前的观测。

P估值分位：当前正PE在截至当日已有正PE历史中的分位，至少252个有效观测。公开源从2018年开始，不冒称十年分位或原始不可修订数据。

F前瞻收益率估值锚：

`forward_return_12m = (1 + g_assumed) * prior_positive_PE_median / current_PE - 1`

`g_assumed = clip(latest_available_profit_yoy / 100, -0.30, +0.30)`

使用当时已披露且原数据UPDATE_DATE亦早于预测日的最近报告同比归母利润增速；假设未来12月维持该增长、总股数不变、12月后PE回到此前正PE历史中位数。中位数严格不包含预测日及未来日，至少252个有效历史值。为防亏损基数造成极端同比，增长假设固定截为±30%，不按实验结果调参。这是公开历史信息构造的估值/盈利情景代理，不是历史分析师一致预期；不含股息，不能称完整总收益预测。模型距离中使用 log(1+forward_return_12m)，与原锚一一对应；三个标签期限均使用同一12月定价锚，不偷用相应未来实际收益。

历史财报版本不足导致可用报告偏旧，必须报告年龄及增长截断比例。F与P共享估值信息，不能把它们视为独立来源；输出特征相关性辅助解释。

## 公平消融

全部8种组合：B、B+C、B+P、B+F、B+C+P、B+C+F、B+P+F、B+C+P+F。加一个无条件扩展历史分布。

各组合严格使用同一完整特征可用人群、同一训练行、同一预测行和实际标签。只使用当前特征来筛选，不按未来结果选样。B在缩小后的共同人群上重算，不能直接拿旧全样本B作对照。另记录与R14人群的覆盖差异。

固定1000近邻，75%近邻分位数+25%总体分位数；每个预测日重训、标签结束日期严格早于预测日。特征仅由训练集的中位数/IQR缩放，截到±5。信用组两个维度各乘1/sqrt(2)，避免仅因维度数多而加倍权重；其余两个新增组各一维。B保持旧距离尺度。无参数搜索。

## 验证与交付

方向Brier、五档Brier、CRPS、方向及各档可靠性、Q05跌破和90%覆盖；按月平均。报告单独加入、从完整模型移除一个组、全部相对B的差异；6/12个月时间块配对区间，分2021–23与2024+阶段。完整2^3比较给出条件依赖，不将探索性区间称为独立验证。

新增行情已被R14查看：若用于新到期结果敏感性，必须标记进一步回溯，不称新封存测试。核心消融只用共同历史数据窗，保持旧证据不变。
