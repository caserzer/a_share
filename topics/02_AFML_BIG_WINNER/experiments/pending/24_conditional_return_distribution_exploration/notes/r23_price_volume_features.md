# R23：量价交互、价格路径与模型容量

R22校准及组合未达到目标。转向新增预测信息，继续原R15 B、原27600股票月与1/3/6个月双20%门槛；不把旧的换手率和成交额均值重复称为新特征。

在R21月份等权模型基础上固定6个新候选：已有换手/成交额均值对照；追加8个成交活跃度/量价交互；追加8个价格路径特征；两组都加入；更大容量的均值对照；相同更大容量加入两组特征。前4个保持深度2/100棵/L2=20，后2个深度4/200棵/L2=50，学习率与种子固定。每个模型使用相同成熟训练行、相同月份等权和相同预测行，完整新分布与B各占50%。更大模型同时改变容量和正则，因此用其匹配对照判断新增特征贡献。

量价组：换手21/63日变化、成交额5/63日变化、成交量变异系数、收益及绝对收益与换手相关、按涨跌方向签名的成交额占比、非流动性代理、成交额加权日内收益与简单平均之差。签名成交额是统计代理，不是已确认的资金流或投资者身份信息。

路径组：日内/隔夜收益均值、收盘在日内范围的位置、振幅水平/变化、日收益自相关、单个正收益日集中度、平价区间日比例。有效一字形价格条的区间位置定义为中性0，并单独保留一字形比例；缺失价格不填充。跨日收益沿用原前复权代理，已知无法解释的复权异常日设为缺失；不改标签、不删除股票。

日线只使用当时及此前21/63个交易日，完整窗口才计算。原价OHLC几何关系、成交量/换手单位、成交额/成交量隐含价格与当日范围核验不通过时，相应量价输入缺失；价格路径输入按其自身有效性计算。单元测试检查追加未来数据不改变过去特征、坏单位处理、异常事件仅影响依赖特征、平价区间定义。全部源文件哈希和逐股质量计数保留。现有历史数据修订及原股票池偏差没有因此消失。

本轮已完成6候选、1/3/6月、64个滚动起点的评分，72个20%单项门槛均未通过，累计53候选未达标。浅层全部特征6月概率评分略有改善（上涨Brier1.41%、五档0.59%、CRPS0.85%），方向命中率50.02%降至48.80%；更大模型为49.06%，也未达到60.03%门槛。

相同容量下，6月浅层全部特征相对均值对照上涨Brier改善0.92%，方向相对改善0.74%，四项配对95%区间均跨零；1月浅层方向反而下降，相对-3.83%，绝对差区间[-3.35,-0.79]个百分点。3月较大模型同月AUC约0.539，但方向命中率52.57%低于原B的53.23%，再次说明相对排序改善不等于涨跌概率可靠。

核验1242只股票、2632930条原价记录；10063条单位/成交均价关系不合格记录不进入相关成交输入。保留全部27600股票月。65项测试通过；全部2484个源文件哈希、训练人群和类别内原子一致性、冻结B与原参考、全部事件概率重建核验通过。实际历史前缀检查使用SH600004、SZ000001、SZ300001的非空有效样本（27/42/42行）；首次抽样发现两只示例在截止日前无共同面板行，已替换并添加非空断言，模型预测无需变更。

特征相关性诊断不使用结果标签：日内收益均值与mom21月内秩相关均值0.891、振幅与vol63为0.880、非流动性与log_money21为-0.820，见`feature_rank_overlap.csv`。这些重合不能证明所有新增特征无信息，但当前实验没有证据支持靠增加此类指标或模型容量达到目标。技术校验和数据可用不等于预测有效；goal保持active。
