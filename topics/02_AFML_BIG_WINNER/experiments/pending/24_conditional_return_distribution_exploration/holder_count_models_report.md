# R36：股东户数水平与变化

**尚未达到双20%目标。** 本轮6个新增候选和2个原样对照，累计123个完整评分候选。原B、27,600股票月与1/3/6个月全部12项标准不变。

本轮较好的方向候选为极端随机树加户数变化：1/3/6个月命中率53.68%/57.18%/49.84%，原B为51.98%/53.23%/50.02%。3个月相对B的上涨Brier、五档Brier和CRPS改善2.21%/0.44%/1.11%，方向相对提高7.42%，仍远低于20%要求；6个月方向低于B。

与不加户数的同算法参考相比，3个月命中率56.89%→57.18%，约+0.29个百分点，按预测月分块重采样95%区间约−0.76至+1.78个百分点；1月和6月的命中率增量区间也跨零。1月增益主要来自2024年以后，早段反而略差。因此这里只观察到小幅点估计变化，尚未证明稳定的信息增量。127项测试通过，输入修正未改变任何原股票月或标签。

新增户数水平、最近两期与约一年变化及时间信息，共7项。两种固定算法各做水平/变化/合并三组消融；原38项控制逐值保留，月份等权成熟训练、32个全局分位点/类、与精确B各半混合。无户数因素的两种同算法参考逐值复用R31。

数据按公告日期严格早于预测日对齐，当前统计期超过180天则特征缺失；每个比较值也取自当时独立已公布记录，未直接采用供应商附带的前期值。原预测样本全部保留，未将来源无记录解释成户数为零。户数不等于持仓集中度或机构资金流。

原1242只股票中1216只股票有历史记录，26只来源明确无记录；公告早于统计日的记录保守排除。两份官方年报四个户数数值匹配，部分供应商日期比年报实际出现该数字更晚；保留较晚日期，不凭零散抽核倒填，历史版本仍未完整认证。

输入检查发现年度比较包含上市前少量股东基数，初始未完成运行已中断隔离，没有计为候选。正式版本要求所有统计日均不早于现有原始行情首个正收盘价日，排除20844条更早记录。这是保守行情覆盖边界，并非精确上市日认证。修正后户数水平覆盖84.82%、年度变化覆盖84.18%。
