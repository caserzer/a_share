# R28：条件分布森林

**尚未达到双20%目标。** 六个固定新候选，累计76个候选。固定原B、27,600股票月、1/3/6个月全部12项门槛；反复历史探索不是独立确认。

原38项输入、相同成熟训练标签和月份权重，测试随机森林与极端随机树。缺失值仅用训练数据填补并加缺失标志；与提升树的原生缺失处理不同。两种森林参数不调优。每种森林比较全局档内幅度/局部幅度与B各半，以及局部分布独立输出。

局部幅度来自预测股票所在叶节点的成熟样本加权分布，七类各32个分位近似。全局与局部的类别概率相同，因此其命中率和上涨Brier应相同；局部分布检验的是幅度、尾部与CRPS增量，不会凭空增加方向信息。

极端随机树局部混合版本3个月命中率53.23%→56.89%（相对+6.87%），上涨Brier/五档/CRPS分别改善1.83%/0.40%/1.01%。分阶段看，2021—2023年命中率57.18%，低于B的57.90%；2024年以后为56.49%，高于B的46.77%。改善主要来自后段，不能认定各阶段均有效。局部幅度替换带来的CRPS变化很小，方向增量来自森林类别概率。
