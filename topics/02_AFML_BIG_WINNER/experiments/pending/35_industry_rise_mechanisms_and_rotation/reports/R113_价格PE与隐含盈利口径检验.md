# R113 价格、PE与隐含盈利的口径检验

本轮验证上涨解释的必要前提：价格、PE、隐含每股盈利和隐含总盈利必须使用一致口径。结果确认代数恒等式可以精确复算，但股本与复权差异足以改变方向解释。它不是“盈利驱动了上涨”的因果证据，也不是预测增量实验。

## 协议与对象

protocols/r113.json在运行前登记。保留R112全部682461条股票月记录，按证券和精确前一日历月连接，要求两个日期均为已完成月的基准末交易日，不跨缺失月份前填。原价与PE均须有限正值且两端上市；非正PE、缺值和未上市保留状态。

设P为原价、M为供应商TTM PE、N为总股数、C为总市值。定义E*=P/M和T*=C/M，仅称供应商隐含每股量及总量。核验三项对数恒等式：

- Δln(P)=Δln(M)+Δln(E*)。
- Δln(C)=Δln(M)+Δln(T*)。
- Δln(T*)=Δln(E*)+Δln(N)，要求两端C=P×N，股本有效日期不晚于端点。

复权价格Q另行要求相同且非空的复权链，记录Δln(Q)−Δln(P)为调整差额。不将该差额自动命名为现金分红，也不认证Q就是可交易含息总回报。

股本变化、调整差额与方向的零值区间固定为绝对对数变化1e-10，作用是区分数值零，不是经济显著性或交易门槛。供应商四舍五入仍可影响小变化方向。

## 结果与覆盖

| 状态 | 股票月记录数 |
| --- | ---: |
| 原价/正PE恒等式可计算 | 368952 |
| 两端未同时上市 | 157681 |
| 非正或缺失PE | 141674 |
| 无效原价 | 8321 |
| 缺少精确已完成月端点 | 5833 |

状态按上述代码中的固定优先次序互斥记录，不能将其中单项理解成所有缺失原因的并集。全部682461条保留，没有在删除亏损公司后重新定义完整母体。

368952个原价配对中，368950个满足总股本/市值条件，368886个满足复权条件，368884个同时满足。三项恒等式最大绝对误差分别约2.22e-15、7.11e-15、6.72e-15，处于浮点精度范围。这证明实现一致，不证明E*或T*等于真实披露盈利。

可评价总量口径中30585对股本变化；复权口径中31133对调整差额非零。19754对隐含每股量与隐含总量的变化方向不同，包含一侧为数值零，不仅是正负翻转。差额绝对值中位数为0、90%分位约8.88e-16、99%分位约0.18476、最大约1.11047，均为对数单位，不直接当收益百分点。

这些差异意味着：若仅依据每股口径下调给出“盈利恶化”解释，可能把拆股、送转或股本分母变化当作公司总盈利变化。总量口径也只是供应商隐含量，仍需与独立会计实际核对。

## 验证与反例

独立验证从原月度价格和R112 PE来源重新按精确身份/月对照全部端点，使用比值取对数重新计算而非复用生产函数；复核全部资格、空值、年度覆盖、股本/调整/方向交叉表及摘要。

新增三个测试覆盖：拆股导致每股量下降但总量不变；现金分配示例中原价下降、复权价不变且盈利隐含量不变；负PE、断复权链、缺前月以及未来股本有效日期均保持适当未知。它们验证算法能区分这些情况，不证明历史上每次差额的公司行为原因。

首轮独立验证遇到CSV年份int64与pandas年份int32的索引类型差异，统一索引类型后继续；单独运行新测试时发现源目录导入依赖，已补显式本地路径。实验数值与协议未改，修正记录保存在outputs/r113/implementation_notes.json。

## 能与不能下的结论

可以确认现有本地源支持精确月末的代数与口径诊断。尚不能声称隐含盈利变动是新信息、先于价格、独立于价格、或者改善了配置；它本身由价格和PE倒算。供应商真实盈利分母、首次发布/修订、稀释股数及公司行为仍待认证。

下一项有依据的工作是固定事前行业成员聚合并完整保留非正PE/缺失分母，同时区分成员等权平均对数分解与行业篮子算术收益，两者不能混称。先登记精确权重、覆盖和身份处理；不能将本轮代数验证直接推广为行业收益归因。整体目标仍active，无采集、部署或发布。
