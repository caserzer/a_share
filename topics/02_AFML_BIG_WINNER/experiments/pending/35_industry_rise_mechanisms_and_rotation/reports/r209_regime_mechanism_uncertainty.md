# R209 同状态模型下的机制增量与不确定性

## 想验证什么

R207 比较同一模型加入 regime 前后，R208 检验分类概率。本轮补上另一项必要比较：双方使用相同 regime 结构时，机制变量是否仍比控制模型有效？另外检验 regime 是否改善了这个信息增量，避免把控制模型自身变化误记为机制贡献。

协议先登记于 protocols/r209.json，不重新拟合、不选择新参数。纳入 R197 盈利预期、R198 装车量、R199 市场风格/规模扩散/融资、R200 龙头与追赶、R201 财务双时钟、R202 宏观、R205 利润事件。各自采用原先登记的方法配对，保留原期限、分类、母体、时钟及指标资格。同一机制比较分别使用 base、state、interaction；再计算 state 与 interaction 的机制增量相对 base 的变化。后一项是预测损失或排序指标的差之差，不是因果估计。

这不是重新声称全部16类都具有独立机制对照。核心三任务、收益排名、固定分数已有直接 regime 对照；短历史早期财务和资本会计仍保留无训练资格结论。没有为它们制造本轮机制预测。

## 方法和结果

配对日期内的指标差先聚合为月平均，再对月份等权；事件模型因此是月等权评价，与原逐事件日等权均值不能直接混用。缺失保持未知。沿用 R207 固定六个日历月的 Bartlett HAC 核，至少24个有效月份、跨至少3个日历年且标准误非退化才提供区间；缺失月份不压缩。使用正态近似和本轮2360项比较的 Bonferroni 校正，含不满足资格的登记比较。

| 比较 | 总项数 | 具估计资格 | 校正后正向区间 | 校正后负向区间 |
|---|---:|---:|---:|---:|
| 原模型的机制增量 | 472 | 96 | 0 | 1 |
| 状态主效应下的机制增量 | 472 | 96 | 0 | 1 |
| 状态交互下的机制增量 | 472 | 94 | 0 | 0 |
| 状态主效应使增量改变多少 | 472 | 86 | 0 | 0 |
| 状态交互使增量改变多少 | 472 | 94 | 0 | 0 |

总计2360项，466项具估计资格，1894项不足或退化。没有校正后为正的区间；也没有“所有年度片段为正且校正下界为正”的筛选通过项。

两项负向结果均来自宏观45日发布滞后代理：SW2014二级 base 的 F_exposure 相对 F，20日IC均差 -0.094069，26个月/3年，校正区间约 [-0.186479,-0.001660]；SW2021二级 state 的 F_macro 相对 F，20日头部超额均差 -0.006783（约 -0.6783 个百分点），30个月/3年，区间约 [-0.012628,-0.000938]。不能外推至其他时钟、层级或可交易收益。

按来源具估计资格项数：预期0/120、装车0/40、市场风格/规模/融资102/1140、龙头0/460、财务0/100、宏观314/400、利润事件50/100。零项符合本轮区间条件，不等于变量没有作用；原有限样本点估计仍完整保留。

## 能否下结论

当前不能说 regime 使某个独立机制获得了稳定、经统一检验支持的信息增量，更不能统一升级所有模型。局部正均值仍存在，但应保留为待验证线索。多重校正保守、区间近似、历史反复使用且市场日期相关，未通过不证明精确零效应；本轮不是新留出或严格有限样本显著性证明。

变量的领先时间及成熟条件沿用原实验；宏观发布、财务更新、预期覆盖等 Historical-proxy 边界没有升级。控制变量比较评价条件预测增量，不证明经济因果。尚未在本轮加入交易延迟后的完整路径、换手成本、回撤和错误退出代价，不能宣称配置价值。保持不采用、不部署、不改默认发布。

## 核验与下一项工作

独立 outer merge 以日期及方案一对一连接机制与控制，重建全部78045个日期差及增量变化，最大误差0；独立复算52900个月度记录及2360组均值、日历HAC与校正下界，标准误最大差1.25e-16。首次独立配对核验因整型/浮点元数据字符串不同失败，修正仅影响核验键的数值规范化，研究输出不变；失败记录保留。

产物位于 outputs/r209：paired_dates.parquet、monthly_deltas.parquet、uncertainty.csv、annual.csv，以及 verification.json、independent_verification.json、independent_pair_verification.json。代码为 src/regime_mechanism_uncertainty_r209.py 和两份 verify_regime_mechanism_*r209.py。
