# R299 显式日期反转概率对照入口

## 已完成的功能

只读指定日期的核心F/F反转20日归档，同时显示各行业base/state/interaction的月频校准概率和日频校准概率。两种概率均带R298用途说明、来源哈希、Historical-proxy和回顾性标记，不代表经济反转概率已被认证。

日期必须为YYYY-MM-DD。无当日样本（包括档案范围以外）明确返回no_exact_date_output和空rows，不填最近值、不补零、不创建新预测。原始数据中的y、maturity20和linear不在读取白名单中，输出不暴露未来目标。

## 使用

在项目根目录运行：

```bash
topics/02_AFML_BIG_WINNER/.venv/bin/python topics/02_AFML_BIG_WINNER/experiments/pending/35_industry_rise_mechanisms_and_rotation/src/reversal_probability_reader_r299.py --as-of 2026-09-30
```

输出严格JSON。2026-09-30返回765条，不混入其它日期；2026-10-21另有独立样例。只返回预测字段，不依据目标是否成熟筛选，未知目标对应的预测仍保留。

## 验证与适用范围

对897个源日期和371967条记录逐日与源文件字段白名单投影精确比较；两个实际日期、一个周末和2030年缺日期均按真实覆盖返回。五类错误日期被拒绝；临时副本源字节改动被拒绝；真实CLI输出与函数结果一致。输入及代码哈希留存在verification.json。

这只证明读取行为与归档相符，不提升预测有效性。领先性、独立增量、机制及成本结论仍分别来自R295—R297：历史重复评价、regime无明确改善、原排名提示不变。入口不输出新退出建议或概率仓位。原全部16类历史归档保持原样，本入口仅提供已验证21个核心反转模型的对照。
