# EP39 修订一　超跌席位复核的复测协议

2026-11-24，于修正版预测、交易清单与账户读数生成前记录。研究问题是，原沪深300训练模型已在池内前10%选入一只超跌股时，用真实超跌样本再判断一次，能否用更好的候补股取代会亏损的持仓。此次修订针对上一次诊断提出的超跌任务。既有139个交易窗口已被观察。

## 数据与模型

- 以沪深300为周频训练母池，将入池规则与H10评分日期使用的实际资格规则对齐，再在当日合格股票中计算过去5日收益分位。5日收益为负且处于最低10%即触发。检查周频和交易档案日期相同的全部截面。
- 自然组保留所有可用超跌股票日。分别预测下一开盘买入、十个交易日后开盘退出时的亏损，以及十日内盘中低点是否跌破信号时的5日低点。前者以收益严格小于零为阳性，后者以严格跌破为阳性。到期后仍不能观测某一标签的股票日只在该任务内缺失。先破低后收涨同时给出“破低”和“期末无亏损”。
- 23个季度扩展训练，每季初仅用已经到期的股票日。保留原78项特征及折内变换，采用固定L2逻辑回归（C=1）分别估计两种概率，保留自然发生率。困难案例组使用相同数据，并将原同日配对两端的行权重从1提高至2。五个对照使用相同额外权重总数，按同日、同原D10身份随机指定加权行。种子39、139、239、339、439。加权概率仅用于同一批候选间排序。全池与原D10内分别评价相对历史自然发生率的Brier分数、ROC AUC及样本数。

## 交易决定

1. 每个信号收盘沿用各池封存原模型的完整合格名单、当日分数和前10%目标。仅复核原D10中当日触发超跌的股票。自然模型所给十日亏损概率严格高于50%的股票进入换出名单。50%为固定盈亏方向判据。破低概率留作诊断，不能单独触发换股。
2. 候补从原D10以外、已知未触发超跌的股票中，按当日原评分从高到低（同分取代码较大者）依次补足，不读取下一开盘能否成交或未来收益。如候补不够只安排能配成的换股，保留其它原席位。原D10非超跌席位和目标持仓总数逐日守恒。次日实际成交、停牌和现金沿用基线执行器。
3. 主比较为自然复核相对原账户的配对H10净差。另外固定自然模型当日的换出数、候补名单和资金预算，比较困难加权、五种随机加权、首轮精选旧评分的局部用法和五个随机换出账户。随机换出仅在原本复核的超跌股票中抽签，固定按种子、池、日期产生选择。这样可以核对换股本身与换哪只股票的区别。每种子独立模拟账户，五种子均值仅为对照读数。
4. 不训练800系数，按实际800成分及池内超跌分位应用同一季模型。300及800的主段、后段分列，三档费率（每边基础买10、卖20 bp；零费；双倍费）。同日同额起算、同日净交易，持仓估值缺口按所有账户共同可评窗口分段；独立账段不拼接年化。逐期净差用各段内长度3的H10循环分块、10,000次、种子3901给出描述性95%区间。
5. 另核对原席位去留、躲开亏损/错过盈利/先破低后收涨、替补的同额收益、门控及真实订单。每组换出和候补的终值盈亏与路径在决策表封存后补入。报告首轮全池和本轮局部部署的区别，留给未见日期检验。
