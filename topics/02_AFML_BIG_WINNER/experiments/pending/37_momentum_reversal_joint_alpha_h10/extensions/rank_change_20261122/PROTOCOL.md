# EP37 排名上升与头部持续入选

2026-11-22。本轮只读封存的收益秩MSE预测，不重训。预先登记比较、匹配、组合与停止条件。原主区间100个固定H10，后39个窗口和全139期单列，均属于已研究历史。

1. 每个时点使用当时可评分股票的当期分数、平均百分位和原十分组。同股票的上期必须来自紧邻的前一个H10信号，跳期、没有过去评分或首期均标未知。新进=本期D10且上期有评分不在D10；留存=连续两期D10；退出用于复核原新进减退出线索。另保留与旧研究一致的名单差（包括新出现股票）。记录跨季度换模及股票池变化。
2. 同日在D10内部，将新进和留存匹配。要求相同且已知的历史申万一级行业、当前分数相差≤当日全部候选分数标准差的0.25倍、近5日和20日收益各差≤各自当日截面标准差的0.5倍。每只最多用一次；先最大化配对数，再最小化三项按容差标准化后的平方距离和，代码排序破同分。冻结前不读H10结果。不放宽容差；披露可比预算、协变量差、未匹配月份。分类“留存”仅表示连续两期在最高组。
3. 主要机制检验：匹配新进篮子减匹配留存篮子的同期开盘到开盘H10净收益，分别以单位资金等权，使用原交易门槛；无买入、无法完整退出或无匹配保留缺失。补充给出未匹配、全额买入、同季度和后段结果。以当前前20%为辅助范围，逐期在圈内剥离行业固定效应、当前分数秩、5/20日收益秩，考察排名升幅与未来H10收益秩的剩余相关。仅使用上期已知、标签已知和行业可识别股票，至少10个残差自由度。该估计不能取代D10净配对。
4. 主要经济检验：保持原D10名单及行业目标预算，基线每股1/k；每个匹配把留存股权重的一半移至对应新进股，配对为1.5/k和0.5/k，未匹配不变。每期对账；未配对月份照常计入账户。净额换手、买10/卖20bp、停牌代理与严格分支和零成本对照沿用原版。比较每个H10连续账户周期的成本后收益差，入场前资金至下一调仓开盘前；主区间末期使用计划退出开盘扣费后市值。报告费用、净年化、回撤、可比终点、与基准差和不能清仓的原因。已截断区间不外推。
5. 两项主检验按6个时间窗口循环块、2000次、Holm两项；原100个日期内保留缺失。若排序信息和账户增量不能共同支持，不据此提升新进股权重，也不继续同历史调参。保留所有目标、交易、逐期差及核验记录。
