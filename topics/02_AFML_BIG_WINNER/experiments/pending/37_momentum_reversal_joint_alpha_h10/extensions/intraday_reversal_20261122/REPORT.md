# EP37 的头部选股、隔夜与日内回撤，以及重复换手

2026-11-22。本轮继续在原沪深300共同池寻找 H10 多头 Alpha。基线是原78特征拟合截面收益排名的 Ridge；原 E1（同78特征拟合标准化收益）并列重放。

**最清楚的改善来自执行。** 同一批预测、同一批目标股票、同一组买卖限制，连续入选股票只交易差额，主区间净年化由2.81%升至5.56%。新加的五日上涨下跌时段信息曾小幅提高头部净值，但其H10配对优势未获确认，中期动量交互也未显示额外优势。保留原收益秩模型，净额执行可作为后续历史研究的现实对照。

## 一、基线靠头部选股还是回避尾部

## 三、数据检查与中期趋势解释

主区间29,304个候选股票日期中有619个被标记，约2.11%。五日窗内出现复权因子变化代理576个、开盘异常代理42个、交易状态标记1个，类别允许重叠。复权因子代理不能替代真实公司行动公告。开盘异常同时考虑开盘超出当日高低及绝对隔夜对数跳幅超过10%。没有用这些标记删除主线的预测。全部新分支41,049个候选股票日期上，五日日内加隔夜与五日收收对数收益的最大可核误差小于8×10⁻¹⁶。

另把已标记股票在信号日统一移出，按各模型冻结分数在同一干净股票池重新分组。加X的D10事件增量为+0.062个百分点，区间[+0.002,+0.131]；再加交互为−0.045个百分点，区间[−0.085,−0.008]。这些是另一个股票池上的敏感性比较，不属于主要检验族。加X换入的股票中约3.30%带标记，换出约6.59%；交互版本分别约1.79%和0%。异常日影响了部分差值，但无法支持交互项获利。[逐日数据审计](results/quality.csv)

为解释“同样回撤时哪类更好”，在主结果生成后，补做一个描述性核对。仅取最近5日下跌股票，按此前55日涨跌分组，每日分别对X和未来H10收益的秩剥离基线分数、中期涨幅、短期跌幅的线性秩关联，每组至少20只。主区间中期上涨组的平均残差相关为−0.021（92期，区间[−0.046,+0.005]），中期下跌组为+0.006（94期，[−0.020,+0.031]）。后39期两组方向均反转。回看这两段历史，没有确认“同样回撤时，隔夜跌或日内跌哪一类应始终优先”的规则。该核对未控制行业，属于事后诊断。[逐期条件相关及覆盖](results/pullback_associations.csv) · [时间块区间](results/pullback_summary.csv)

## 四、净额执行保住了多少收益

冻结原收益秩模型的全部D10目标，沿用同一开盘、卖出受阻每日重试、买入门槛及终点。每次在当时现金及持仓基础上，先确定原规则可执行的卖额和目标买额，再抵消同股同开盘成交的重叠部分。当前省下的费用留现金，在下一次建仓进入可用资金。被限制的交易不会因为抵消而取得额外成交资格。

| 主区间，每初始100元 | 到期全卖后重买 | 同一名单净额交易 |
|---|---:|---:|
| 零成本年化 | +10.88% | +10.88% |
| 主成本净年化 | +2.81% | **+5.56%** |
| 主成本期末资产 | 111.61元 | **123.96元** |
| 实付交易费用合计 | 28.93元 | 19.57元 |
| 主成本最大回撤 | −36.51% | −34.70% |
| 收盘对齐的全收益指数年化差 | +8.85个百分点 | +11.61个百分点 |

原主账户5,784条已执行或受阻的订单记录逐行重放一致。在原资金路径上逐股逐开盘核算，99次续期均有可抵消成交，机械可省10.22元，占原实际费用约35.3%。两条真实模拟路径费用之差为9.36元；净额账户保留了更多本金，后续成交规模已不同。终值增加12.36元还包含后续收益复利。零成本两账户逐日净值最大误差4.22×10⁻¹⁵。因而本轮增加的净收益可以归到执行合同和随后的资金路径。[原逐开盘可省费用](results/primary_100_windows.csv) · [实际净额成交](results/net_orders.parquet) · [逐日净值与费用](results/nav.parquet)

## 裁决与数据边界

- 现阶段保留原收益秩基线。时段拆分仍有小幅历史线索，未达到预先指定的增量标准；中期趋势交互没有显示经济增益。本轮不据此升级模型。
- 相同目标名单的净额执行在当前历史合同下有可重放的价值。后续研究可同时保留“全额重开”供历史对照及“净额换手”衡量可保留的收益。后续候选比较应共享同一执行方式。
- 主账户估值使用确认全天停牌时最多20交易日旧价。所有模型的主账户期末有未能卖出的持仓，用估值计算终值；严格报价账户仅走到2025-02-05。延伸账户2025-03-04遇SH600837持仓报价未知，无法认证至2026-10-12的连续净年化；后39期只评价可单独观察的排名和新建事件。源数据为前复权合成单位、历史成分代理。真实前瞻新增观测为0。
- 运行24季度、4版本共96次拟合，原两基线48个“模型×季度”预测核对通过，两条原主成本账户逐日净值复现。净额订单独立重建持仓、现金及净值；27项原EP37测试与4项新增执行测试通过。[冻结合同](PROTOCOL.md) · [输入哈希](results/inputs.json) · [封存名单哈希](results/selection.json) · [核验回执](results/validation.json) · [各账户停止原因](results/account_receipts.json)
